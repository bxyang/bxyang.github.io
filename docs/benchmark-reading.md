# Benchmark 精读

逐篇阅读经典 benchmark 的论文与评测方案，讨论它们如何把要测量的能力转化为任务、数据和评分规则，以及最终分数能够说明什么。

## 关注哪些设计

| 设计环节 | 阅读重点 |
| --- | --- |
| 评测目标 | 希望衡量什么能力，选择的任务与实际使用场景有什么关系。 |
| 任务与数据 | 样本来自哪里，如何构造、筛选和划分，难度与覆盖范围如何确定。 |
| 运行环境 | 模型能获得哪些信息、使用哪些工具，交互方式和资源限制如何设置。 |
| 评分与验证 | 如何判断任务完成，采用执行测试、标准答案还是人工与模型评审，如何汇总分数。 |
| 结果与局限 | 结果是否稳定，是否存在数据泄漏、评分漏洞或适用范围限制，不同方案的分数能否直接比较。 |

每篇从具体任务样例出发，结合原论文、官方文档和必要的评测代码解释设计。区分作者已经验证的结论与仍需讨论的问题。
