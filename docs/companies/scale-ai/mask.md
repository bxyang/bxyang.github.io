# MASK：区分知识准确性与诚实表达

比较模型已掌握的信息与受到压力时给出的陈述。

## 工作内容

数据通过人工收集场景，将模型的知识判断与后续受情境影响的回答区分开来。评测试图避免把“知道答案”直接当作“会如实表达”，并比较干预方法对行为的影响。 [资料](https://arxiv.org/abs/2503.03750)

## 数据与使用范围

研究测量的是实验情境中的输出一致性和诚实行为，不需要假定模型具有人类式主观意图。论文提供可用于不同模型的评测设置。 [资料](https://arxiv.org/abs/2503.03750)
