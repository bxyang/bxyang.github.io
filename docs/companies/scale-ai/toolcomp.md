# ToolComp：多工具推理与过程监督

同时检查多步工具任务的最终答案和中间执行过程。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-01-02 |
| 类型 | 基准与论文 |
| 公司参与 | Scale 发布 |

## 工作内容

模型与人工共同制作任务，人工编辑或核实提示、最终答案和步骤标签。研究使用这些标注比较结果监督奖励模型与过程监督奖励模型对候选轨迹的排序能力。 [资料](https://arxiv.org/abs/2501.01290)

## 数据与使用范围

论文包含 485 个复杂任务。过程标签让评测能够定位中间错误；排序实验与直接部署 agent 的端到端成功率是不同指标。 [资料](https://arxiv.org/abs/2501.01290)
