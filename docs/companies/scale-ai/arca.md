# ARCA：利用适配器残差分配训练信号

模型写出几百个 token 的数学解答，最终只能得到“答案正确”或“答案错误”的奖励。ARCA 研究如何把这个奖励分配到不同生成位置：对同一条回答，分别开启和关闭 LoRA 适配器，比较最后一层隐藏状态；变化较大的位置获得较高训练权重。论文在 Qwen3-1.7B-Base 与 MATH 上做了七组小规模实验，观察到这种权重比其他非均匀基线更分散，但最终准确率没有全面领先。它提供的是一种分配训练信号的方法及诊断结果，不能把隐藏状态变化直接解释为某个 token 对正确答案的真实贡献。

## 最终奖励不能指出每一步的作用

设题目为 $x$，模型生成回答 $y=(y_1,\ldots,y_T)$，最终奖励为 $R(x,y)$。普通策略梯度把同一个奖励减基线后的优势 $A(x,y)$，乘到每个 token 的对数概率梯度上：

$$
g=A(x,y)\sum_{t=1}^T\nabla_\theta\log\pi_\theta(y_t\mid x,y_{<t}).
$$

这不表示每个 token 的实际参数梯度相同，而是每项前面的优势系数相同。正确回答中的过渡词、关键等式和最终答案都收到同方向的标量信号。ARCA 改变这些系数在位置间的比例。[原文式 1–7](https://arxiv.org/pdf/2606.00257v1#page=3)

论文使用 GRPO 风格的组内优势。每题采样 $K$ 条回答，奖励为 $R_1,\ldots,R_K$，以组内均值和标准差归一化：

$$
A_i=\frac{R_i-\mu_R}{\sigma_R+\varepsilon}.
$$

实验 $K=4$。全部正确或全部错误时，各回答的优势都为零；重新分配 token 权重不能为这一组凭空创造差异化奖励。原文也给出 RLOO 的留一法基线，但七组主实验使用的都是 GRPO，不能把支持两种算法的代码说成已经做完两种算法的实验比较。

## 在每条回答内部归一化权重

令 $s_t\ge0$ 为位置 $t$ 的原始重要性分数。为避免与 LoRA 的缩放参数混淆，本文用 $s_t$ 表示论文中的 $\alpha_t$。原文式 8 定义：

$$
w_t=\frac{s_t+\varepsilon}{\sum_{k=1}^T(s_k+\varepsilon)},
\qquad\sum_t w_t=1.
$$

随后使用加权更新：

$$
g_w=A(x,y)\sum_{t=1}^T w_t\nabla_\theta\log\pi_\theta(y_t\mid x,y_{<t}).
$$

均匀基线为 $w_t=1/T$。它相比前面的 token 求和多了长度归一化；回答长度不同时，两者的期望更新不能当作完全相同。归一化控制的是系数总和，不能保证不同权重下的梯度向量范数相等。

实现把权重从计算图分离，即不沿 $w_t$ 反向传播。这样更新的是按既定权重加权的对数概率，而不是同时优化“让自己的权重变大”。非均匀权重依赖生成轨迹，通常会改变原始策略梯度估计，论文附录 C 也承认存在偏差；on-policy 采样并不自动消除这类偏差。[原文 §3.2–3.3、附录 C.1–C.5](https://arxiv.org/pdf/2606.00257v1#page=13)

## 四类信号分别衡量不同现象

| 方法 | 原始分数 $s_t$ | 含义 |
| --- | --- | --- |
| 惊讶度 | $-\log\pi_\theta(y_t\mid x,y_{<t})$ | 当前模型对实际生成 token 有多意外 |
| 熵下降 | $\max(0,H_t-H_{t+1})$ | 生成该 token 后，下一步预测分布是否更集中 |
| 策略差异 | $|\log\pi_\theta(y_t\mid x,y_{<t})-\log\pi_{\rm ref}(y_t\mid x,y_{<t})|$ | 当前模型与参考模型给实际 token 的对数概率相差多少 |
| ARCA | $\|h_t^{\rm adapted}-h_t^{\rm base}\|_2$ | 开关适配器后，最后一层隐藏状态改变多少 |

$H_t=-\sum_v\pi_\theta(v\mid x,y_{<t})\log\pi_\theta(v\mid x,y_{<t})$，求和覆盖词表。熵下降在最后一个有效位置按论文定义设为零。策略差异只看被采样 token 的对数概率差的绝对值，并不是对整个词表精确计算 KL 散度。[原文式 10–15](https://arxiv.org/pdf/2606.00257v1#page=4)

这些信号都没有中间步骤的正确标签。某个 token 罕见、让分布变得集中，或引起较大隐藏状态变化，都不意味着它一定正确。最终奖励仍决定这条轨迹总体被强化还是被抑制。

## ARCA 比较同一条序列上的两个前向过程

LoRA 冻结原权重，用低秩矩阵乘积表示增量，例如 $W'=W+BA$。ARCA 不把每层的 $BA$ 范数直接相加，而是取模型最后一层、与预测当前 token 对齐的隐藏状态：

$$
\Delta h_t=h_t^{\rm adapted}-h_t^{\rm base},\qquad s_t=\|\Delta h_t\|_2.
$$

两次前向读取相同的题目和已生成 token 序列，只切换适配器。它不是让两个模型各生成一条回答，再比较不同长度的文本。代码从 `prompt_width - 1` 开始截取隐藏状态，使第一个位置对应预测第一个回答 token 的上下文；最后一个生成 token 本身不再作为下一步输入参与这段对齐。

**说明示例：**四个位置的残差范数是 $(1,1,2,6)$，忽略极小稳定项时，原文线性归一化权重为 $(0.1,0.1,0.2,0.6)$。若整条回答优势为负，第四个位置会受到更强的负向系数；它不会因为残差大而自动得到正奖励。

论文称只需增加一次关闭适配器的无梯度前向，且可以复用参考模型计算。当前实现实际上先计算带梯度的策略 log-probabilities，再分别额外执行一次开启适配器、一次关闭适配器的无梯度隐藏状态前向。它没有复用第一次前向中的隐藏状态。因此，“没有新可训练网络”成立，“当前代码只多一次前向”则不成立。[固定提交的 `compute_loss`](https://github.com/rodlaf/tokenweighting/blob/d34239a0647c276530722480853757777119ec46/experiment/hf/run_experiment.py)

## 理论中的局部条件与证明边界

### 小变化与小秩不能直接画等号

附录 C.6 设最后一层输出头为 $W_{\rm lm}$，$L=\|W_{\rm lm}\|_{\rm op}$，$\beta=\max_t\|\Delta h_t\|_2$。从隐藏状态到 logits，再到对数概率，可以得到逐位置变化受 $L\beta$ 控制的局部界。策略差异满足原文给出的 $0\le s_t^{\rm div}\le2L\beta$。

如果所有分数都远小于固定的 $\varepsilon$，分子分母主要由稳定项决定，权重趋于 $1/T$。若分数仍远大于稳定项，归一化则取决于各位置的相对大小：小数值本身不必产生均匀权重，也不必产生稀疏权重。例如 $s_t=c a_t$ 且忽略稳定项时，公共尺度 $c$ 会约掉。

这里是给定轨迹和小残差条件下的分析。低秩只限制更新矩阵的秩，不单独限制矩阵范数；还需要适配器幅度、输入与网络传播等条件，才能推出 $\beta$ 很小。论文没有通过多种秩、全参数微调及相同信号的完整交叉对照，证明所有 LoRA 训练都会发生同一种退化。[原文 §3.4、附录 C.6](https://arxiv.org/pdf/2606.00257v1#page=14)

### 惊讶度主要沿用基础模型的分布

命题 1 的意思是：当适配器改变很小时，当前惊讶度的归一化形状接近参考模型的形状。这能说明它未必反映适配器影响最大的地方，却不能说明参考模型的不确定性与任务无关。

该命题印出的 $L_1$ 界还需要注意序列长度：正文先得到每个位置至多 $2L\beta$ 的分数差；把这些差累加到向量的 $L_1$ 范数，通常会引入 $T$。按常见的非负向量归一化界，可得到类似：

$$
\|w-w^{\rm ref}\|_1
\le\frac{2\|s-s^{\rm ref}\|_1}{\sum_t s_t^{\rm ref}}
\le\frac{4TL\beta}{\sum_t s_t^{\rm ref}},
$$

这里忽略稳定项并要求相关总和为正。原文显示的对应上界没有 $T$；本页给出的是解释这一推导缺口的数学整理，不把它当成作者已证明的更强结论。熵下降还涉及相邻位置熵的变化，原文只称类似结论成立，未展开所有条件和常数。

### 层间变化可能抵消

附录 C.7 命题 3 尝试从各层适配器贡献 $v_{\ell,t}$ 的范数方差，推出最终残差范数也有正的方差。证明文字提到“主导层”，但命题没有明确排除不同层的向量抵消；向量和的范数不能直接按各层范数的方差下界处理。

**用于检查条件的自拟例子：**两个位置令 $a_1=1,a_2=2$，两层贡献为 $v_{1,t}=(a_t,0)$、$v_{2,t}=(-a_t,1)$，高阶项为零。每层范数都随位置改变，但总残差恒为 $(0,1)$，其范数始终为 1，归一化权重仍然均匀。这个例子满足所写分解，并且总残差不需要低于稳定项。[原文命题 3](https://arxiv.org/pdf/2606.00257v1#page=15)

因此，可以直接确认的是：**若最终残差范数本身具有位置差异，且没有被稳定项淹没，ARCA 权重就能保留这种差异。** 从任意一层激活有变化到最终权重必然不退化，还需要额外条件。论文也没有证明残差大小等价于梯度贡献，更没有给出 RL 收敛保证。

## MATH 实验实际比较了七组设置

实验使用 `Qwen/Qwen3-1.7B-Base`，根据数学答案是否与参考答案匹配给出 0/1 奖励。四种基线的 LoRA 秩都为 64；ARCA 分别使用秩 4、16、64。公平的同参数比较是 ARCA-64 与其余 rank-64 方法，低秩 ARCA 则是容量对照。[原文 §4.1、表 1](https://arxiv.org/pdf/2606.00257v1#page=7)

| 设置 | 论文报告 |
| --- | --- |
| 训练任务 | MATH 训练划分 |
| 最终评测 | 200 道保留的 MATH 题 |
| 随机种子 | 1337，单个种子 |
| 更新次数 | 100 |
| 每题回答数 | 4 |
| 每个微批题数与梯度累积 | 2 题，累积 4 个微批 |
| 优化器 | AdamW，学习率 $5\times10^{-6}$，零权重衰减 |
| 学习率计划 | 10 步 warmup 后余弦衰减 |
| 最大题目与回答长度 | 各 512 tokens |
| 采样 | 温度 1.0，top-p 0.95 |
| 检查点 | 每 20 步保存 |

按这些数值，每次优化器更新对应 8 次题目抽取、32 条回答，100 步共 3,200 条训练回答。题目可重复抽取，所以不能写成 800 道不同题。若每条都达到 512 tokens，回答部分上限约为 164 万 tokens；这是预算算术，不是实测生成量，未计题目与额外前向。

### 数据与答案评分的具体实现

代码使用 `DigitalLearningGmbH/MATH-lighteval`，当前核查快照 `0530c78699ea5e8eb5530600900e1f328b48acad` 的默认配置有训练 7,500 题、测试 5,000 题。程序选测试划分**最前面的 200 题**，没有在截取前打乱；因此不能写成随机抽取、难度分层或完整 MATH 测试集。[数据快照](https://huggingface.co/datasets/DigitalLearningGmbH/MATH-lighteval/tree/0530c78699ea5e8eb5530600900e1f328b48acad)、[加载代码](https://github.com/rodlaf/tokenweighting/blob/d34239a0647c276530722480853757777119ec46/experiment/hf/data.py)

奖励提取最后一个括号配平的 `\boxed{...}`，做有限文本规范化，然后比较字符串。没有可提取答案就记零。它不是符号等价证明器：本次用原函数检查，`\dfrac{1}{2}` 与 `\frac{1}{2}` 记为相同，`0.5` 与 `\frac{1}{2}` 则记为不同；`A` 与 `a` 也不同，尽管函数注释提到 lowercase。这里仅运行了字符串评分例子，未运行模型实验。[评分实现](https://github.com/rodlaf/tokenweighting/blob/d34239a0647c276530722480853757777119ec46/experiment/hf/tasks/math_task.py)

论文没有额外构造专家过程标签。它沿用 MATH 的题目和参考解答，没有报告基础模型预训练数据与评测题的排重审计。代码也没有固定模型、tokenizer、数据的 revision；本次数据快照不能反向认作原实验使用的版本。

## 准确率结果没有显示全面领先

以下由表 2 转为百分数。平均训练奖励是全训练过程的均值，不是训练结束时的准确率。

| 方法 | 秩 | 可训练参数 | 贪心准确率 | pass@4 | 平均训练奖励 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 均匀权重 | 64 | 69.7M | 62.0% | 67.5% | 0.362 |
| 惊讶度 | 64 | 69.7M | 52.0% | 65.0% | 0.326 |
| 熵下降 | 64 | 69.7M | 60.0% | 70.0% | 0.367 |
| 策略差异 | 64 | 69.7M | 56.5% | 67.0% | 0.351 |
| ARCA | 4 | 4.36M | 52.5% | 64.0% | 0.327 |
| ARCA | 16 | 17.4M | 51.0% | 65.5% | 0.336 |
| ARCA | 64 | 69.7M | 59.0% | 68.0% | 0.353 |

ARCA-64 相对均匀权重，贪心准确率低 3 个百分点，pass@4 高 0.5 个百分点；相对熵下降，两个指标分别低 1、2 个百分点。200 题上，0.5 个百分点只对应一道题的成功覆盖差，不能据此宣称显著提升。[原文表 2](https://arxiv.org/pdf/2606.00257v1#page=7)

当前评测代码的贪心准确率来自每题一次确定性生成；pass@4 来自另行采样的四条回答，只要其中一条正确，这题就成功。它并不使用奖励模型选出一条，也不是四次平均正确率。两种评测都沿用最长 512 个新 token；没有独立训练重复或置信区间。

低秩 ARCA 没有达到 rank-64 均匀基线的表现，ARCA-16 的贪心结果还低于 ARCA-4。这些点估计不能支持“增加秩一定提高准确率”，也没有证实能用极少参数完全替代高秩适配器。主表未列未训练基础模型的成绩，因而不能据表中训练后数值计算相对原模型的净收益。

## 权重诊断与解题正确率需要分开

对一条有效长度为 $T$ 的回答，定义：

$$
\mathrm{EffN}(w)=\frac{1}{\sum_t w_t^2},\qquad
\rho(w)=\frac{\mathrm{EffN}(w)}{T}.
$$

均匀权重时 $\rho=1$；全部权重集中在一个位置时 $\rho=1/T$。它是权重集中程度对应的“有效数量”，不是实际只训练了多少 token。实现还计算 Gini 系数：

$$
G(w)=\frac{\sum_{i=1}^T\sum_{j=1}^T|w_i-w_j|}
{2T\sum_i w_i}.
$$

均匀时为零；单点集中时为 $(T-1)/T$，有限长度下不是精确的 1。表 3 给出跨训练过程的统计：

| 方法 | 秩 | Gini | 有效 token 比例 |
| --- | ---: | ---: | ---: |
| 均匀权重 | 64 | 0.000 | 1.000 |
| 惊讶度 | 64 | 0.941 | 0.052 |
| 熵下降 | 64 | 0.920 | 0.073 |
| 策略差异 | 64 | 0.939 | 0.055 |
| ARCA | 4 | 0.353 | 0.467 |
| ARCA | 16 | 0.388 | 0.460 |
| ARCA | 64 | 0.490 | 0.334 |

三个输出概率基线在本实验中是高度集中，**不是趋于均匀**。ARCA 则介于均匀与高度集中之间。表格证明了权重分布不同，但不证明高权重位置是正确推理步骤；论文没有人工 token 重要性标签、移除指定 token 的因果干预，或固定稀疏度后只改变信号来源的对照。熵下降虽然更集中，pass@4 却高于 ARCA，也说明“更均衡”不是直接决定分数的指标。[原文 §4.3、表 3](https://arxiv.org/pdf/2606.00257v1#page=7)

## 当前代码影响复现的几个细节

### 权重还要平方

主实验对应的 YAML 默认 `sharpening: 2.0`。除均匀权重外，程序先对加入稳定项的分数平方，再归一化：

$$
w_t^{\rm code}=\frac{(s_t+\varepsilon)^2}
{\sum_{k\in\mathcal V}(s_k+\varepsilon)^2},\qquad t\in\mathcal V.
$$

$\mathcal V$ 是有效回答位置。若分母不大于阈值，代码回退到有效位置上的均匀分布。这与原文式 8 的线性归一化及逐分数稳定项占优的极限不完全相同。前面 $(1,1,2,6)$ 的例子在平方后变成 $(1,1,4,36)/42$，最后一项约 0.857，明显高于线性版本的 0.6。

这个处理会改变集中度，因此解释表 3 时需要保留实际 sharpening 配置。论文提到锐化可能影响退化，但没有给出锐化指数 1 与 2 的受控消融，不能将表中所有集中现象单独归因于 LoRA。[权重实现](https://github.com/rodlaf/tokenweighting/blob/d34239a0647c276530722480853757777119ec46/experiment/hf/token_weights.py)

### 训练步数与计算流程有版本差异

论文与公开 TeX 写 100 步，但当前 `qwen3-1.7b-base-math-deadline.yaml` 设置 **300 步**，七个实验文件继承该值，启动脚本没有覆写为 100。直接运行当前配置会使用三倍更新预算，而且余弦学习率计划也随总步数变化。缺少原运行的完整 resolved config 和日志，不能把 300 步结果当成表 2 复现。

代码名为 GRPO，具体损失是 $-\operatorname{mean}_i[A_i\sum_t w_{i,t}\log\pi_\theta(y_{i,t}\mid x_i,y_{i,<t})]$，没有 PPO 概率比裁剪或额外 KL 正则项。组内标准差使用 PyTorch 默认样本标准差，再 `clamp_min`，与论文写成 $\sigma+\varepsilon$ 的方式略有区别。这里使用的是 GRPO 风格优势，不能直接套用其他库默认 GRPO 的完整损失。

生成时切到 eval 模式，计算损失与额外隐藏状态时恢复 train 模式；配置的 LoRA dropout 为 0.05。额外开启适配器的隐藏状态前向使用新的 dropout 随机性，且不与第一次策略前向共享状态。若要复核残差信号与纯适配器参数变化的关系，这个随机性需要单独控制，本文没有测量其影响。

### 指标与边界位置

训练器累积四个微批的梯度，但写入每步日志的 `aux` 权重指标来自最后一个微批；奖励均值则覆盖四个微批。因而原始日志中的两种“每步均值”分母不同。跨日志平均也不等于汇总每个 token 后计算一次 Gini。

熵下降实现把张量最后一列设为零，之后才应用 mask。对提前结束的较短回答，它没有逐条把最后一个有效位置的熵下降明确置零，该位置可能与后面的 padding 位置熵作差。EOS 是否作为有效 token 还取决于 pad 与 EOS 是否为同一 ID。这些是重建权重诊断时应核对的边界条件，不能只实现论文的理想公式就假设逐位一致。
