# Insights Generator：批量执行轨迹诊断

从一批 agent 轨迹中提出并验证失败原因假设。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-05-20 |
| 类型 | 论文与系统 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

系统将跨轨迹诊断划分为发现线索和深入调查等角色，检查行为模式是否在不同任务组中重复出现。输出以自然语言解释发现，并附上对应证据。 [资料](https://arxiv.org/abs/2605.21347)

## 数据与评测

评测既检查报告的依据和细节，也观察采用报告后修改 agent 是否改善任务表现。这样将诊断质量与下游系统改进同时纳入比较。 [资料](https://arxiv.org/abs/2605.21347)

## 结果与公开范围

论文报告，人工专家依据报告修改执行框架后，相对未修改基线提高 30.4 个百分点。arXiv 首发为 5 月 20 日，Scale 目录记录为 6 月 4 日。 [资料](https://arxiv.org/abs/2605.21347)
