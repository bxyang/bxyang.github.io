# ROK-FORTRESS：语言与地域背景的安全评测

分别控制语言和地域背景，研究安全判断及过度拒绝。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-05-13 |
| 类型 | 合作基准 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

基准用英语与韩语、美国与韩国情境构成对照矩阵。在任务意图相同的条件下，分别替换语言和当地机构、实体等背景，从而观察两者的独立作用与交互。 [资料](https://arxiv.org/abs/2605.14152)

## 数据与评测

每个风险请求配有一个具有相近背景的正常用途请求，用于测量过度拒绝。输出由校准后的评审模型组依据专家编写的二元评分项判断。 [资料](https://arxiv.org/abs/2605.14152)

## 结果与公开范围

论文发现语言与地域背景的作用因模型而异，单纯翻译不能覆盖这些差异。项目公开一部分数据，结论对应英语与韩语这一组比较。 [资料](https://arxiv.org/abs/2605.14152)
