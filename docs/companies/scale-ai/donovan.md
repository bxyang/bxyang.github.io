# Donovan：公共部门 agent 平台

为公共部门提供知识接入、模型比较和专用 agent 部署。

| 项目 | 信息 |
| --- | --- |
| 时间 | 首发日期未确认 |
| 类型 | 产品 |
| 公司参与 | Scale 开发 |

## 工作内容

用户通过 Agent Factory 配置资料源、知识库、模型、任务说明和已有工具连接。产品与 Scale 的企业平台集成，将特定业务资料接入 agent 工作流程。 [资料](https://scale.com/donovan)

## 数据与评测

平台包含测试和评估功能，用于比较回答与模型性能，并提供不同任务的 agent 模板。公开页面展示知识检索、来源引用和模型比较等能力。 [资料](https://scale.com/donovan)

## 结果与公开范围

Donovan 以商业系统方式部署于客户环境。公开演示中的样例分数不作为独立模型基准；具体模型、资料权限及部署配置由项目决定。 [资料](https://scale.com/donovan)
