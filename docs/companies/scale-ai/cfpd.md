# CFPD：外交政策情境下的模型决策

比较语言模型在外交政策情境中的决策倾向。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-03-08 |
| 类型 | 合作论文与基准 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

研究与 CSIS 合作，由专家设计政策情境，并改变国家角色和背景条件，观察模型选择及其解释。任务覆盖升级、干预、合作与联盟等决策类型。 [资料](https://arxiv.org/abs/2503.06263)

## 数据与评测

基准包含 400 个基础情境，论文比较七个语言模型。评估重点是不同模型及国家设定下的选择分布，没有把每个外交决策简化为唯一正确答案。 [资料](https://arxiv.org/abs/2503.06263)

## 结果与公开范围

研究发现模型存在不同的决策倾向。公开数据集提供部分样本，完整任务范围与国家变体以论文说明为准。 [资料](https://arxiv.org/abs/2503.06263)
