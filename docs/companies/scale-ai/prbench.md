# PRBench：法律与金融专业推理

通过专家任务和细项标准评估专业回答。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-11-14 |
| 类型 | 论文与基准 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

任务由有实际从业经验的专家编写，要求模型结合背景条件完成法律或金融分析。每项回答按多条标准检查，覆盖推理、事实与专业要求。 [资料](https://arxiv.org/abs/2511.11562)

## 数据与评测

基准包含 1,100 个任务、19,356 条评分标准，182 名专家参与，覆盖多个国家和美国法律辖区。论文比较 20 个模型，并区分任务领域与难度。 [资料](https://arxiv.org/abs/2511.11562)
