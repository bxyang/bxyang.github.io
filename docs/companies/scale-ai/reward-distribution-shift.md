# 奖励模型在分布变化下的准确率与校准

分别改变提示和回答的分布，检查奖励模型评分的可靠性。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2023-11-21 |
| 类型 | 论文 |
| 公司参与 | Scale 研究团队发表 |

## 工作内容

奖励模型既用于人工反馈强化学习，也可在推理时判断回答是否符合目标行为。研究将提示变化与回答变化分开，测量模型准确率和置信度校准随分布变化的情况。 [资料](https://arxiv.org/abs/2311.14743)

## 数据与评测

实验使用分布内与分布外的提示及回答，比较两种变化造成的影响，并把分类中的分布外检测方法调整到奖励模型上。 [资料](https://arxiv.org/abs/2311.14743)

## 结果与公开范围

结果显示，奖励模型对回答分布变化比对提示变化更敏感，准确率与校准均可能下降。论文提供检测这类变化的方法和基线结果。 [资料](https://arxiv.org/abs/2311.14743)
