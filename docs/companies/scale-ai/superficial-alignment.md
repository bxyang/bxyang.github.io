# 重新检验表层对齐：后训练对格式、推理和知识使用的影响

## 0. 作者与机构背景

## 1. 摘要翻译

以下译自 [arXiv v1](https://arxiv.org/abs/2410.03717v1) 的完整摘要，原文采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可。

表层对齐假说认为，语言模型几乎所有的能力和知识都在预训练期间习得，而后训练只是让模型采用恰当的风格和格式。我们重新检验这些主张：随着微调样本数量增加，实证研究后训练的扩展规律，并使用客观、面向具体任务的标准化基准进行评估。

通过对 Llama-3、Mistral 和 Llama-2 系列中多个规模的模型开展实验，我们观察到，与预训练的扩展规律类似，后训练的任务表现也随微调样本数量呈幂律变化。这种幂律关系适用于多种能力，包括数学推理、编程、指令遵循和多跳推理。

此外，在数学和多跳推理等任务上，我们观察到，少量样本只是让模型在风格上对齐，并不能使基准上的表现达到饱和。模型表现与其推理能力相关，而且会随着样本增加而显著提高。这表明，除了衡量与人类偏好的对齐程度，还需要使用客观基准开展全面评估。

我们还观察到，语言模型未必只能使用预训练阶段学到的知识。通过适当的后训练，模型在多跳问答等下游任务中整合新知识的能力会大幅提高。综合来看，这些结果为表层对齐假说提供了新的认识，表明这一假说充其量是一种过度简化。

## 2. 研究背景与相关研究

LIMA 等研究发现，少量高质量示例就能让模型生成符合人类偏好的回答，由此提出后训练主要调整风格和格式的“表层对齐”解释。本文认为，这类聊天偏好评估未必足以说明模型在数学、编程或多步问答中的实际能力已经达到上限。

Introduction 将问题分为三个层面：增加后训练数据还能带来多大收益；提升来自格式变化还是任务能力；模型能否使用预训练之后的新知识。Related Work 则把本文放在对齐研究和扩展规律研究之间。此前扩展规律通常关注预训练 token 数、参数量和损失，本文关注的是模型开发者实际收集的任务示例数量，以及这些示例带来的下游表现变化。

因此，这项工作采用标准化任务指标，再配合回答错误分析，而不是仅依赖两个模型之间的偏好胜率。这里的“后训练”实验具体采用监督微调，不能直接当作对全部强化学习方法的验证。[原文第 1、6 节](https://arxiv.org/html/2410.03717v1)

## 3. 核心贡献

### 要解决的问题

论文检验“学会合适的回答方式”是否足以解释后训练的全部收益，尤其关注少量示例之后继续增加任务数据的作用。

### 核心方案

作者在多个 Llama 和 Mistral 基座模型上逐步增加监督微调数据，分别测试数学、编程、指令遵循和多跳问答。随后，他们把数学和问答中的错误拆成格式错误、推理错误等类别，观察哪些问题较早改善，哪些仍然随数据增加而减少。

研究还构建 **Facts100**，收集 100 个发生在所用模型预训练截止时间之后的新闻事件，为每个事件编写直接问题和多跳问题。作者先比较是否接受过推理后训练的模型，再通过事件微调或直接提供事件上下文引入新知识。这一区分使研究能分别观察“获得信息”和“使用信息回答问题”。

### 主要结论

在本文测试的数据范围和模型中，任务表现继续随示例数量增长，并可用幂律曲线描述。数学和多跳问答的格式问题在约 100 个示例后已大幅改善，但推理错误仍会随更多训练而减少。这说明，表面上已经像合格助手的回答，仍可能缺乏相应的任务正确性。

Facts100 的结果表明，先进行推理后训练有助于模型随后利用新知识。直接提供相关事件上下文时也能看到这一收益，但该设置使用的是完美检索的 Oracle RAG，不能直接推广到存在检索错误的实际系统；新知识的幻觉问题也没有被完全解决。

这些结果支持作者对表层对齐假说的修正：后训练的价值应同时通过任务正确性和风格偏好衡量。它们并不单独证明模型获得了与预训练完全无关的新推理机制；论文也承认，多任务之间的能力取舍及长期知识更新仍需进一步研究。[原文第 3—5、7 节](https://arxiv.org/html/2410.03717v1)
