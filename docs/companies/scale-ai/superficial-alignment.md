# 后训练数据规模与能力提升

检验增加微调样本是否只改变回答风格，还是也改善任务能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-09-27 |
| 类型 | 论文 |
| 公司参与 | Scale 研究团队发表 |

## 工作内容

研究逐步增加指令微调样本，在 Llama 2、Llama 3 和 Mistral 多个尺寸的模型上比较变化。评估使用客观任务基准，覆盖数学、代码、指令遵循和多跳推理。 [资料](https://arxiv.org/abs/2410.03717)

## 数据与评测

实验将少量示例带来的风格变化与更多数据带来的任务分数变化分开，还考察通过后训练引入新知识后，多跳问答表现是否改变。 [资料](https://arxiv.org/abs/2410.03717)

## 结果与公开范围

论文观察到任务性能随微调样本数呈幂律变化；少量样本能够调整风格，但未使数学和多跳推理表现饱和。作者据此重新讨论表层对齐假说。 [资料](https://arxiv.org/abs/2410.03717)
