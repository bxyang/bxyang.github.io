# 用图文定位数据预训练幻觉检测器

将图像回答中的错误定位为具体文本片段，并减少所需人工标注。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-08-30 |
| 类型 | 论文 |
| 公司参与 | Scale 研究团队发表 |

## 工作内容

方法将多模态幻觉检测表述为序列标注：检测器需要指出回答中哪些文字没有图像依据。研究利用已有短语与图像区域的对应数据，替换部分有依据的短语，生成用于预训练的错误文本。 [资料](https://arxiv.org/abs/2409.00238)

## 数据与评测

检测器先在构造的数据上预训练，再用人工标注数据微调。实验比较不同预训练信息和人工数据量，检查图文定位信号是否真正带来改善。 [资料](https://arxiv.org/abs/2409.00238)

## 结果与公开范围

论文报告该预训练方式改善后续微调的样本效率。主要输出是一种数据构造与检测训练方法，评测关注错误片段定位，而不仅是整段回答的二分类。 [资料](https://arxiv.org/abs/2409.00238)
