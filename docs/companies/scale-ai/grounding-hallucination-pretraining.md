# 幻觉检测预训练精读：替换图文定位短语，学习找出错误片段

一段图片描述可能前半句正确，后半句却补出了画面里不存在的物体。判断整段“有幻觉”还不够，检测器需要指出具体哪些文字有问题。这篇论文把任务改成逐 token 标注，并利用已有的图文定位数据制造训练样本：先找到有图像依据的短语，再让不看图的 T5 提议替换内容，把其中一部分作为模拟幻觉。

研究先用这些带噪声的样本训练检测器，再用人工标注的 M-HalDetect 微调。LLaVA-1.6 13B 在只有 500 条人工训练样本时，片段定位 macro F1 从 17.98 提高到 25.30；增加到 10,000 条时，两种训练方式都是 31.52。论文支持的是低标注量下的样本效率改善，并非所有规模下都有相同收益。[论文 §3–5、附录表 5](https://arxiv.org/pdf/2409.00238v1)

## 从给定片段分类，到自己找出片段

这项工作延续了 [M-HalDetect](/companies/scale-ai/m-haldetect) 的多模态幻觉研究，但改变了输入条件。此前的片段分类任务，会给模型一个已经划定边界的片段，让它判断该片段是否有图像依据。本篇的输入只有图像、问题和完整回答，片段起止位置也要由模型预测。

例如，作为**说明示例**，画面里只有一个人坐在长椅上，回答却说：“一个人坐在长椅上，旁边有两只狗。”给定片段分类可以直接检查“旁边有两只狗”；端到端检测还需要从整段回答中找出这串文字。漏掉边界、把正确描述一起圈进去，或者把一个错误片段拆成许多小碎片，都可能影响检测成绩。

论文选择二分类标签：非幻觉与幻觉。检测器对回答中的每个 token 给出标签，相邻标签相同的 token 合并成连续片段。它不使用预先提供的句子或人工片段作为输出边界，也不在推理时调用搜索、物体检测工具和另一个大模型来逐条审查主张。[论文 §2–3](https://arxiv.org/pdf/2409.00238v1)

这种输出可以为后续过滤或人工检查提供具体位置，但论文并没有进一步验证用它作奖励模型、回答重排序器后，生成模型的幻觉率下降多少。检测实验与减少最终回答幻觉的部署实验需要分开。

## 检测器的输入、输出与训练目标

作者使用 LLaVA-1.5 和 LLaVA-1.6 的指令微调权重，各测试 7B、13B 两个规模。模型接收图像、问题和待检查的回答，把原有的词表预测头换成标签预测头。其余架构保持原状；预训练和人工微调默认都冻结视觉编码器，更新其他参数。[论文 §3、附录 H](https://arxiv.org/pdf/2409.00238v1)

可以用下面的记号表达这一过程。设图像为 $I$、问题为 $q$、回答 token 为 $r_1,\ldots,r_T$，模型给第 $t$ 个回答 token 产生表示 $h_t$。标签头输出两个类别的概率：

$$
p_t=\operatorname{softmax}(g_\phi(h_t)),\qquad
\hat y_t=\arg\max_{c\in\{0,1\}}p_t(c).
$$

其中 0 表示非幻觉，1 表示幻觉，$g_\phi$ 是新标签头。若预测标签是 $0,0,1,1,1,0$，则得到一个三 token 的幻觉片段，以及左右两段非幻觉文本。这里的公式是对论文模型描述的展开，不表示作者公开了这一函数的完整实现。

附录 H 指明使用交叉熵训练。对参与监督的回答位置集合 $\mathcal T$，常见写法是：

$$
\mathcal L=-\frac{1}{|\mathcal T|}\sum_{t\in\mathcal T}\log p_t(y_t).
$$

训练希望正确标签的概率变高。与原本的下一个 token 预测不同，这里监督的是当前回答位置的类别；直接套用语言模型训练里的标签右移，会改变任务。原文没有公布具体的字符偏移到 subword 的映射、跨边界 token 的处理、输入中非回答位置的屏蔽实现，以及标签头的完整结构，因此这些仍是复现时要补齐的实现细节。

作者还试过 focal loss，希望处理预训练标签不平衡，但报告效果不如交叉熵。论文没有给出该尝试的具体分数和参数，不能把它写成充分搜索后的一般结论。[附录 H](https://arxiv.org/pdf/2409.00238v1)

## 图文定位数据怎样变成幻觉数据

### 起点是有依据的短语

图文定位数据把文本中的短语与图像区域联系起来。例如，一段房间描述中的“单人床”“电脑桌”“椅子”分别能在图中找到对应物体。本文不把这些框坐标直接当作幻觉标签，而是利用它们确定适合替换的文本位置。

作者使用 Grounded Visual Chat，简称 GVC。它来自 LLaVA-Grounding 的数据工作，图像源于 COCO，对话来自 LLaVA Visual Instruct 150K，使用自动流程建立图文对应关系。本篇只取每段对话的第一轮。附录 E.1 报告 121,909 个样本、449,144 个 grounded spans，平均每样本 3.684 个；实际用于构造预训练数据的是 **121,907 个样本**，少掉的两个样本原因没有说明。[附录 E.1](https://arxiv.org/pdf/2409.00238v1)

这里的“合成数据”也有层级区别：对话和图文匹配由自动流程生成，不意味着图像是生成图片，或上游完全没有人工工作。GVC 原始项目明确利用人工标注的物体检测数据和 GPT-4 的匹配能力。本篇新增的自动步骤是短语破坏与标签生成。[GVC 原始项目说明](https://llava-vl.github.io/llava-grounding/)

### T5 看文字、不看图

短语提议器使用 **T5-Base，约 220M 参数**。T5 本身支持文本填空，因此不需要给它设计复杂的指令或例子。它只看被遮住部分短语的文字上下文，不接收图像。

不看图的作用是让替换内容仍可能符合语言上下文，却失去原有视觉约束。例如，图片中“单人床”被替换成“两张沙发”，语句仍可以流畅，但图像不支持新物体。它只是提高生成幻觉的可能性，并不保证替换内容一定错误：同义词、宽泛描述或偶然与图片相符的提议仍会出现。[论文 §4、图 1](https://arxiv.org/pdf/2409.00238v1)

### 完整构造流程

附录 E.2 给出几个影响标签分布的关键概率。

| 步骤 | 具体设置 |
| --- | --- |
| 是否改写样本 | 以 0.95 的概率进入破坏流程；其余保留原文 |
| 遮住的位置 | 有图文定位标注的短语 |
| 生成限制 | 原短语中除停用词以外的 token，其生成概率置为 0，避免原样填回 |
| 采样 | 使用 multinomial sampling 产生替换提议 |
| 真正采用的提议 | 在所有提议中随机选择 75%–100% 替换，其他位置恢复原短语 |
| 片段标签 | 被替换的文字标为幻觉，其他部分标为非幻觉 |
| 扩展到整句 | 一个句子含替换片段时，以 0.5 的概率将整句标为幻觉 |

若一条回答有八个定位短语，进入破坏流程后会替换其中六至八个。这里的 75%–100% 是**短语数量比例**，不是回答 token 比例；0.95 是**样本被处理的概率**，也不是最终幻觉 token 占比。整句扩展又会进一步改变标签覆盖范围，因此不能把这几个数字直接当作正负类别比例。

整句扩展是为应对定位短语较稀疏、常为名词短语的问题。例如一长句只有一个物体名称被改写，只给该名称标红会产生很稀疏的监督。将整句标为幻觉能让训练中出现更长的连续错误片段，同时也会把句子里未修改的内容纳入正类，增加标签噪声。它是合成监督策略，不能理解为人工确认整句每个词都没有图像依据。

原文没有完整给出多项式采样的温度、最大填空长度、停用词表、随机种子，以及提议数量比例对应的取整细节。限制原 token 也不等于做了视觉验证或语义去重。[附录 E.2](https://arxiv.org/pdf/2409.00238v1)

## 预训练噪声的实际检查

附录 I.1 人工检查 50 个样本中的提议短语，归纳为四类。

| 提议类型 | 报告比例 | 含义 |
| --- | ---: | --- |
| 真正的幻觉 | 66% | 适合文字上下文，但与图像不符 |
| 语义匹配 | 10% | 新短语仍与图像匹配，基本保留原意 |
| 泛化表述 | 18% | 描述更宽泛、更模糊，未必构成明确事实错误 |
| 其他错误 | 6% | 非真实词、不连贯或其他异常 |

这个结果说明自动标为幻觉的提议有噪声。它不是在全量 121,907 条数据上计算的正确率；原文按“检查 50 个样本、分析其中短语”描述，没有进一步给出被判定短语总数和多位标注者一致性，不能直接将 66% 换算成全量语料的质量保证。

图 5 给出两种代表性问题：把有关滑雪装备的短语替换成“兴奋”，仍可能符合人物状态；把具体地点替换成“你看到的东西”，则变得宽泛而不一定错误。论文因此把这批数据用于预训练，再用人工标注校正，而没有宣称它能直接替代人工金标准。[附录 I.1、图 5](https://arxiv.org/pdf/2409.00238v1)

### 两阶段训练与比较预算

FT 基线从原有 LLaVA 指令权重开始，只做人工数据微调。PT+FT 从相同类型的权重开始，先在 121,907 条合成数据上预训练，再用相应数量的人工样本微调。两者使用相同的逐 token 标签任务。

| 项目 | 设置 |
| --- | --- |
| 基础模型 | LLaVA-1.5 7B/13B、LLaVA-1.6 7B/13B |
| 预训练 | 学习率 $10^{-6}$，3 个 epoch |
| 微调搜索 | 学习率 $\{2\times10^{-5},8\times10^{-6},2\times10^{-6}\}$；epoch 数 $\{3,6,12\}$ |
| Batch size | 128 |
| 优化器 | AdamW，动量参数 $(0.9,0.999)$，weight decay 为 0 |
| 学习率日程 | cosine，warmup ratio 为 0.03 |
| 上下文长度 | 2,048 |
| 训练硬件 | 8 张 NVIDIA A100，DeepSpeed ZeRO-3 |
| 默认冻结范围 | 视觉编码器冻结，其他参数训练 |

原文报告每种模型、数据规模下所搜索配置中的最佳结果，没有给出多随机种子均值、标准差或显著性检验。建立了验证集，但模型选择与最终 checkpoint 的完整程序未公开。不同曲线点也可能使用不同学习率和 epoch 数，不能理解为只增加数据、其余所有设置绝对相同。[附录 H、表 6–7](https://arxiv.org/pdf/2409.00238v1)

作为具体例子，LLaVA-1.6 13B 在 500 条时，FT 与 PT+FT 都用 $2\times10^{-5}$、12 epoch；在 1K 时，FT 仍用该设置，PT+FT 改为 $2\times10^{-6}$、12 epoch；在 10K 时，FT 用 $8\times10^{-6}$、6 epoch，PT+FT 用 $2\times10^{-5}$、6 epoch。样本效率比较在相同人工训练量上进行，但 PT+FT 多了合成数据和预训练计算，不能转写成同计算预算的优胜。

论文没有报告总 GPU 小时、A100 显存规格、T5 数据生成耗时、每项调参的实际搜索次数或经济成本。因此，减少人工训练样本不能直接换算为节约多少总费用。

## 片段定位怎样评分

论文的主要指标是 **IoU 阈值为 0.5 的片段 macro F1**，同时计算幻觉和非幻觉两类。它既检查类别，又检查位置。

设一个预测片段覆盖位置集合 $P$，一个人工片段覆盖位置集合 $G$，其交并比为：

$$
\operatorname{IoU}(P,G)=\frac{|P\cap G|}{|P\cup G|}.
$$

只有标签相同且达到规定重叠阈值的片段才能视为匹配。边界不必逐字符完全相同，因此能够容忍一部分标点和短小边界差异，但圈得太少或太多仍会失败。附录 F 将每个连续片段作为一个实例，而不是把每个词算作独立的检测命中。

对类别 $c$，令 $TP_c$ 为匹配片段数，$FP_c$ 为没有匹配的预测片段数，$FN_c$ 为没有被匹配的金标准片段数：

$$
F1_c=\frac{2TP_c}{2TP_c+FP_c+FN_c},\qquad
\operatorname{macroF1}=\frac{F1_0+F1_1}{2}.
$$

这两个公式是对论文文字指标的展开。macro 平均给两类相同权重，不因非幻觉片段更多就让它占据更大权重。报告中的 25.30 表示 $100\times\operatorname{macroF1}$，不是 25.30% 的词被分类正确，也不是 25.30% 的回答完全正确。[论文 §3、附录 F](https://arxiv.org/pdf/2409.00238v1)

用一个**说明示例**，真实幻觉长度为 10 个位置，预测完全位于其中但只有 4 个位置，则 IoU 为 0.4，无法通过 0.5 阈值。即使这 4 个位置的标签都正确，片段检测仍会漏掉该真实实例。若预测覆盖真实片段及外侧另外 6 个位置，IoU 为 $10/16=0.625$，则可以达到阈值。这解释了为什么仅靠零散关键词命中，很难获得高定位分数。

复现仍需明确字符还是 token 作为边界单位、严格大于还是包含阈值边界、匹配冲突的处理、空类别计分和跨样本累计方式。论文说明了同标签 IoU 匹配与 macro F1，但没有公开对应评分器，本文不把这些实现约定补写成已经验证过的代码事实。

## 主结果：收益主要集中在少标注数据时

下表完整整理附录表 5。所有数字均为检测 macro F1，单位为百分制；“差值”为 PT+FT 减 FT 的分数差。

| 模型 | 人工样本 | FT | PT+FT | 差值 |
| --- | ---: | ---: | ---: | ---: |
| LLaVA-1.6 13B | 500 | 17.98 | 25.30 | +7.32 |
| LLaVA-1.6 13B | 1,000 | 18.64 | 23.35 | +4.71 |
| LLaVA-1.6 13B | 10,000 | 31.52 | 31.52 | 0.00 |
| LLaVA-1.5 13B | 500 | 22.75 | 26.62 | +3.87 |
| LLaVA-1.5 13B | 1,000 | 20.96 | 25.89 | +4.93 |
| LLaVA-1.5 13B | 10,000 | 29.95 | 30.91 | +0.96 |
| LLaVA-1.6 7B | 500 | 23.75 | 26.46 | +2.71 |
| LLaVA-1.6 7B | 1,000 | 24.11 | 27.27 | +3.16 |
| LLaVA-1.6 7B | 10,000 | 29.97 | 30.75 | +0.78 |
| LLaVA-1.5 7B | 500 | 21.78 | 25.23 | +3.45 |
| LLaVA-1.5 7B | 1,000 | 19.38 | 26.18 | +6.80 |
| LLaVA-1.5 7B | 10,000 | 29.61 | 30.44 | +0.83 |

在 500 和 1,000 条人工样本下，四种模型的 PT+FT 都高于对应 FT；10K 时差距缩小，LLaVA-1.6 13B 完全相同。因此，比“预训练始终提升性能”更精确的表述是：**预训练在这组实验中主要改善低人工训练量时的定位成绩**。[附录 D、表 5](https://arxiv.org/pdf/2409.00238v1)

对 LLaVA-1.6 13B，500 条和 10K 条之间的差距从 $31.52-17.98=13.54$ 缩小到 $31.52-25.30=6.22$ 个分数点。它仍没有用 500 条达到 10K 条效果；不能据此写成“节省 95% 标注而不损失质量”。并且 979 条验证样本仍用于实验流程，500 只是模型微调的训练样本量。

曲线也不是单调上升的。例如两种 13B 的 PT+FT 都在 1K 点低于 500 点；未给出重复种子误差，无法判断这种局部回落来自数据子集、调参还是训练随机性。图的横轴虽然标了 5,000 刻度，实际报告的样本规模只有 500、1,000、10,000，不存在一个单独完成的 5K 实验点。

正文用“约 33%”概述最高成绩，但附录表 5 的最高值是 31.52。本文以可逐项核对的表格为准，不将“约 33%”作为另一项实验结果。

## 消融：定位位置、替换内容和训练阶段

### 随机遮文字会削弱预训练收益

Random Spans 保留 T5 填空，但不再使用图文定位短语：先随机选择句子，再从选中句子里随机抽取一个文本片段进行遮盖和替换。

图 3 中，这一版本在三个数据规模下都低于原方法，10K 时约为 27，而原方法为 31.52，也低于不预训练的 FT 基线。这里支持的是**按视觉定位选择破坏位置，对这套生成流程有效**。它没有单独证明检测器学到了某种内部视觉定位机制，因为随机片段还可能改变被遮文本的长度、语法类别和错误分布。[论文 §5.2、图 3、附录 E.2](https://arxiv.org/pdf/2409.00238v1)

### 随机词填空在低数据量下较弱

Random In-Fill 保留定位短语，但用 `wordfreq` 的 small 词表采样 1–5 个词作为替换，不使用 T5 提议。图 3 显示，在 500、1K 时明显弱于原方法；在 10K 时曲线接近原方法。

这说明在人工数据较少时，语言上下文较合理的替换比任意词拼接更有帮助。图中未给出该消融的完整数值表及置信区间，所以不为每个点补造两位小数，也不把作者的“显著”措辞自动转成已经进行统计显著性检验。[图 3、附录 E.2](https://arxiv.org/pdf/2409.00238v1)

### 先预训练，再人工微调，优于直接混合

附录 A 比较把合成数据直接加入人工微调集的 FT-Aug，与分成两个阶段的 PT+FT。

| 人工样本量 | FT-Aug | PT+FT |
| --- | ---: | ---: |
| 500 | 11.75 | 25.30 |
| 1,000 | 13.25 | 23.35 |
| 10,000 | 19.07 | 31.52 |

混合训练在表中明显较弱。作者认为可能与合成数据噪声、预训练和微调的分布差异有关，但没有分别操纵噪声比例和任务分布来分离原因，也没有完整公布混合采样比例及其搜索范围。因此，这项结果不能推成“任何数据混合都不如顺序训练”。[附录 A、表 1](https://arxiv.org/pdf/2409.00238v1)

### 只训练标签头不够

另一项消融在预训练阶段冻结基础模型，只更新标签头，然后再执行后续微调。

| 预训练可更新参数 | 500 | 1,000 | 10,000 |
| --- | ---: | ---: | ---: |
| 仅标签头 | 13.08 | 14.48 | 22.70 |
| 基础模型相关参数及标签头 | 25.30 | 23.35 | 31.52 |

第二行仍遵守默认视觉编码器冻结设置，“训练基础模型”并不表示所有视觉参数也更新。这项消融表明，本实验里让语言侧等可训练表示适应任务，比只拟合新输出头更有效。[附录 A、H、表 2](https://arxiv.org/pdf/2409.00238v1)

## 检测、给定片段分类与句子分类不能混用分数

附录 B 将检测器输出转换为给定片段分类：对一个预先给定的片段，取其 token 预测标签的多数票。边界已经由外部提供，因此不再承担相同的定位难度。指标也改成 **weighted F1**，按类别样本数加权，而非正文的定位 macro F1。

| 给定片段分类模型 | weighted F1 |
| --- | ---: |
| M-HalDetect 原 InstructBLIP 7B 分类器 | 83.22 |
| 本篇 LLaVA-1.5 7B FT 检测器改作分类 | 81.19 |
| 本篇 LLaVA-1.6 7B FT 检测器改作分类 | 81.16 |
| 本篇 LLaVA-1.5 13B FT 检测器改作分类 | 81.63 |
| 本篇 LLaVA-1.6 13B FT 检测器改作分类 | 81.58 |

这些是使用 10K 人工训练集的 FT 检测器。81.63 不是定位 F1，也不应与 31.52 相减并称为模型性能提升。原分类器和本文使用不同骨干，论文明确提示不能把这张表当作严格相同架构下的直接胜负比较。[附录 B、表 3](https://arxiv.org/pdf/2409.00238v1)

附录 C 又比较句子分类。作者尝试让 GPT-4 Turbo 和 GPT-4o 输出 token 级预测，但未能获得可靠结果，于是改为让模型判定每句是否含幻觉，并提供指令和一个上下文示例。检测器则用简单规则转换：句内只要有预测幻觉片段，就把该句标为含幻觉。

| 句子分类方式 | weighted F1 |
| --- | ---: |
| GPT-4 Turbo 提示 | 73.16 |
| GPT-4o 提示 | 79.57 |
| M-HalDetect 专用句子分类器 | 78.37 |
| LLaVA-1.6 13B PT+FT 检测器转换 | 74.60 |

检测器高于这组 GPT-4 Turbo 句子分类结果，但低于 GPT-4o；它的优势是同时能给出细粒度位置。该实验没有得到 GPT 的同任务定位成绩，不能写成检测器在端到端定位上击败 GPT-4o。[附录 C、表 4](https://arxiv.org/pdf/2409.00238v1)

## 定性结果与适用边界

附录图 6 和图 7 显示，预训练后有些预测从零散单词变成更连续的错误片段，这与片段 IoU 的评测目标相符。但图 8 也给出反例：PT+FT 只找到一段真实幻觉的小部分，FT 反而更接近完整位置。预训练改善的是整体表格结果，不保证每条回答都更准确。[附录 I.2](https://arxiv.org/pdf/2409.00238v1)

人工标注本身还存在边界噪声，例如是否把标点包括在错误片段里。论文引用 M-HalDetect 约 86% 的分类一致性估计，但那不等于本篇端到端定位任务的人类 F1 上限；本文没有测量这个上限。

实验只有一个主要人工下游数据集，回答主要由 InstructBLIP 产生，以英语图片描述为主。合成预训练则来自更广泛的对话问题，两者存在分布差异。没有跨数据集、跨回答生成器、跨语言或医学影像等专业领域的完整迁移实验。T5 只处理短语替换，也不能视为覆盖了所有事实错误、复杂推理错误及视觉关系错误。[论文 §7](https://arxiv.org/pdf/2409.00238v1)

## 复现需要补齐的内容

根据论文，可以重建“读取定位短语—T5 提议—概率替换—生成标签—预训练—人工微调—片段评测”的流程。但要逐项对齐表格，还需要作者未完整披露的几类信息：

- **数据实例**：实际 121,907 条 GVC 子集、第一轮筛选规则、少两个样本的原因、M-HalDetect 的 10K/979 与 500/1K 划分索引。
- **合成过程**：T5 精确权重版本、停用词与 token 禁用规则、全部采样参数、取整和随机种子、句子切分器及最终合成语料。
- **监督与评测**：四类原始标注到二类标签的映射、未标注字符处理、subword 边界规则、匹配器、空类别处理和 macro F1 累计方式。
- **训练记录**：专属检测器代码、最佳 checkpoint 选择规则、各搜索运行及重复种子结果、混合训练采样比例、资源消耗。

这些缺口限制的是对原始实验的精确复现；已经公开的论文仍给出了明确的方法流程和主要训练参数。本文完成全文、附录和上游资源核对，尚未复现模型结果。
