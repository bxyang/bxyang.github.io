# DrugDiscoveryBench：早期药物发现计算任务

评测 agent 使用科学工具和资料完成早期药物研究的能力。

| --- | --- |
| 时间 | 2026-06-30 |
| 类型 | 合作基准 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

任务涉及资料检索、分子信息读取和计算分析，运行于包含科研软件与数据的 Scale-Biomni 环境。评分由专家设计的加权 rubric 给出，重点检查结果及工作要求的满足情况。 [资料](https://scale.com/blog/drugdiscoverybench)

## 数据与评测

基准含 82 个任务、920 个评分项，环境提供 226 个功能。研究同时比较模型、推理预算和执行框架，并分析关键约束丢失及资料理解错误。 [资料](https://scale.com/blog/drugdiscoverybench)

## 结果与公开范围

Scale 与 Phylo 合作发布；公开仓库提供任务和运行环境，评分标准与参考答案通过需要申请访问的 Hugging Face 数据集提供。研究范围止于早期发现，不涵盖临床验证。 [资料](https://scale.com/blog/drugdiscoverybench)
