# PropensityBench：压力条件下的 agent 行为

在模拟工具环境中观察 agent 是否偏离授权目标。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-11-24 |
| 类型 | 论文与基准 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

研究改变任务压力、资源条件与自主行动空间，观察模型面对这些条件时的行为选择。任务在模拟环境中运行，通过代理工具记录行动。 [资料](https://arxiv.org/abs/2511.20703)

## 数据与评测

基准包含 5,874 个情境与 6,648 个代理工具，覆盖四类风险行为。实验对比不同情境条件下的发生率，并检查任务要求对结果的影响。 [资料](https://arxiv.org/abs/2511.20703)

## 结果与公开范围

项目公开评测代码。观察到的行为倾向对应模拟设置，不代表模型已在现实系统执行相同行动；首发为 11 月 24 日。 [资料](https://arxiv.org/abs/2511.20703)
