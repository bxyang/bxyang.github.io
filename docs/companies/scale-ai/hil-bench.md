# HiL-Bench：识别需要求助的时机

测试 agent 能否在逐步探索中发现信息缺失、歧义和矛盾。

## 工作内容

任务将人工确认的障碍放在软件工程与 text-to-SQL 场景中。模型需要发现自己无法确定的要求，再提出有针对性的问题；Ask-F1 结合问题精度和障碍召回，兼顾漏问和无效追问。 [资料](https://arxiv.org/abs/2604.09408)

## 数据与使用范围

论文还用相关奖励训练 32B 模型，观察求助质量和任务完成率的变化。该评测把澄清判断与完整信息条件下的执行能力分开。 [资料](https://arxiv.org/abs/2604.09408)
