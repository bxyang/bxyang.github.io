# RGSD：由评分标准指导的自蒸馏

本文介绍 [Rubric-Guided Self-Distillation: Post-Training Without Rubric Verifiers](https://arxiv.org/abs/2606.12507v1)，依据 2026 年 6 月的 arXiv v1。

## 1. 摘要翻译

以下译自 arXiv v1 的完整摘要，该版本采用 [CC BY 4.0 许可](https://creativecommons.org/licenses/by/4.0/)。

在没有唯一真实最终答案的开放式领域，评分标准已成为可验证奖励强化学习（RLVR）的一种替代方式。现有基于评分标准的训练方法依赖大语言模型验证器，依据标准为每次生成的回答打分。这会带来大量训练开销，使优化受到特定验证器偏差的影响，并将评分标准反馈压缩成在整段生成结束时才提供的稀疏信号。

我们提出评分标准引导的自蒸馏（Rubric-Guided Self-Distillation，RGSD），一种无需验证器的训练方法：以评分标准为条件的基础策略模型，担任未以这些标准为条件的学生模型的教师。RGSD 将教师在评分标准条件下的分布逐 token 蒸馏给学生，用密集的逐 token 学习信号替代稀疏的整段奖励，并从训练循环中完全移除大语言模型评审。

在医疗和科学领域的 Qwen-2.5（3B、7B）与 Qwen3-Thinking（4B、8B）模型上，RGSD 达到了与基于评审的 GRPO 相当的评分标准符合程度，同时每个问题只需要一次由当前策略生成的回答，训练时不调用验证器。消融分析表明，原始评分标准比模型自行生成的参考回答更能增强教师的指导信息；但在部分设置下，使用更强评审的 GRPO 能超过 RGSD。因此，当验证器的成本或可靠性成为瓶颈时，RGSD 是一种互补的、无需验证器的替代方案。

## 2. 研究背景与相关研究

基于评分标准的强化学习把回答质量拆成若干要求，再让模型评审逐项打分。这扩展了后训练可覆盖的任务，但每生成一份回答就需要评分，既增加成本，也可能让模型学会利用评分器的偏差。最终汇总为一个分数，还会丢失哪些具体生成选择值得学习的信息。

论文第 2 节回顾了 Rubrics as Rewards、动态标准生成等工作。它们主要把标准用于评价已经完成的回答。另一条路线是蒸馏：让学生学习教师的生成行为。MiniLLM、Generalized Knowledge Distillation 等方法在学生实际生成的文本上提供更细的指导；自蒸馏方法则让同一个基础模型在看到参考答案等额外信息后担任教师。

RGSD 结合了后两种思路。它不要求另找一个更大的教师，而是利用一个观察：同一基础模型看到问题对应的评分标准后，通常能更好地满足这些要求。作者尝试把这种有额外信息时的行为，转移到只看到问题的模型中。（原文第 1—2 节）

## 3. 核心贡献

RGSD 从同一个基础模型复制出教师与学生，训练期间教师保持不变。学生只接收问题，并生成一份回答；教师则接收问题、评分标准和学生已经写出的前文，在每个位置给出下一 token 的概率分布。学生据此逐步学习。这种做法直接提供细粒度生成指导，省去了先完成多份回答、再逐份评分的训练流程。（原文第 3 节）

它仍需要训练数据中的评分标准，也仍需要教师前向计算。“无需验证器”指训练循环不调用额外的评分模型，并不意味着训练完全不需要监督信息。测试学生时，只提供问题，评分标准不作为学生的作答输入。

在四个基础模型、医疗与科学两个领域中，RGSD 与论文主要 GRPO 对照取得了接近的标准符合程度，同时每个问题仅生成一次学生回答，训练时不调用评审。部分 Qwen-2.5 设置中，它还用更短的回答达到接近的评分；但这种长度变化并不在所有模型上相同。（原文第 4—5 节）

论文将 RGSD 定位为互补方法。若基础模型在看到标准后本来就没有明显改善，可供转移的信号也有限；若能承担更强评审的成本，GRPO 在某些设置下表现更好。因此，本文支持的是一种减少外部评分依赖的训练路线，没有证明它能够普遍替代基于验证器的强化学习。（原文结论与 Limitations）
