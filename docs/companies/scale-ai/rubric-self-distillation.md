# RGSD：由评分标准指导的自蒸馏

让读取评分标准的教师模型指导未读取标准的学生模型。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-06-10 |
| 类型 | 论文 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

方法使用同一个基础策略：教师额外获得 rubric，学生只接收任务。训练按 token 蒸馏教师分布，从而用密集反馈替代整段轨迹结束后的评分。 [资料](https://arxiv.org/abs/2606.12507)

## 数据与评测

实验使用 Qwen2.5 的 3B、7B 和 Qwen3-Thinking 的 4B、8B，在医学与科学任务上比较。每个提示只需要一条当前策略轨迹，训练中不调用额外评审器。 [资料](https://arxiv.org/abs/2606.12507)

## 结果与公开范围

研究得到与基于评审器的 GRPO 相近的 rubric 满足程度；较强 GRPO 评审器在部分设置中仍更好。方法适用于评审开销或可靠性限制训练的情况。 [资料](https://arxiv.org/abs/2606.12507)
