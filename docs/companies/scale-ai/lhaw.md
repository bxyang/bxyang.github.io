# LHAW：可控制的信息缺失任务

从完整任务中移除不同类型的信息，研究 agent 何时需要澄清。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-02-11 |
| 类型 | 论文与数据 |
| 公司参与 | Scale 研究团队发布 |

## 工作内容

生成流程沿目标、约束、输入和背景四个维度移除信息，并控制缺失程度。研究通过实际 agent 运行后的终态变化判断变体是否影响结果，而不只让模型主观判定任务是否含糊。 [资料](https://arxiv.org/abs/2602.10525)

## 数据与使用范围

公开 285 个变体，来源包含 TheAgentCompany、SWE-bench Pro 和 MCP-Atlas。变体的严重程度及澄清成本共同构成评测条件。 [资料](https://arxiv.org/abs/2602.10525)
