# CLIP 零样本推理的置信度校准

研究视觉语言模型的预测置信度与实际正确率是否一致。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2023-03-11 |
| 类型 | 论文 |
| 公司参与 | Scale 研究团队发表 |

## 工作内容

研究改变提示、测试数据集及模型架构，测量 CLIP 零样本分类的校准情况。方法在温度缩放的基础上调整校准过程，使其适应同一模型被用于不同任务和提示的设置。 [资料](https://arxiv.org/abs/2303.12748)

## 数据与评测

温度参数针对特定的预训练数据与模型架构学习，再迁移到不同测试数据集和文本提示。研究目标是校准预测分数，分类任务和模型本身保持各自的实验设置。 [资料](https://arxiv.org/abs/2303.12748)

## 结果与公开范围

实验发现原始 CLIP 零样本分数存在校准偏差，而针对单个模型学习的温度可以跨数据集和提示复用。论文提供了分析视觉语言模型置信度的实验依据。 [资料](https://arxiv.org/abs/2303.12748)
