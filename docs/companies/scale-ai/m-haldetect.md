# M-HalDetect：用局部反馈减少图像描述中的幻觉

## 1. 摘要翻译

以下译自该版本 Abstract；arXiv 原文采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可。

经过指令微调的大型视觉语言模型，在泛化到多种多模态任务方面取得了显著进展，尤其是在视觉问答任务上。然而，对这些模型而言，生成有图像依据的详细回答仍然具有挑战。我们发现，即使是当时最先进的视觉语言模型 InstructBLIP，其生成文本中仍有高达 30% 的幻觉内容，表现为不存在的物体、不忠实的描述以及不准确的关系。

为解决这一问题，我们提出 M-HalDetect，一个可用于训练和评测幻觉检测与预防模型的多模态幻觉检测数据集。M-HalDetect 包含对视觉问答样本的 1.6 万份细粒度标注，是首个面向详细图像描述的综合多模态幻觉检测数据集。与此前只考虑物体幻觉的工作不同，我们还标注不忠实的实体描述与关系。

为展示这一数据集在预防幻觉方面的潜力，我们提出细粒度直接偏好优化方法 FDPO，并用它优化 InstructBLIP。我们还基于 InstructBLIP 训练细粒度多模态奖励模型，并通过从 n 个候选中选择最佳回答的拒绝采样评估其有效性。我们对 FDPO 和拒绝采样都进行了人工评估，发现两者分别使 InstructBLIP 的幻觉率降低了 41% 和 55%。我们还发现，奖励模型可以泛化到其他多模态模型，分别使 LLaVA 和 mPLUG-OWL 的幻觉减少 15% 和 57%，并且与人工评估的准确率分数具有较强相关性。数据集发布于 [M-HalDetect 项目仓库](https://github.com/hendryx-scale/mhal-detect)。

## 2. 研究背景与相关研究

视觉语言模型可以为图片生成流畅、详细的解释，但语言流畅并不保证描述符合画面。一句话可能正确地提到骑摩托车的人，却同时捏造背景中的其他车辆。只对整段回答给一个分数，很难说明错误出现在哪里，也会把准确和不准确的信息混在同一条训练信号中。

论文的 Related Work 回顾了几个方向。LLaVA、InstructBLIP 等工作通过指令微调提升多模态任务能力；POPE 用关于物体是否存在的问题评估幻觉；LRV 数据集与 GAVIE 等工作则引入正负指令和自动评价。本文作者认为，除物体是否出现外，属性、相对位置和关系等描述同样需要检查。

在人类反馈学习中，RLHF 通常训练奖励模型，再用强化学习优化生成模型；DPO 则直接利用成对偏好调整模型。常见偏好数据告诉模型“哪一整份回答更好”，但不一定指出具体原因。已有细粒度反馈研究尝试把评价细化到句子或片段。M-HalDetect 将这一思路用于图像描述，让反馈直接对应回答中的局部事实，并进一步研究如何把这些标注用于检测与改进生成。[原文 Introduction、Related Work](https://arxiv.org/pdf/2308.06394v3)

## 3. 核心贡献

**核心要解决的问题。** 研究希望得到一种比整段评分更具体的多模态反馈：指出哪些描述有图像支持，哪些内容不准确，并验证这些标注能否实际减少模型输出中的幻觉。

**核心方案。** 作者从 COCO 中选取 4,000 张图片，为每张图片生成四份描述，形成 16,000 个图像、提示与回答样本。人工标注细化到句子内部的片段，区分准确、不准确和分析性内容，并允许标注不确定情况。这里单列“分析”，是为了区分可由画面核验的描述与主观概括。

基于这些标注，论文研究两种使用方式。第一种训练多模态奖励模型，判断句子或片段是否符合图像，再为多份候选回答评分，挑选幻觉较少的一份。实际候选筛选使用句子级模型；片段级检测实验假设已知片段边界，尚未解决自动定位所有错误片段的问题。

第二种是 FDPO。它不要求为同一个问题收集“较好回答—较差回答”对，而是将一份回答中的准确片段作为正向信号、不准确片段作为负向信号，并对中性内容作忽略等处理。模型由此直接学习提高准确片段的生成倾向、降低不准确片段的生成倾向。[原文 Dataset、Method](https://arxiv.org/pdf/2308.06394v3)

**结论。** 人工评估显示，FDPO 与候选筛选都能够降低所测试模型的幻觉。摘要报告的 InstructBLIP 幻觉率降低 41% 和 55%，是相对降幅，分别对应直接优化与从 64 份候选中筛选的结果；不是准确率提高了 41 或 55 个百分点。这里的幻觉率根据客观描述中不准确词语所占比例计算，排除分析性片段，不等于“出现任何错误的回答比例”。

奖励模型还可以用于筛选 LLaVA、mPLUG-OWL 的回答，说明从一个模型收集的细粒度反馈，在所测试条件下具有一定迁移能力。不过，筛选需要生成多份候选，增加推理成本；人工评估使用的是 50 张独立图片，主要任务是详细图像描述。因此，本文证明了局部标注对这一场景的检测和改进价值，尚不能将结果直接推广到所有多模态任务。论文也只完成了一轮反馈收集与训练。[原文 Evaluation、Results、Conclusion](https://arxiv.org/pdf/2308.06394v3)
