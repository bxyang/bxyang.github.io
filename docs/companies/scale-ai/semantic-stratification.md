# 检索评测的语义分层与覆盖

依据语料结构生成评测查询，检查平均分掩盖的覆盖缺口。

## 工作内容

方法把检索评估视为统计估计问题，先按实体等信息将文档组织成可解释的语义区域，再为缺少评测样本的区域补充查询。这样可以分别观察不同文档群的检索质量。 [资料](https://arxiv.org/abs/2604.20763)

## 数据与评测

研究跨多个基准和检索方法比较，分析评测集构建方式如何影响指标稳定性，并给出一定条件下的语义覆盖保证。 [资料](https://arxiv.org/abs/2604.20763)

## 结果与公开范围

实验发现汇总指标可能掩盖语料中的系统性薄弱区域；分层评测提高了结果的稳定性和可解释性。工作输出是评测集构造与分析方法。 [资料](https://arxiv.org/abs/2604.20763)
