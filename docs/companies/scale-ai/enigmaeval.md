# EnigmaEval：从非结构化谜题中寻找解题路径

## 1. 摘要翻译

以下按论文 v2 摘要完整翻译；原文采用 [CC BY 4.0 许可](https://arxiv.org/abs/2502.08859v2)。

> 随着语言模型掌握现有推理基准，我们需要新的挑战来评估它们的认知边界。解谜活动蕴含丰富而困难的多模态问题，能够测试多种高阶推理和知识能力，因此为评估前沿语言模型提供了独特试验场。
>
> 我们提出 ENIGMAEVAL，一个从解谜比赛和活动中收集问题与答案的数据集，用于考察模型整合隐含知识和进行多步演绎推理的能力。与现有推理和知识基准不同，解谜要求模型在看似无关的信息之间发现隐藏联系，从而找到解题路径。该基准包含 1,184 道复杂度各异的谜题，每道通常需要熟练解题者组成的团队花费数小时到数天完成，并具有明确、可验证的答案，便于高效评估。
>
> 先进语言模型在这些谜题上的准确率极低，甚至低于 Humanity’s Last Exam 等其他困难基准，揭示了模型面对需要非结构化思考和横向联想的问题时的不足。

## 2. 研究背景与相关研究

多数推理题会明确告诉解题者任务规则，而谜题活动中的题目往往只给出图像、文字和线索，连“该做什么”都需要自己发现。解题者既要理解各条信息，又要判断它们之间可能的联系，再逐步检验思路。

Introduction 将这一点作为对现有评估的补充。MATH、GPQA、HLE 等考察数学或专业知识，MMMU、MathVista 等包含视觉语言理解，ARC-AGI 关注抽象模式。已有谜题基准常围绕稳定的题型展开；EnigmaEval 则强调题面形式不固定、线索跨领域且解题规则隐含的任务。[论文 Introduction 与 Related Work](https://arxiv.org/pdf/2502.08859v2)

## 3. 核心贡献

### 核心要解决的问题

评估模型在缺少明确解题步骤的多模态材料中，发现规则、联结知识并完成较长推理链的能力。

### 核心方案

EnigmaEval 从八类谜题活动中整理 1,184 道题，按难度划分，并保存原始题面图像与人工整理的图文版本。两种形式用于观察文档解析和推理本身对表现的影响。多数答案是单词或短语，能够明确验证。

论文同时说明，为减少题解泄露进入训练数据，并尊重部分创作者的分发意愿，完整评估集保持私有。它不是把所有题目与解答公开下载的普通开放数据集。[论文数据集设计](https://arxiv.org/pdf/2502.08859v2)

### 结论

在论文当时的评估中，最佳模型 o1 在普通题子集达到 7.0% 准确率，在困难子集为 0%。这些结果表明，受测模型在非结构化谜题上仍有较大困难，不能根据其他推理基准的高分直接推断其解谜能力。

7.0% 属于特定版本、输入方式和难度子集，不是当前排行榜成绩。题目对文化知识和题型经验也有要求，因此分数同时反映多种因素；它不构成一个与知识背景无关的通用智力测量。论文用原始与整理题面对照探索输入影响，但并未完全分离所有视觉、知识和推理因素。[论文实验与相关研究](https://arxiv.org/pdf/2502.08859v2)
