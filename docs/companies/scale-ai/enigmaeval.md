# EnigmaEval：长流程多模态解谜

从解谜活动中整理需要隐含联系和多步推理的任务。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-02-13 |
| 类型 | 合作基准 |
| 公司参与 | Scale 与合作研究者发布 |

## 工作内容

题目结合多种信息，要求发现表面无关材料之间的联系，再推导明确答案。任务来源于解谜比赛与活动，人工解题团队通常需要较长时间完成。 [资料](https://arxiv.org/abs/2502.08859)

## 数据与使用范围

包含 1,184 道不同难度谜题及可验证答案。它考查非结构化和横向联想推理，与专业工作环境或教材问答有不同任务分布。 [资料](https://arxiv.org/abs/2502.08859)
