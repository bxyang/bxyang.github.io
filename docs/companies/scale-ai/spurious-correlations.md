# 后训练方法对数据伪相关的敏感性

比较监督微调与偏好优化在含有捷径特征的数据上的表现。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-05-09 |
| 类型 | 论文 |
| 公司参与 | Scale 研究团队发表 |

## 工作内容

研究人为控制训练数据中的伪相关，比较 SFT、DPO 和 KTO。两类数据问题分别为特征含义不明确，以及训练分布过窄，模型可能依赖与任务目标无关的线索。 [资料](https://arxiv.org/abs/2505.05704)

## 数据与评测

实验涵盖数学、带约束的指令遵循和基于文档的问答，并比较 10% 与 90% 的伪相关程度。各方法使用相应合成任务，观察任务与数据问题的组合如何影响泛化。 [资料](https://arxiv.org/abs/2505.05704)

## 结果与公开范围

较强伪相关经常降低表现，但影响并不一致。论文中偏好方法在部分数学任务较稳健，SFT 在复杂上下文任务上较好；结论依赖任务及伪相关类型。 [资料](https://arxiv.org/abs/2505.05704)
