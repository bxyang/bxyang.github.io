# 后训练与伪相关：SFT、DPO、KTO 在不同任务中的表现

## 1. 摘要翻译

以下译自 [arXiv v1](https://arxiv.org/abs/2505.05704v1) 的完整摘要，原文采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可。

监督微调和基于偏好的微调技术，已成为使大语言模型（LLM）与用户意图及正确性标准对齐的常用方法。然而，现实世界的训练数据往往存在伪相关：它们可能来自偏差、数据集中的人为痕迹，或其他“捷径”特征，并可能损害模型的表现或泛化能力。

本文在多种合成任务和伪相关条件下，系统评估了三种后训练算法：监督微调（SFT）、直接偏好优化（DPO）以及卡尼曼—特沃斯基优化（KTO）。任务涵盖数学推理、带约束的指令遵循，以及基于文档的问答。我们改变伪相关程度，比较 10% 与 90% 两种情况，并研究两类数据特征：“特征歧义”和“分布狭窄”。

结果表明，伪相关程度较高时，模型的表现往往会下降，但并非总是如此。基于偏好的方法（DPO/KTO）在数学推理任务中可能表现出相对较强的稳健性。相比之下，SFT 在复杂、依赖大量上下文的任务中保持了更好的表现。这些发现说明，没有一种后训练策略能在所有情形下都优于其他策略；最佳选择取决于目标任务的类型，以及伪相关的性质。

## 2. 研究背景与相关研究

训练数据中“经常与正确答案一起出现”的特征，不一定是答案正确的原因。例如，正确回答恰好总包含年份，模型可能学会添加年份，而没有学会依据文档回答问题。当测试数据不再遵循这个规律时，训练中看似有效的线索就会失效。

Introduction 和 Related Work 将这一问题放在两条研究脉络中。一条是 NLP 数据集中的捷径学习：已有研究发现，模型会利用词语模式等数据痕迹，在原始测试集上取得高分，却无法推广到变化后的输入。另一条是对齐中的过度优化：SFT、PPO、DPO、KTO 等方法虽然改善了模型回答，但也可能放大与偏好标签相关的表面特征，例如回答长度。

本文把关注点放在生成模型的后训练阶段：在明确控制伪相关种类和占比时，不同训练方法会受到怎样的影响。它比较既有算法，并构造用于检验它们的数据条件，没有提出新的训练目标。[原文第 1—2 节](https://arxiv.org/html/2505.05704v1)

## 3. 核心贡献

### 要解决的问题

研究关注的是：当训练数据混入不可靠的正确性线索时，SFT、DPO 和 KTO 能否仍然学到目标任务；这种能力是否随任务而改变。

### 核心方案

作者围绕文档问答、数学推理和带约束的指令遵循，构造两类数据变化。

- **特征歧义**：让正确回答与无关词语、日期或特定结尾一起出现，使模型难以区分真正的正确性依据和表面线索。
- **分布狭窄**：把训练中的正确答案限制在很小的范围，例如只出现 1—5 的数学答案，使训练数据不能覆盖实际任务。

每种设置分别采用 10% 和 90% 的伪相关数据占比，在 Llama 系列指令模型上比较三种方法，再用分布更广的任务检验正确性。数学和部分指令任务使用规则检查，开放问答则依赖模型评判。这样可以观察增加伪相关后的变化，而不只比较一组训练后的最终分数。

### 主要结论

在这些受控设置中，DPO 和 KTO 在数学任务上通常优于 SFT，而 SFT 在文档问答上整体更强。带约束的指令任务对多种方法都较困难。把伪相关占比从 10% 提高到 90% 经常损害表现，但也存在变化很小或有所改善的组合，因此不能把伪相关比例直接当作性能下降的统一预测指标。

作者认为，训练方式的选择需要结合任务和数据偏差类型。关于 SFT 可能更充分利用上下文、偏好优化可能更容易放大表面特征的解释，是对结果的分析，本文没有单独证明这些机制。研究范围是合成操控下的三类任务，也不能据此认定某一种算法在全部真实业务数据上更稳健。[原文第 3—6 节](https://arxiv.org/html/2505.05704v1)
