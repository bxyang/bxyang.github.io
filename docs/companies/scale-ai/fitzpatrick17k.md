# Fitzpatrick17k：皮肤图像与肤色分组评测

为皮肤病临床图像补充肤色标签，比较模型在不同分组上的分类表现。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2021-04-20 |
| 类型 | 合作论文与数据集 |
| 公司参与 | Scale 研究人员参与共同研究 |

## 工作内容

研究从两部在线皮肤病图谱整理临床照片，由人工标注团队添加 Fitzpatrick 皮肤类型标签。研究同时比较人工标签与基于图像颜色计算的 individual typology angle，用于观察两种肤色描述方式的一致性。 [资料](https://arxiv.org/abs/2104.09957)

## 数据与评测

数据集包含 16,577 张图像，分类任务涉及 114 种皮肤疾病。实验按训练资料和测试资料的皮肤类型分组，考察训练数据构成与分类准确率之间的关系。 [资料](https://arxiv.org/abs/2104.09957)

## 结果与公开范围

论文发现浅色皮肤图像的数量明显多于深色皮肤图像；模型在与训练数据皮肤类型相近的图像上表现较好。项目公开标注和代码，数据集用于研究分类模型的分组表现。 [资料](https://arxiv.org/abs/2104.09957)
