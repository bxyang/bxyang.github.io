# Remote Labor Index：完整远程工作项目

评测 agent 完成真实、有经济价值的远程工作项目的能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-10-28 |
| 类型 | 合作基准 |
| 公司参与 | Scale 与 Center for AI Safety 等合作 |

## 工作内容

任务采用完整项目要求及交付物，而不是把工作拆成孤立问答。agent 需要理解资料、执行多步工作并提交产物，评价依据项目要求和实际交付质量。 [资料](https://arxiv.org/abs/2510.26787)

## 数据与使用范围

首发实验中最高自动化率为 2.5%，对应当时的模型、工具和成功标准。该数字属于任务集合的通过比例，不是对整个劳动力市场的替代率估计。 [资料](https://arxiv.org/abs/2510.26787)
