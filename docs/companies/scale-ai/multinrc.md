# MultiNRC：母语编写的多语言推理评测

使用原生语言与文化情境中的题目评测多语言推理。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-07-23 |
| 类型 | 基准 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

题目由法语、西班牙语和中文母语作者编写，覆盖语言结构、文字游戏、文化知识与文化情境中的数学推理。任务不以英文题目逐句翻译为主要来源。 [资料](https://scale.com/blog/multinrc)

## 数据与评测

数据超过 1,000 题，筛选时保留至少使五个候选模型中的三个失败的题目。发布评测比较 14 个模型，并用人工检查核对自动评分。 [资料](https://scale.com/blog/multinrc)

## 结果与公开范围

项目提供数据与榜单，呈现模型在不同语言、任务类型中的差异。筛选过程主动保留难题，分数反映这一困难集合上的表现。 [资料](https://scale.com/blog/multinrc)
