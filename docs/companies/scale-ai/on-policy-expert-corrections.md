# OEC：沿学生轨迹进行专家纠正

让专家接手学生实际遇到的状态，制作更贴合学生错误的训练数据。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-12-16 |
| 类型 | 论文 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

方法先让学生模型执行任务，再由专家从其轨迹中的状态继续完成。通过筛选与监督微调，学生学习如何处理自己容易到达的困难状态。 [资料](https://arxiv.org/abs/2512.14895)

## 数据与评测

论文在软件工程任务中比较 OEC 与直接模仿专家轨迹，使用 7B 和 32B 模型，并在 SWE-bench Verified 上评估。对照实验分析纠正数据与普通示范数据的差别。 [资料](https://arxiv.org/abs/2512.14895)

## 结果与公开范围

作者报告两个模型相对基线分别改善约 14% 和 13%。这里是相对提升，且对应论文设置；方法仍需要专家模型与任务执行预算。 [资料](https://arxiv.org/abs/2512.14895)
