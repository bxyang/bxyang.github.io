# 目标条件化的语言奖励模型

让奖励模型学习当前生成步骤与未来目标状态之间的关系。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-07-18 |
| 类型 | 论文 |
| 公司参与 | Scale 研究团队发表 |

## 工作内容

训练通过对比目标，使偏好轨迹中的状态表示更接近其未来状态，并拉开与非偏好轨迹的距离。得到的表示既能评价回答，也能估计一条生成轨迹通向指定目标的可能性。 [资料](https://arxiv.org/abs/2407.13887)

## 数据与评测

实验包括 MATH、GSM8K 和 Helpful-Harmless，分别考察数学正确性与一般对齐。论文还用模型提前筛除可能失败的轨迹，或引导回答满足有帮助、较复杂等目标。 [资料](https://arxiv.org/abs/2407.13887)

## 结果与公开范围

作者报告奖励模型 AUROC 最多提高 0.09，在多数投票实验中最多筛去 55% 的生成 token。不同数字对应不同实验，论文分别提供任务和控制条件。 [资料](https://arxiv.org/abs/2407.13887)
