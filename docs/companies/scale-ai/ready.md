# READY：可靠性、人工监督与运行成本

在指定可靠性目标下测量 agent 所需的人工审核和运行成本。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-09-02 |
| 类型 | 论文与评测框架 |
| 公司参与 | Scale 研究团队发布 |

## 工作内容

框架保留各工作流自己的成功定义，在候选监督策略中选择满足可靠性目标、成本最低的方案，再用保留案例进行统计检验。输出包含可靠性、人工审核负担和成本，而不只有自主完成率。 [资料](https://arxiv.org/abs/2609.02095)

## 数据与使用范围

临床审查案例涉及 16 个系统和 750 个病例。两个自主准确率接近的系统，达到同一目标所需人工审核比例可能不同；论文提供可拆分工作流、执行和检验的测试框架。 [资料](https://arxiv.org/abs/2609.02095)
