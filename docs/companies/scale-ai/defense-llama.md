# Defense Llama：公共部门领域模型

基于 Llama 3 调整领域知识与写作方式的专用模型。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-11-04 |
| 类型 | 合作模型 |
| 公司参与 | Scale 与 Meta、领域专家合作 |

## 工作内容

Scale 通过 Data Engine 制作微调资料，在 Llama 3 基础上调整模型。公告列出的资料包括领域规范、国际人道法和相关政策，并使回答风格符合特定公共部门的报告要求。 [资料](https://scale.com/blog/defense-llama)

## 数据与评测

模型通过 Donovan 在受控的美国政府环境中提供，面向领域问答、文件分析和决策支持。公告未披露参数规模、完整训练集或统一公开测试结果。 [资料](https://scale.com/blog/defense-llama)

## 结果与公开范围

发布范围为特定政府环境中的集成服务；底座采用 Llama 3，并不意味着这个微调版本已公开权重。 [资料](https://scale.com/blog/defense-llama)
