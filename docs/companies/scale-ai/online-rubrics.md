# 在线生成评分标准的强化学习

根据当前模型与参考回答动态生成训练用评分标准。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-10-08 |
| 类型 | 论文 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

方法在训练期间比较当前策略的回答与参考回答，再为这组回答生成具体评审标准。奖励因此随模型的实际错误和回答变化更新。 [资料](https://arxiv.org/abs/2510.07284)

## 数据与评测

实验覆盖通用指令遵循与知识推理，使用 AlpacaEval、GPQA 和 Arena-Hard 等评测，并加入专家验证。作者比较静态标准与在线标准的训练效果。 [资料](https://arxiv.org/abs/2510.07284)

## 结果与公开范围

论文报告在线生成标准在若干任务上取得改善。评分依赖标准生成模型和参考回答，实验结论对应论文中的模型与训练预算。 [资料](https://arxiv.org/abs/2510.07284)
