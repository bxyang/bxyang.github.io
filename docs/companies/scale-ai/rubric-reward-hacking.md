# Rubric 强化学习中的奖励偏离

区分评分器误判与评分标准本身遗漏造成的质量偏差。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-05-12 |

| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

研究用一个评分器提供训练奖励，再由三个不同模型系列的评审器评价。它将训练评分器错误给分，与评分标准未覆盖重要质量要求这两类问题分开。 [资料](https://arxiv.org/abs/2605.12474)

## 数据与评测

实验覆盖医学与科学问答。分析包括复合标准只满足一部分、隐含内容被当成明确回答，以及主题大致相关却未达到要求等评分偏差。 [资料](https://arxiv.org/abs/2605.12474)

## 结果与公开范围

更强评分器减少了部分错误奖励，但未消除标准设计遗漏。作者还提出不调用评审器的自内化差距指标，用策略的对数概率变化辅助识别训练停止带来实质进步的时点。 [资料](https://arxiv.org/abs/2605.12474)
