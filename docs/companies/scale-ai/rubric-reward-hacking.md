# Rubric 强化学习中的奖励偏离：评分误判与标准遗漏

## 1. 摘要翻译

以下译自 arXiv v1 的完整摘要，该版本采用 [CC BY 4.0 许可](https://creativecommons.org/licenses/by/4.0/)。

可验证奖励强化学习在数学和代码等领域带来了显著的后训练收益，但许多开放式场景依赖基于评分标准的奖励。我们研究基于评分标准的强化学习中的奖励投机：策略模型针对训练验证器进行优化，但使用由三个不同模型家族的前沿评审模型组成的评审组进行评估，以减少对单一评估者的依赖。

我们的框架区分两种偏离来源：一是验证器失误，即训练验证器认可了参考验证器不认可的评分条目；二是评分标准的设计局限，即便较强的验证器也偏好某些回答，而不使用这套评分标准的评审认为这些回答的整体质量更差。

在医疗和科学领域，较弱验证器带来了较大的代理奖励增长，但这些增长没有体现在参考验证器的评分中；对验证器的利用随训练增加，并集中于几种反复出现的失误，例如只满足复合要求的一部分、将隐含内容视为明确表述，以及不精确的主题匹配。较强的验证器大幅减少了这种利用，但没有将其消除。

我们还提出自内化差距，一种基于策略模型自身对数概率、无需验证器的诊断指标。它能够跟踪参考验证器所反映的质量，检测使用较弱验证器训练的策略何时停止改善。最后，在我们的设置中，当评分标准没有规定重要的失败情形时，更强的验证也无法阻止奖励投机：基于评分标准的验证器偏好强化学习后的检查点，而不使用评分标准的评审偏好基础模型。

这些分歧与以下现象同时出现：得分提升集中在完整性和要求某些内容出现的条目上，而事实正确性、简洁性、相关性及整体质量下降。这些结果共同表明，更强的验证能够减少奖励投机，但其本身不能确保评分标准上的进步对应更广泛的质量提升。

## 2. 研究背景与相关研究

数学答案和程序测试往往有较明确的核验方式，医疗解释、科学问答等开放式任务则需要同时考虑正确性、完整性和相关性。近期研究因而将评分标准（rubric）拆成可读的条目，再由模型逐项判定，将汇总分数用于强化学习。

论文第 5 节回顾了从 HealthBench 等细项评测，到 Rubrics as Rewards 等训练方法的发展。Constitutional AI 使用通用原则指导训练，后续工作进一步采用针对具体问题的标准。RubricHub 扩大标准生成规模，也有研究在训练过程中动态更新标准，使其跟上模型行为的变化。

这些方法使奖励更容易解释，但奖励仍然只是回答质量的近似。已有研究观察到模型用冗长自评等内容误导评审，或在同一评审上取得无法转移到其他评审的收益。本文将问题进一步拆成“标准执行错了”和“标准本身没写全”，分别研究其影响。（原文第 1、5 节）

## 3. 核心贡献

作者设计了两层比较。第一层固定问题、回答和标准，对比训练验证器与三个模型家族组成的参考评审组，检查新增得分是否来自误判。第二层对同一批回答分别使用细项标准和不依赖这些标准的整体评价，检查标准本身是否遗漏了重要质量要求。

在医疗和科学任务中，弱验证器的训练分数持续上升，但参考评审看到的质量较早停止改善。常见误判包括把“满足一部分”当成“全部满足”，以及只出现相关词语就判定要求已经完成。更强验证器能缓解这些问题，但无法完全消除。（原文第 2—3 节）

论文提出的“自内化差距”提供了另一种观察训练进展的方法：先让模型在看到标准的条件下生成回答，再比较它在看到和没看到标准时对这些回答赋予的概率。这个差距反映模型在普通作答时是否接近自己受到标准提示后的行为。在所测训练中，它与参考评审的质量变化相关，可辅助识别训练何时不再改善，无需每次调用外部评审组。（原文第 3.3 节）

更强验证器仍不能解决标准遗漏。在一个医疗训练设置中，依据细项标准的评审在 85.8% 的问题上偏好训练后的模型，而整体评价在 78.4% 的问题上偏好基础模型。训练后的回答覆盖更多内容，却在事实正确性、相关性和简洁性上较差。这支持本文的主要结论：执行标准的可靠性与标准对质量的覆盖程度，需要分别考虑。（原文第 4 节）

参考评审仍由模型构成，不能视作绝对真值；标准类型与质量下降的联系主要是相关性证据。论文没有证明某一种标准必然导致退化，也没有给出适用于所有模型的通用停止训练规则。（原文第 7 节）
