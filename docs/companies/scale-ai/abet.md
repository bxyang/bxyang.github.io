# AbeT：分布外输入检测

使用学习到的温度与能量分数识别偏离训练分布的输入。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-01-22 |
| 类型 | 论文 |
| 公司参与 | Scale 研究团队发表 |

## 工作内容

Ablated Learned Temperature Energy 从分类模型内部计算分布外检测信号。方法只使用分布内样本进行显式训练，并分析训练中被错分的样本如何帮助模型形成检测能力。 [资料](https://arxiv.org/abs/2401.12129)

## 数据与评测

实验覆盖图像分类、物体检测和语义分割。分类实验报告，在真正率固定为 95% 时，假正率相对所比较方法下降 43.43%；检测和分割另用各自指标评估。 [资料](https://arxiv.org/abs/2401.12129)

## 结果与公开范围

该方法在推理时不需要额外反向传播，也不依赖多阶段训练。输出用于判断预测是否遇到陌生数据，研究同时展示对检测框和像素的应用。 [资料](https://arxiv.org/abs/2401.12129)
