# 视觉训练数据规模与人工标注研究综述

梳理大规模视觉数据、预训练和合成数据对模型表现的影响。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2021-07-31 |
| 类型 | 综述论文 |
| 公司参与 | Scale 研究团队发表 |

## 工作内容

论文整理使用远大于 ImageNet 的数据集进行视觉训练的研究，比较增加训练数据与改进训练算法这两条路径。它还讨论合成数据、双下降现象，以及持续学习与离线大规模训练的关系。 [资料](https://arxiv.org/abs/2108.00114)

## 数据与评测

这是一篇研究综述，依据已有视觉任务和数据集的实验归纳结论，没有发布一套新的统一排行榜。所讨论的数据涵盖人工标注的真实图像与生成的合成图像。 [资料](https://arxiv.org/abs/2108.00114)

## 结果与公开范围

作者认为，已有优化和合成数据方法能够减少部分数据需求，但当时的证据仍显示真实人工标注数据对提升性能具有作用。该判断对应 2021 年的研究范围。 [资料](https://arxiv.org/abs/2108.00114)
