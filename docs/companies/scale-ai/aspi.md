# ASPI：澄清交互中的提示注入风险

在匹配任务中比较直接执行和先澄清两种 agent 状态。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-05-17 |
| 类型 | 基准 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

研究保持任务内容相近，一组 agent 接收完整指令后执行，另一组先请求补充信息再行动。测试由此考察进入澄清状态后，模型处理外部内容的方式是否变化。 [资料](https://arxiv.org/abs/2605.17324)

## 数据与评测

基准包含 728 个任务与攻击场景，评测十个模型。分析区分交互状态的影响和输入通道的影响，避免把两者合并为一种解释。 [资料](https://arxiv.org/abs/2605.17324)

## 结果与公开范围

被测模型在澄清状态下的提示注入成功率普遍上升。论文公开数据与代码，用于研究交互式 agent 的防御能力。 [资料](https://arxiv.org/abs/2605.17324)
