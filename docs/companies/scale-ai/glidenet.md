# GlideNet：结合全局与局部信息预测属性

使用三路视觉特征识别不同类别物体的细粒度属性。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2022-03-07 |
| 类型 | 合作论文与模型 |
| 公司参与 | Scale 与高校研究人员共同发表 |

## 工作内容

模型分别提取整幅图像的全局信息、目标周围的局部信息，以及目标自身的特征。第三路使用 Informed Convolution 处理像素较少的目标，再通过类别嵌入和门控机制组合三路表示。 [资料](https://arxiv.org/abs/2203.03079)

## 数据与评测

实验使用 VAW 和 CAR 两套属性数据。输出标签随物体类别调整，避免为某类对象预测不适用的属性；分析尤其关注小目标和依赖场景上下文的属性。 [资料](https://arxiv.org/abs/2203.03079)

## 结果与公开范围

论文报告平均召回率相对所比较方法提升超过 5%，并在训练数据较少的设置中评估表现。GlideNet 延续了 CAR 对物体属性的研究方向。 [资料](https://arxiv.org/abs/2203.03079)
