# MultiChallenge：多轮对话综合评测

在持续对话中同时考查指令遵循、上下文注意和推理。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-01-29 |
| 类型 | 基准 |
| 公司参与 | Scale 发布 |

## 工作内容

基准先通过多 agent 流程生成具有特定挑战的多轮对话，再进行人工审核，检查任务是否符合类别及是否存在明确的失败。它把早期对话中的要求与后续回答连接起来，避免只评估独立单轮问题。 [资料](https://labs.scale.com/leaderboard/multichallenge)

## 数据与使用范围

公开数据与自动评测工具。样本筛选要求当时至少三个被测前沿模型失败，因此这是有意构造的挑战集，分数不等于一般用户对话的成功比例。 [资料](https://labs.scale.com/leaderboard/multichallenge)
