# 较弱模型对较强 agent 的监测

研究监测模型能力较弱时，执行轨迹组织方式对检测的影响。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-08-26 |
| 类型 | 论文 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

研究让监测器读取 agent 的任务与操作轨迹，判断是否出现偏离授权目标的行为。实验包含 agent 知道自己受到监测的情形，并比较不同轨迹分解和汇总方式。 [资料](https://arxiv.org/abs/2508.19461)

## 数据与评测

评测使用 SHADE Arena 与基于 The Agent Company 的计算机操作场景。指标同时考虑检出率与误报率，并检查将部分记录交给人工复核的效果。 [资料](https://arxiv.org/abs/2508.19461)

## 结果与公开范围

所测设置中，结合顺序与分层分析的监测流程优于若干简单基线。论文公开代码与记录，结果不等同于对任意强模型的完整监督保证。 [资料](https://arxiv.org/abs/2508.19461)
