# 语言模型对生物学新手任务表现的影响

比较新手使用语言模型与仅使用互联网时的任务表现。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-02-26 |
| 类型 | 合作实验论文 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

研究围绕八组具有双重用途的计算生物学任务，设置语言模型辅助组和仅互联网组，并在部分任务中加入专家及模型独立完成的对照。评估对象是人机协作后的实际表现。 [资料](https://arxiv.org/abs/2602.23329)

## 数据与评测

被试有较充足的作答时间，最复杂任务最多允许 13 小时。论文报告模型辅助新手的准确率为对照组的 4.16 倍，95% 置信区间为 2.63—6.87。 [资料](https://arxiv.org/abs/2602.23329)

## 结果与公开范围

在有专家基线的四项评测中，辅助新手在三项上超过仅使用互联网的专家；独立模型也经常超过辅助新手。结果限于计算任务，研究未验证实验室中的实际操作能力。 [资料](https://arxiv.org/abs/2602.23329)
