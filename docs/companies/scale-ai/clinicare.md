# CliniCARE-Bench：电子病历审查

在纵向病历中查证临床审查结论，并区分缺失证据和医学歧义。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-08-07 |
| 类型 | 合作基准 |
| 公司参与 | Scale 研究团队与合作研究者发布 |

## 工作内容

基于 MIMIC-IV 的资料，将 25 个临床场景实例化为 750 个病例。agent 使用有记录的工具检索病历、计算和查询规则，输出肯定、否定、资料不足或医学歧义四类结论。 [资料](https://arxiv.org/abs/2608.07796)

## 数据与使用范围

评价同时包括结论、证据、规则使用和过程遵循。16 个系统的原始准确率与无违规捷径准确率不同；任务是回顾性病历审查，不是前瞻性临床试验。 [资料](https://arxiv.org/abs/2608.07796)
