# GSM1k：检查数学评测中的数据污染

重新编写与 GSM8K 难度相近的应用题，比较模型对新旧题目的表现。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-05-01 |
| 类型 | 基准 |
| 公司参与 | Scale 发布 |

## 工作内容

研究邀请具备数学和相关专业背景的标注者制作新题，通过复核、独立解题和质量审计检查答案及难度。将模型在新题与 GSM8K 上的表现对照，用于研究公开题目熟悉度与实际推理能力的差别。 [资料](https://labs.scale.com/leaderboard/math)

## 数据与使用范围

早期榜单介绍 1,000 题及 50 题公开样本。榜单还使用人工提取最终答案，论文则使用自动评分；两种设置的分数存在差异，正文不将它们混合。 [资料](https://labs.scale.com/leaderboard/math)
