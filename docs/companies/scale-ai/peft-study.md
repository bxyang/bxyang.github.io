# 参数高效微调方法的统一比较

在相同模型和任务条件下比较不同微调方法的数据效率及收敛表现。

## 工作内容

研究以 FLAN-T5 为基础，在分类和生成任务中改变训练数据规模，比较参数高效微调与全量微调。实验还调整训练哪些模型部分，寻找参数量更少而效果相近的配置。 [资料](https://arxiv.org/abs/2304.14999)

## 数据与使用范围

论文发现低数据条件下，部分 PEFT 方法收敛比全量微调慢。研究提供按任务和数据条件选方法的证据，没有把参数更少等同于总训练成本必然更低。 [资料](https://arxiv.org/abs/2304.14999)
