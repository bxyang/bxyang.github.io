# 合成数据策略的成本与效果

比较扩写答案、改写问题和生成新问题三种数据扩充方式。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-09-29 |
| 类型 | 论文 |
| 公司参与 | Scale 研究团队发布 |

## 工作内容

研究固定种子指令集合与教师模型查询预算，分别制作不同合成训练集，再训练学生模型。查询预算相对种子数据较少时，新增答案往往更有效；预算增大后，新问题能提供更多覆盖。 [资料](https://arxiv.org/abs/2409.19759)

## 数据与使用范围

结论强调预算与种子集的比例，而非某种策略始终更优。论文还考察验证合成数据和选择生成模型等条件，形成按资源配置比较的方法。 [资料](https://arxiv.org/abs/2409.19759)
