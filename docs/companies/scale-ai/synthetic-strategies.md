## 1. 摘要翻译

以下译自 [arXiv v3](https://arxiv.org/abs/2409.19759v3) 的完整摘要，原文采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可。

随着大语言模型（LLM）被用于更多场景，为微调构建高质量、面向具体任务的数据集，成为模型改进的瓶颈。使用高质量人工数据是提升模型表现最常见的方式，但在许多情形中成本过高。生成合成数据或混合数据等替代方法也已出现，不过，这些方法的有效性仍不清楚，尤其是在资源受限的情形，以及不容易验证的任务中。

为研究这一问题，我们将各种合成数据生成策略归纳为三类代表性方法：答案增强、问题改写和新问题生成，并研究学生语言模型在不同约束下接受训练后的表现，这些约束包括种子指令集大小和查询预算。我们证明，这些策略在不同设置中的有效性并不相同。

值得注意的是，最佳数据生成策略强烈依赖于可用教师模型查询预算与种子指令集大小之间的比值。当这一比值较低时，为已有问题生成新答案最有效；随着比值增加，生成新问题成为最优策略。在所有任务中，我们发现，相比数据量较大的情形，增强方法及其他设计选择在低到中等数据量时重要得多。

我们提供了一个实用框架，帮助在不同设置下选择合适的增强方法，同时考虑各方法的扩展能力、验证合成数据的重要性，以及使用不同语言模型生成合成数据等额外因素。

## 2. 研究背景与相关研究

合成数据已经被用于数学推理、代码生成和指令遵循。它可以从少量示例出发，让较强模型生成训练材料，再用于较小模型的监督微调。但不同工作同时改变了数据数量、生成方式、过滤规则和模型，很难直接比较哪种方法更划算。

Introduction 和 Related Work 将本文重点放在受限资源下的选择：手中已有多少任务问题，还能负担多少次模型调用。此前不少研究关注单个领域，或者在较大规模上追求最终分数；本文比较不同任务与预算条件下的效果，尤其包括答案不容易自动验证的任务。

这里的成本主要按模型调用次数近似计算，不是完整的 API 账单。实际费用还会受到输入输出长度、模型价格、验证和训练开销的影响。[原文第 1—2、5.2 节](https://arxiv.org/pdf/2409.19759v3)

## 3. 核心贡献

### 要解决的问题

在只有有限种子问题和生成预算时，应继续为原问题补充回答，还是把预算用于扩大问题覆盖。

### 核心方案

作者比较三种方式，并用生成的数据监督微调学生模型：

- **答案增强**：保留原问题，生成不同的解释与回答。
- **问题改写**：保留问题含义和答案，改写提问方式，再生成回答。
- **新问题生成**：以种子为参照，生成具有不同答案的新问题，再生成对应回答。

研究在数学、SQL 和科学问答上改变种子集大小与调用预算。主实验不假定已有人工标准答案；后续验证分析才在特定任务中额外使用标准答案进行筛选。生成新问题与仅改写问题也被分开，以观察增加内容覆盖和改变表达方式的差别。

### 主要结论

当可用调用次数相对于种子问题较少时，直接补充答案往往更有效：有限资源首先用于已有问题的训练信号。随着每个种子可分配的预算增加，生成新问题通常更有优势，重复围绕原题采样的收益逐渐减小。切换位置随任务和种子集变化，不能写成统一预算阈值。

生成新问题更依赖生成模型的能力，而改写问题对较弱模型更宽容。在本文的 SQL 验证实验中，筛选正确回答的额外收益不明显；这一局部结果并不意味着所有合成数据都不需要验证。

本文贡献的是一套比较数据策略的框架。结论来自有限任务、教师与学生模型，仍需结合目标数据和实际成本检验。[原文第 3—6 节](https://arxiv.org/pdf/2409.19759v3)
