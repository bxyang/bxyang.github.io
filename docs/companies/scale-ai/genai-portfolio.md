# Scale GenAI Portfolio：企业 agent 平台

接入企业资料，构建、运行和持续评测工作 agent。

## 工作内容

平台将企业数据连接、agent 编排、监测和模型改进结合。它支持从 Confluence、SharePoint、S3 等来源接入资料，并运行长时间、异步和多 agent 工作流程。 [资料](https://scale.com/genai-portfolio)

## 数据与评测

评测结合自动化评分、人工反馈和执行轨迹，业务运行中产生的问题可转成后续训练信号。官网说明支持在客户 VPC 内部署，并接入不同云服务与模型。 [资料](https://scale.com/genai-portfolio)
