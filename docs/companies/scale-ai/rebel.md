# REBEL：结合多项标准的检索重排序

在相关性之外加入回答所需的其他标准，改善 RAG 的文档排序。

## 工作内容

REBEL 根据用户查询推导重排序标准，例如信息时效、来源可靠性和观点覆盖。方法可以一次完成评分，也可以先生成针对查询的评分说明，再据此排序文档。 [资料](https://arxiv.org/abs/2504.07104)

## 数据与评测

实验同时考察检索上下文的相关性和最终回答质量，并比较增加推理计算量后的变化。这样可以识别文档看似相关、却不足以支持完整回答的情况。 [资料](https://arxiv.org/abs/2504.07104)

## 结果与公开范围

论文报告，多标准重排序改善了所测系统的质量与耗时关系。作者提供 llama-index 实现及实验代码入口；方法需要额外推理，其收益取决于任务与评估标准。 [资料](https://arxiv.org/abs/2504.07104)
