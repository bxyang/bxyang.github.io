# Reasoning Gym：可程序生成的推理任务

通过任务生成器与验证器，为训练提供可调难度的推理题。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-05-30 |
| 类型 | 开源框架与论文 |
| 公司参与 | Scale 研究目录收录；具体贡献未在目录中单独披露 |

## 工作内容

项目将每类任务实现为生成器和答案验证器，覆盖算术、代数、图、几何、逻辑和游戏等领域。训练时可以改变随机种子与难度参数，持续生成新的样本。 [资料](https://arxiv.org/abs/2505.24760)

## 数据与评测

论文介绍超过 100 类任务，并讨论程序生成数据在推理训练中的用途。可验证答案支持自动奖励，但每个生成器只覆盖其编码的任务规则与难度范围。 [资料](https://arxiv.org/abs/2505.24760)

## 结果与公开范围
