# 结合人工与自动化的语言模型测试框架

组织能力测试、安全测试和人工复核，分配不同评测方法的工作。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2023-10-05 |
| 类型 | 技术报告 |
| 公司参与 | Scale 发布技术报告 |

## 工作内容

报告先建立评测分类，再组合自动化评估、通用红队人员和领域专家。系统通过人工判断确定哪些环节可以由 AI 辅助，哪些情况需要进一步审查。 [资料](https://labs.scale.com/papers/a-holistic-approach-for-test-and-evaluation-of-large-language-models)

## 数据与评测

方法同时覆盖模型能力与安全表现，比较不同人员和自动化手段发现问题的方式。报告的重点是评测流程、成本和可扩展性，未将所有评测压缩为单一分数。 [资料](https://labs.scale.com/papers/a-holistic-approach-for-test-and-evaluation-of-large-language-models)

## 结果与公开范围

作者提出一套可供其他团队采用的混合测试流程，并讨论如何提高新问题的发现效率。原始技术报告和摘要由 Scale 发布。 [资料](https://labs.scale.com/papers/a-holistic-approach-for-test-and-evaluation-of-large-language-models)
