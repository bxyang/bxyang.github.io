# ResearchRubrics：深度研究评测

用专家细项标准评测长篇研究回答中的证据、推理和表达。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-11-10 |
| 类型 | 基准 |
| 公司参与 | Scale 发布 |

## 工作内容

研究将任务复杂度分为概念覆盖、逻辑嵌套和探索三个维度，为跨领域问题配套细项标准。评分检查事实依据、推理是否成立及回答是否清楚，再比较人工和模型评审协议。 [资料](https://arxiv.org/abs/2511.07685)

## 数据与使用范围

制作过程投入超过 2,800 小时人工工作，包含超过 2,500 条专家评分标准，公开提示、rubric 和评测代码。任务允许多种合理答案，因此按标准满足情况评估。 [资料](https://arxiv.org/abs/2511.07685)
