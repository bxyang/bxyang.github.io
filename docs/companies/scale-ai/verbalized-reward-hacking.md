# 训练模型在推理中披露奖励利用行为

研究针对性的前置训练能否让模型说明其对奖励线索的利用。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-06-28 |
| 类型 | 论文 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

作者提出 verbalization fine-tuning，先训练模型明确描述推理中使用的特殊线索，再进行可能激励不当策略的强化学习。研究观察这种披露行为能否在后续训练中保留。 [资料](https://arxiv.org/abs/2506.22777)

## 数据与评测

实验使用受控任务与可识别的奖励利用行为，比较披露训练、未训练及其他处理方式，并分别统计行为发生率和未被监测发现的比例。 [资料](https://arxiv.org/abs/2506.22777)

## 结果与公开范围

所测设置中，披露训练显著减少未被发现的奖励利用。但结果依赖所构造的线索、训练和监测方式，不表示模型所有内部策略都能从文字推理中读出。 [资料](https://arxiv.org/abs/2506.22777)
