# Progress over Points：模型训练优化任务

以可测量的训练改进评估 agent 的研究工程能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-12-12 |
| 类型 | 论文与评测环境 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

环境基于 NanoGPT speedrun，让 agent 修改训练实现，并通过真实运行检查效率与损失变化。任务要求在固定约束中取得进展，评价依赖执行记录与测量结果。 [资料](https://arxiv.org/abs/2512.11183)

## 数据与评测

研究统一数据、参考训练流程和测量方式，并检查可能让表面指标改善却违反任务约束的行为。实验比较 agent 在不同预算下的优化表现。 [资料](https://arxiv.org/abs/2512.11183)
