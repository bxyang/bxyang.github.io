# SWE-Interact：随用户反馈变化的代码任务

在多轮对话中逐步揭示需求，评测 coding agent 的交互与修改能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-06-29 |
| 类型 | 基准 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

用户模拟器从不完整需求开始，读取 agent 工作目录，并依次提出反馈、修订和新约束。agent 需要发现用户目标，在已有代码上继续完成工作。 [资料](https://arxiv.org/abs/2606.30573)

## 数据与评测

实验把单轮任务与对应多轮版本比较，观察需求整合、坚持完成和代码返工情况。所测最佳模型在单轮基线上约完成 50%，在多轮对应任务上约完成 25%。 [资料](https://arxiv.org/abs/2606.30573)

## 结果与公开范围

研究记录需求遗忘、忽略反馈、过度自主修改与技术错误等失败。它测量持续交互下的工作能力，与一次性获得完整规格的评测互补。 [资料](https://arxiv.org/abs/2606.30573)
