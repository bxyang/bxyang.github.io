# Scale Data Engine：数据开发服务

连接采集、筛选、标注、训练和评测的数据工作流程。

## 工作内容

服务覆盖文本、图像、视频和三维传感器数据，并通过领域专家提供标签。客户可以根据模型错误筛选需要补充的数据，再安排标注与质量检查。 [资料](https://scale.com/data-engine)

## 数据与评测

公开产品页列出文档处理、自然语言、转写、图像、视频及 LiDAR 等输入类型。生成式模型部分进一步包括提示回答对、偏好反馈、红队测试和模型评估。 [资料](https://scale.com/data-engine)

## 结果与公开范围

这是持续演进的数据服务组合，具体数据集和标注量依客户项目确定。现行产品页没有足够信息核定整个 Data Engine 名称的首次上线日期。 [资料](https://scale.com/data-engine)
