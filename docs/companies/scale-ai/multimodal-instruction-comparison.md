# 多模态指令微调方法比较

比较视觉编码器接入语言模型后的架构和指令微调方案。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2023-10-04 |
| 类型 | 论文 |
| 公司参与 | Scale 研究人员 Utsav Garg 与 Erhan Bas 发表 |

## 工作内容

研究比较将独立预训练视觉编码器接入语言模型的不同方案，通过指令微调使模型处理图像与文字输入。消融实验检查架构选择与训练方法对表现的影响。 [资料](https://arxiv.org/abs/2310.03211)

## 数据与评测

评测覆盖复杂推理、对话、图像描述、选择题和二分类任务。比较同时关注零样本任务迁移，以及模型回答中事实性和图像依据的情况。 [资料](https://arxiv.org/abs/2310.03211)

## 结果与公开范围

论文指出，当时的方法在多模态指令数据多样性与回答事实性上仍有不足。该工作提供方法比较与消融结果，没有另行定义一个统一的商业产品。 [资料](https://arxiv.org/abs/2310.03211)
