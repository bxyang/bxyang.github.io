# Adaptive Guidance：训练中的自适应提示

在模型无法独立解题时提供提示，并调整提示轨迹的训练权重。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-06-16 |
| 类型 | 论文 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

方法让指导模型给出自然语言提示，帮助学生模型完成原本失败的任务。训练同时处理带提示与不带提示的轨迹，减少训练输入与独立作答输入之间的差异。 [资料](https://arxiv.org/abs/2506.13923)

## 数据与评测

实验涵盖数学、科学与代码任务，模型规模从 0.5B 到 72B，并比较多种强化学习设置。作者分析提示的质量、出现时机及权重处理对最终独立解题表现的影响。 [资料](https://arxiv.org/abs/2506.13923)

## 结果与公开范围

结果表明，适当使用指导信息可以改善困难任务上的学习。论文评估的是训练后模型不依赖提示的表现，提示阶段的成功率不直接当作最终能力。 [资料](https://arxiv.org/abs/2506.13923)
