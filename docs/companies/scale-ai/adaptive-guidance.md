# Adaptive Guidance：在推理训练遇到困难时加入提示

## 1. 摘要翻译

以下按 [arXiv v2 摘要](https://arxiv.org/abs/2506.13923v2)顺序翻译。原文由 Vaskar Nath 等六位作者撰写，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；中文为翻译版本。

我们研究采用可验证奖励强化学习（RLVR）训练的推理模型如何学会解决新问题。我们发现，RLVR 主要通过两种方式提升表现：（1）把 pass@k 压缩为 pass@1；（2）产生“能力增益”，使模型学会解决那些此前即使在较大 k 值下也无法解决的新问题。我们发现，不同规模的模型都存在能力增益，但学会解决新问题主要仍由自蒸馏推动。我们在参数规模从 5 亿到 720 亿的模型上验证了这些发现，研究使用超过 50 万道涵盖数学、科学和代码领域的推理问题，每道问题均包含提示词和可验证的最终答案。

我们进一步表明，在仍要求模型从头推导解题过程的情况下，让模型在上下文中参考自然语言指导，可以显著提高 pass@k。基于这些发现，我们提出一类新的在线训练算法 Guide。对于最初所有采样轨迹都不正确的问题，Guide 会自适应地将提示加入模型上下文，并调整这些“离策略”轨迹的重要性采样比率，以优化模型在不再包含提示的上下文中的策略。

我们介绍了适用于 GRPO 和 PPO 的 Guide 变体，并通过实验表明，在 70 亿和 320 亿参数模型上，Guide-GRPO 比原始算法具有更好的泛化表现，在数学基准上的宏平均表现最多提高 4%。我们还通过细致的消融分析研究 Guide 的组成部分，并对其学习效率进行理论分析。

## 2. 研究背景与相关研究

数学题和部分代码任务可以通过最终答案或测试结果自动检查正确性，因此适合用可验证奖励训练模型。但强化学习带来的提升可能有不同来源：模型原本偶尔就能答对，训练只是让正确答案出现得更稳定；也可能模型开始解决在训练前多次尝试仍未答对的问题。

这里的 pass@1 表示单次尝试成功的表现，pass@k 表示尝试 k 次至少成功一次的表现。Introduction 与 Related Work 将此前的专家迭代、自蒸馏等研究概括为：把模型多次探索中偶然出现的好答案，转化为更稳定的单次作答能力。另一些研究则认为，RLVR 主要改善采样效率，未必能扩大模型的解题范围。本文尝试区分这两种变化。

如果一道题的所有尝试都失败，仅有正确或错误的奖励可能难以告诉模型下一步应尝试什么。使用其他策略或教师提供的数据能够增加学习机会，但这些数据与当前模型产生的轨迹可能相差较大。Guide 选择另一种方式：必要时提供自然语言提示，让当前模型自己生成后续解题轨迹，再把这些轨迹用于训练。[论文第 1 节及第 4 节](https://arxiv.org/pdf/2506.13923v2)

## 3. 核心贡献

**核心问题。** 在推理强化学习中，模型完全无法答对的问题如何产生有用的学习信号，并最终让模型不依赖提示也能解题。

**核心方案。** 作者先区分训练带来的稳定作答提升和新问题上的能力增益，再提出 Guide：模型先不带提示地多次尝试；只有全部失败时，才引入针对该题的提示，要求模型仍然自己生成完整推理过程。训练时对这些有提示轨迹作相应的权重修正，使学习目标仍然指向无提示条件下的解题能力。提示不是测试时必须存在的外部帮助。

这种选择性指导既为困难问题提供探索方向，也保留模型自行形成解题步骤的过程。论文给出了与 GRPO、PPO 结合的形式，主要实证验证集中于 Guide-GRPO。[论文第 2 节](https://arxiv.org/pdf/2506.13923v2)

**主要结论。** 作者发现，在其有限采样设置下，多种规模模型的进步主要来自自蒸馏，同时也存在此前未答对问题上的增益。“此前未答对”指在所用次数的采样中没有成功，不等同于证明模型在任意多次尝试下都绝对无法解决。

Guide-GRPO 在所测数学基准上总体优于普通 GRPO，但并非每个单项都提升。例如 32B 模型、8K 上下文的数学宏平均 pass@1 从 52.87% 提高到 56.26%，而一些单项或多次采样指标并未改善。分析学习机制时涉及的模型规模和任务范围，宽于 Guide 训练方法本身的主要验证范围；不能据此宣称已在 72B 模型或所有代码、科学任务上验证 Guide 的收益。[论文第 3 节、表 2 及第 5—6 节](https://arxiv.org/pdf/2506.13923v2)
