# 生物风险缓解方法的评估实践

分析计算评测与训练数据处理在生物风险研究中的作用。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-10-31 |
| 类型 | 论文 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

研究讨论如何设计风险相关能力评测，并检验训练数据过滤等缓解措施的效果。分析区分一般领域知识、评测表现与实际风险，避免仅用一个分数概括缓解效果。 [资料](https://arxiv.org/abs/2510.27629)

## 数据与评测

实验使用多项计算评测，比较不同处理条件及后续模型适配后的表现。研究重点是缓解结论能否在评测变化后仍然成立。 [资料](https://arxiv.org/abs/2510.27629)

## 结果与公开范围

论文指出部分能力会在后续适配中恢复，因此单次测试下降不足以证明风险已被持久消除。结果限于论文中的计算实验，不是实验室操作效果的验证。 [资料](https://arxiv.org/abs/2510.27629)
