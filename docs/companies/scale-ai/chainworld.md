# ChainWorld：组合桌面任务的长期评测

将 OSWorld 原子任务串联，比较一次交代和逐步交代任务的差异。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-06-19 |
| 类型 | 合作基准 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

研究搜索可以按方向衔接的原始任务，保持其验证器，将多个目标组成一段桌面工作。相同任务链分别以单轮完整指令和多轮逐项揭示两种方式运行。 [资料](https://arxiv.org/abs/2606.21654)

## 数据与评测

工作集包含 347 条长度为 2—4 的任务链，比较四个计算机操作 agent。最高整链完成率为 31%，其中三个模型在多轮设置中完成率较高。 [资料](https://arxiv.org/abs/2606.21654)

## 结果与公开范围

单轮失败更多涉及产物细节，多轮失败更多涉及进度衔接和后期停止执行。基准用于观察任务连接后的状态保持，和独立任务准确率分别记录。 [资料](https://arxiv.org/abs/2606.21654)
