# 搜索时的数据污染

检查联网评测是否通过搜索直接取得基准答案。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-08-12 |
| 类型 | 论文 |
| 公司参与 | Scale 研究人员发表或参与共同研究 |

## 工作内容

研究分析带搜索工具的模型执行记录，追踪检索结果是否包含题目原文或答案。数据污染在这里发生于评测时的工具调用环节。 [资料](https://arxiv.org/abs/2508.13180)

## 数据与评测

实验涉及 Humanity’s Last Exam、SimpleQA 和 GPQA。作者检查公开数据站点出现在搜索结果中的情况，并通过限制部分来源比较回答变化。 [资料](https://arxiv.org/abs/2508.13180)

## 结果与公开范围

论文发现部分任务会检索到真实答案，影响对推理能力的判断。作者公开相关执行记录；结论针对所测搜索配置与当时可检索的网页。 [资料](https://arxiv.org/abs/2508.13180)
