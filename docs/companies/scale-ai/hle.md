# Humanity’s Last Exam：专家知识与推理

通过跨学科专家题目评测高难度知识与推理能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-01-23 |
| 类型 | 基准 |
| 公司参与 | Scale 与 Center for AI Safety 等共同组织 |

## 工作内容

专家提交题目、答案和审查材料，题型包括简短回答和选择题，部分需要理解图像。评测强调可检查的答案及专业难度，并审查题目的歧义和公开可搜索性。 [资料](https://arxiv.org/abs/2501.14249)

## 数据与使用范围

公开版本包含约 2,500 道题。它主要衡量给定条件下的知识与推理，不直接衡量跨软件工作或长期自主执行能力；不同工具设置的分数需要分开比较。 [资料](https://arxiv.org/abs/2501.14249)
