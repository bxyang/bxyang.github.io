# OpenThoughts：开放推理数据配方

系统研究推理数据的制作方法，并公开数据和训练模型。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-01-28 |
| 类型 | 合作数据与模型 |
| 公司参与 | 多机构社区合作，Bespoke 为参与和支持机构 |

## 工作内容

项目比较题目来源、推理轨迹生成和筛选方式，以同样的训练与评测流程检验数据配方。OpenThoughts2 扩展到百万级推理数据，OpenThoughts3 进一步通过大量实验选择更有效的配方。

## 数据与使用范围

初始项目于 2025 年 1 月启动，6 月论文总结数据配方。OpenThoughts、OpenThinker 模型和后续 Agent 项目属于不同发布项；项目并非 Bespoke 单独开发。
