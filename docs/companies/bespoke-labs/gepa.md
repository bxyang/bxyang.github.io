# GEPA：通过执行反馈优化提示

让模型分析任务轨迹，再迭代和组合提示候选。

| --- | --- |
| 时间 | 2025-07-25 |

| 公司参与 | 联合研究，Bespoke 创始人 Alexandros Dimakis 参与署名 |

## 工作内容

GEPA 读取推理、工具调用和反馈，用自然语言分析失败并提出提示修改。系统测试不同候选，保留在不同任务上各有优势的方案，再组合互补经验；优化对象主要是提示，而非直接更新模型权重。

## 数据与使用范围

论文在六项任务中与 GRPO 和 MIPROv2 比较，并公开代码。数据效率与性能优势对应所测任务和运行预算，不意味着所有任务都应使用提示优化替代训练。
