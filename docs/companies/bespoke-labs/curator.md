# Curator：合成数据处理工具

为后训练数据生成和结构化信息抽取提供批量处理接口。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025 |
| 类型 | 开源工具 |
| 公司参与 | Bespoke Labs 开发 |

## 工作内容

开发者定义提示和输出解析逻辑，再通过工具调用模型、处理批量响应并整理为数据集。工具把生成结果、结构化解析及数据处理连接起来，便于反复运行同一套数据制作流程。

## 数据与使用范围

项目代码公开，支持范围以仓库版本为准。它是数据工作流工具，生成数据的事实质量还取决于任务设计和后续验证。
