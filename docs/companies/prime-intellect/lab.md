# Lab：模型训练平台

把数据、环境、训练和评测组织成托管工作流程。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-02-10 |

## 工作内容

用户通过平台选择训练任务、准备数据或环境、启动训练并查看结果。产品将底层算力与开放训练工具接入统一流程，减少自行维护分布式运行系统的工作。

## 数据与使用范围

2 月为初次介绍，5 月发布面向自我改进 agent 的训练版本。商业托管服务与公开代码是不同交付形式；实际模型和硬件支持随版本变化。
