# Environments Hub：开放 RL 环境目录

为训练和评测环境提供发布、共享及运行入口。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-08-27 |
| 类型 | 平台与工具 |
| 公司参与 | Prime Intellect 开发 |

## 工作内容

环境以状态、动作与奖励描述任务，开发者可以分享代码、游戏、对话等环境，并通过配套 CLI、verifiers 和 Prime-RL 使用它们。平台将环境制作与模型训练连接起来。

## 数据与使用范围

目录包含社区贡献，不应把所有环境都归为 Prime Intellect 独立开发。每个环境的许可、验证方式和数据来源需要分别查看。
