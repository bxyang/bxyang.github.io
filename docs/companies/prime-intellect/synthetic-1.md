# SYNTHETIC-1：可验证推理数据

组织分布式算力生成数学、代码和科学推理轨迹。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-02-20 |
| 类型 | 数据集 |
| 公司参与 | Prime Intellect 与算力贡献者共同制作 |

## 工作内容

使用 DeepSeek-R1 生成回答，再按任务使用符号计算、单元测试或模型评审器验证。数据保留正确与错误轨迹和元数据，并整理适合监督微调及偏好训练的子集。

## 数据与使用范围

公开约 200 万条推理轨迹，其中监督微调子集约 90 万条。不同任务的验证器可靠性不同；模型评审标记的“正确”不等于形式化证明。
