# PCCL：可恢复的集体通信

为公共互联网中的分布式训练提供动态成员和故障恢复。

## 工作内容

节点声明共享状态；通信期间有节点失效时，操作可在剩余成员中重试。新节点可以加入，并在训练循环的接受点与现有成员同步，支持算力成员随时间变化。
