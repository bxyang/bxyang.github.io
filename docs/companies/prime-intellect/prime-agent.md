# Prime Agent：可修改自身工作方式的编码 agent

通过持续 REPL 管理上下文、工具和子 agent，并保存可调整的工作状态。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-08-05 |
| 类型 | 开源工具 |
| 公司参与 | Prime Intellect 开发 |

## 工作内容

框架将历史和工具作为程序可访问的对象，子 agent 调用表现为函数操作。模型可以更新提示、技能与记忆，并与其他会话通信；后台进程管理会话和恢复状态。

## 数据与使用范围

产品采用 Recursive Language Model 与 Continual Harness 两类抽象，并公开代码。所谓自我改进主要指工作框架和状态的调整，不等同于每次使用都更新模型权重。
