# Prime Intellect Compute：算力交易平台

汇集不同提供方的 GPU 算力，供模型训练和推理使用。

## 工作内容

平台为用户提供查找和租用计算资源的入口，并将资源连接到后续的分布式训练工作。不同算力提供方的设备和连接条件由平台组织，用户按工作需要选择配置。

## 数据与使用范围

这是商业算力服务。公开的分布式训练框架和社区算力实验建立在相关基础设施之上，但不能把平台全部租赁资源都视为参加同一训练。
