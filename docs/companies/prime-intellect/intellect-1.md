# INTELLECT-1：跨机构分布式预训练

在全球多处算力节点上训练 100 亿参数语言模型。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-11-29 |
| 类型 | 模型与论文 |
| 公司参与 | Prime Intellect 与算力贡献者共同完成 |

## 工作内容

训练使用低通信分布式方法，让节点在本地计算后定期同步，并支持节点加入和退出。公开实验处理互联网连接与算力波动带来的问题，完成约一万亿 token 的训练。

## 数据与使用范围

论文记录 30 家算力提供方参与，最多 14 个节点同时训练，跨越三个洲。公开权重和技术报告；它是预训练实验，与后来的 INTELLECT-2 强化学习不同。
