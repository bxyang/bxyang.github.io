# GDP.PDF：专业 PDF 综合推理

在真实专业文档中综合读取表格、图表、脚注及跨页信息。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-07-13 |
| 类型 | 基准 |
| 公司参与 | Surge 发布 |

## 工作内容

来自十个领域的专业人员编写文档问答。候选题只有在至少两个前沿模型出现实质错误时才保留，再配套细项标准和十一类能力标签，区分抽取、引用、空间理解与证据不足等情况。

## 数据与使用范围

论文版本包含 100 项任务，比较 17 个模型。它是有意筛选困难样本的诊断集；官网摘要和修订论文的最佳成绩不同，本页以任务设计为主，不混用版本数字。
