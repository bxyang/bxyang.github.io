# WebGPT：浏览器问答与人工反馈

让模型搜索网页、收集来源，再生成可供人工检查的长篇回答。

## 工作内容

模型在文字浏览环境中学习人的搜索和浏览示范，再使用人工偏好训练的奖励模型选择回答。生成时需同时记录参考资料，便于评审者检查事实依据。

## 数据与使用范围

主要实验使用 ELI5 问答。论文比较的是特定任务中的人工偏好，偏好胜率不等同于事实准确率。Surge 的合作记录与 OpenAI 的论文作者和研究贡献分别注明。
