# CoreCraft：企业客服 RL 环境

模拟企业客服组织，研究长流程任务训练能否迁移到其他工具任务。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-02-18 |
| 类型 | 论文与训练环境 |
| 公司参与 | Surge 发布 |

## 工作内容

环境包含超过 2,500 个实体、14 类实体和 23 个工具，任务由专家设计并用细项标准评分。研究使用 GLM 4.6 和 GRPO 训练，比较训练前后在保留任务及外部工具基准上的表现。

## 数据与使用范围

论文报告保留任务通过率从 25.37% 提高到 36.76%，并观察到跨基准提升。官网使用 EnterpriseBench 名称，预印本使用 EnterpriseGym；本页按 CoreCraft 合并，避免重复统计。
