# Agentic Capabilities：工作任务失败分析

在电商工作环境中分析 agent 的工具使用、规划和语境推理。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-01-13 |
| 类型 | 论文与环境评测 |
| 公司参与 | Surge 发布 |

## 工作内容

研究比较模型完成 150 项工作任务的轨迹，把失败归入工具使用、目标与计划、适应变化、依据环境信息行动，以及常识推理等能力。较强模型的错误仍集中在需要补足隐含条件的任务中。

## 数据与使用范围

使用 Surge 的交互式电商 RL 环境。论文中最好的被测模型仍有约 40% 的任务失败；该比例对应当时环境和模型，不能当作当前所有 agent 的失败率。
