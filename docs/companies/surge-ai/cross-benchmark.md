# 长流程 agent 的跨基准泛化

检验办公环境训练能否改善未用于训练的工具和软件任务。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-07-31 |
| 类型 | 论文 |
| 公司参与 | Surge 发布 |

## 工作内容

研究对 Qwen3.5-122B-A10B 进行先监督微调、后强化学习，训练数据为 27 类、363 项长流程 MCP 办公任务。外部基准不进入奖励和训练检查点选择，评测包含工具调用与软件工程。

## 数据与使用范围

五个外部评测均有提升，其中 SWE-bench Pro 提高 5.8 个百分点。办公任务中没有软件工程样本；后续行为分析另有论文，使用同一训练工作，不能视为独立重复实验。
