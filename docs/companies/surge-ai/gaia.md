# GAIA：通用助手综合任务

以需要检索、工具调用和多模态理解的任务评测通用助手。

## 工作内容

题目通常对人类有明确答案，却要求模型组合多步操作，例如读取附件、在网页中找资料并做简单推理。评测按所需操作复杂度划分难度，检查最终答案是否正确。

## 数据与使用范围

GAIA 由多机构共同研究，公开部分问题及评测入口，并保留测试答案。它考查带工具的综合任务，与只输入问题的知识测验不同。
