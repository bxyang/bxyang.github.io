# Model-Written Evaluations：模型生成评测

让语言模型生成测试题，再通过筛选和人工审核研究其他模型的行为。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2022-12-19 |
| 类型 | 合作论文与数据 |
| 公司参与 | Anthropic 等联合研究，Edwin Chen 参与署名 |

## 工作内容

研究从简单的是非问题到多阶段生成与过滤流程，制作 154 个数据集。人工检查问题相关性和标签，再观察模型规模及人工反馈训练程度变化时的回答趋势。

## 数据与使用范围

评测涉及迎合用户、偏好表达等行为。数据反映模型在特定提问方式下的输出倾向，论文公开的行为现象不应直接解释为模型拥有相应心理动机。
