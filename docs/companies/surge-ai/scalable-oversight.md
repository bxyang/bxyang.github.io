# Scalable Oversight：人机联合监督实验

研究不完全可靠的语言模型能否帮助人完成较难的判断。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2022-11-04 |
| 类型 | 合作论文 |
| 公司参与 | Anthropic 等联合研究，Edwin Chen 参与署名 |

## 工作内容

实验选择专家能完成、普通人在限定条件下较难完成的任务。参与者通过聊天向模型求助，再将联合结果与模型单独回答和人类独立回答比较。

## 数据与使用范围

概念验证使用 MMLU 和限时 QuALITY。结果支持在现有系统上研究监督方法，但实验没有测试人类对全面超越自身能力的模型进行监督。
