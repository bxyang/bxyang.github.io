# Riemann-Bench：研究级数学问题

由专业数学研究者制作高难度问题，并用独立解题验证答案。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-04-08 |
| 类型 | 基准 |
| 公司参与 | Surge 发布，Edwin Chen 参与署名 |

## 工作内容

25 道题由数学教授、研究生及具有博士背景的竞赛获奖者编写。每道题由两位独立领域专家从头求解验证，答案具有唯一闭式形式，以程序检查结果。

## 数据与使用范围

评测允许模型使用代码、搜索和开放式推理，并进行多次独立运行。题目保持私有，公开论文介绍设计与结果；它与不允许工具的竞赛题测试具有不同条件。
