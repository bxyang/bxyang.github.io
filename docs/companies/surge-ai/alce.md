# ALCE：评估语言模型的回答是否有据可查

论文：*Enabling Large Language Models to Generate Text with Citations*，EMNLP 2023。原文：[正式发表页](https://aclanthology.org/2023.emnlp-main.398/) · [arXiv v2](https://arxiv.org/abs/2305.14627v2)。

## 1. 摘要翻译

以下完整翻译 Tianyu Gao、Howard Yen、Jiatong Yu 和 Danqi Chen 的 Abstract。[EMNLP 正式版](https://aclanthology.org/2023.emnlp-main.398/)适用 ACL 的 [CC BY 4.0 许可](https://aclanthology.org/faq/#what-is-the-copyright-for-materials-in-the-acl-anthology)；本节为中文翻译。

大型语言模型已经成为广泛使用的信息获取工具，但它们生成的内容容易出现幻觉。在这项工作中，我们旨在让大型语言模型生成带有引用的文本，提高其事实正确性和可验证性。已有工作主要依赖商业搜索引擎和人工评估，因此难以复现和比较不同的建模方法。我们提出 ALCE，这是首个用于自动评估大型语言模型引用的基准。ALCE 汇集了多样的问题和检索语料，要求构建端到端系统，检索支持证据并生成带有引用的答案。我们从流畅性、正确性和引用质量三个维度设计自动指标，并证明这些指标与人工判断具有较强相关性。我们使用先进的大型语言模型和新的提示策略开展实验，发现当前系统仍有很大的改进空间。例如，在 ELI5 数据集上，即便是表现最好的模型，也有 50% 的情况缺乏完整的引用支持。我们的分析还指出了值得探索的未来方向，包括开发更好的检索器、推进长上下文语言模型，以及提高整合多个来源信息的能力。

## 2. 研究背景与相关研究

语言模型可以把答案写得通顺，却可能混入错误事实。让回答附上来源，能帮助用户核实信息，但前提是来源确实支持回答。一个真实存在的网页链接，并不能证明模型对网页的转述正确；资料里出现了某个关键词，也不代表资料支持模型据此作出的判断。

论文在 Introduction 和 Related Work 中讨论了三条相关路线。**检索增强语言模型**，如 REALM、RETRO 和 Atlas，将外部文段引入模型，但不一定显式提供引用，也不保证回答忠实于材料。**带引用的问答系统**，如 WebGPT 及 Menick 等人的工作，已经训练模型在回答时给出证据，但当时的实验较依赖商业搜索服务、封闭模型和人工评价。**来源归属评测**，如 AIS，研究一段回答是否可以由指定来源支持，为引用评价提供了基础，但一些既有任务主要针对单篇文档和短答案。（原文 §1、§7。）

ALCE 将这些问题放到一个可重复比较的任务中：给定问题和固定语料库，系统自行检索、组织答案并标注引用，评测则覆盖整个过程。它关注需要多句话、多个事实或多个来源的回答，而不仅是判断一个简短答案是否正确。

## 3. 核心贡献

### 核心要解决的问题

论文要建立一种自动评测方式，区分“回答读起来不错”“回答包含正确信息”和“引用实际支持回答”这三件事。只有把它们分开观察，才能知道一个系统究竟在哪个环节出了问题。

### 核心方案

ALCE 组合了三种问答任务：ASQA 要求覆盖有歧义问题的不同解释，QAMPARI 要求列出多个符合条件的实体，ELI5 要求解释较开放的问题。前两类使用维基百科，第三类使用更大规模的网页语料。系统从指定语料中找到短文段，并在答案中用编号引用它们。（原文 §2。）

评价分为三个方面。流畅性观察文本表达；正确性检查答案是否覆盖已知要点；引用质量则检查**每项陈述是否有充分证据，以及所列引用是否相关**。引用评价借助自然语言推断模型：它读取陈述和证据，判断证据是否能够支持陈述。作者又以人工判断验证这些自动指标。（原文 §3、§6。）

例如，回答“某事件发生在某年，并导致某项后果”时，如果引用只支持年份，整句话仍缺少完整证据。若答案已经获得充分支持，却又多挂一个无关来源，引用质量也应受到影响。这样的设计避免把“引用数量多”误当成“依据充分”。

作者进一步比较先检索再生成、先生成再补引用、生成途中检索，以及从多个候选答案中重新选择等策略。这使 ALCE 不只是一个分数，也能用于比较不同的检索与生成组合。（原文 §4—§5。）

### 结论

在论文的 2023 年实验中，模型通常能生成通顺的答案，但正确性与引用质量仍有明显不足。尤其在解释性问答 ELI5 上，最好的模型也常不能让所有陈述得到完整支持。先写答案再补引用可以得到看似正确的内容，却更容易出现证据与陈述不匹配；先提供检索材料通常有助于生成有依据的答案。（原文 §5、§8。）

人工评估总体支持自动引用指标的有效性，但它们仍受推断模型准确率限制，也不能穷尽开放问题的所有合理答案。ALCE 的主要贡献是提供了一个可复现的比较框架，并把后续改进方向具体指向检索质量、长上下文处理和多来源信息整合，而不是仅以回答是否流畅判断系统能力。（原文 §6、§8、Limitations。）
