# ALCE：带引用回答的自动评测

将检索证据、生成答案和引用质量放在同一评测中。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2023-05-24 |
| 类型 | 合作基准 |
| 公司参与 | Princeton 研究；Surge 目录收录合作 |

## 工作内容

系统需要从给定语料中检索资料，生成答案并附来源。评测分别检查流畅性、答案正确性和引用质量，避免仅因为出现了引用标记就判断回答有依据。

## 数据与使用范围

基准提供问题、检索语料与自动评价指标，并与人工判断比较。引用完整性与引用正确性不同：答案可能只为部分陈述提供了支持。
