# FLAN：扩大指令微调规模

研究任务数量、模型大小和推理示范对指令微调效果的影响。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2022-10-20 |
| 类型 | 合作论文与模型 |
| 公司参与 | Surge 官方研究目录列为合作项目；主要论文由合作研究机构发表 |

## 工作内容

研究将不同数据集改写成自然语言指令，扩大训练任务覆盖，并加入带推理过程的示例。实验在 PaLM、T5 等模型上比较零样本、少样本和思维链任务的表现。

## 数据与使用范围

论文公开 Flan-T5 权重。约 1,800 个任务的训练组合与单一公开 benchmark 不同；Surge 的合作关系见其目录，模型方法及论文由 Google 团队等署名。
