# DOC：用详细大纲控制长篇故事

通过分层大纲和段落控制提高长篇生成的情节连贯性。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2022-12-20 |
| 类型 | 合作论文 |
| 公司参与 | UC Berkeley 等研究；Surge 目录收录合作 |

## 工作内容

框架先生成详细、分层的故事计划，再在写作过程中检查每段是否符合相应大纲。这样把情节安排与具体文字生成拆成相互配合的两个环节。

## 数据与使用范围

论文使用数千词故事，并通过人工评价比较情节连贯、贴合大纲和趣味性。人工偏好实验是特定生成设置下的结果；首次预印本为 2022 年，后续版本于 2023 年修订。
