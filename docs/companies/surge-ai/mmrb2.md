# Multimodal RewardBench 2：图文奖励评测

检查评审模型能否判断图像与文字混合产物的质量。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-12-18 |
| 类型 | 合作基准 |
| 公司参与 | Meta 与 Surge 合作 |

## 工作内容

包含文生图、图像编辑、图文交错生成和多模态推理四类任务。每类提供 1,000 组专家偏好对，评审器从两个回答中选择较好的一项，并与人类判断比较。

## 数据与使用范围

共 4,000 组偏好对，候选回答来自 23 个模型或 agent、21 类原始任务。它评测奖励模型的选择能力，不能把这个准确率解释为生成模型本身的任务成功率。
