# PALMS：以目标价值数据调整模型行为

通过小规模人工整理数据和迭代评测调整语言模型的回应方式。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2021-06-18 |
| 类型 | 合作论文 |
| 公司参与 | OpenAI 研究；Surge 官方目录列为合作项目 |

## 工作内容

流程先定义目标行为，再制作示例用于微调，通过人工评价、毒性指标及词语关联分析检查变化。根据评测发现的不足补充下一轮训练例子，使数据制作和模型调整形成迭代。

## 数据与使用范围

实验使用不同规模的 GPT-3。目标价值由研究设置给定，结果表示对这套目标的符合程度；不等同于对所有社会文化规范的统一评价。
