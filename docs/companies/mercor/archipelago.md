# Archipelago：agent 执行与评测基础设施

为 APEX-Agents 提供任务执行、工具访问和结果评估的运行基础。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-01-20 |
| 类型 | 开源工具 |
| 公司参与 | Mercor 开发并随 APEX-Agents 开放 |

## 工作内容

基础设施把专业任务所需的环境文件、工具和评分流程组织起来，供不同 agent 在相同任务条件下运行。研究者可以查看执行轨迹，并结合任务的评分标准检查最终文件。

## 数据与使用范围

与 APEX-Agents 数据集一同发布。基准内容与执行框架分别承担出题和运行职责；复现分数还需要记录模型版本、运行预算及具体配置。
