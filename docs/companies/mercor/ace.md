# ACE：日常消费任务评测

以购物、饮食、游戏和家居维修任务评测模型满足具体需求的能力。

## 工作内容

专家为每项任务编写专用评分标准，并设置必须先满足的门槛。例如购物任务需要先给出用户所要求的产品类型，才继续获得其他质量分。该设计避免回答在外围细节上得分，却没有完成核心需求。

## 数据与使用范围

项目公开技术报告、数据及评测框架。它属于面向个人生活场景的评测，与 APEX 的职业任务互补；不同领域分数分别统计。
