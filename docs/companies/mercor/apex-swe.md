# APEX-SWE：集成与可观测性软件任务

评测 agent 在真实代码仓库中完成软件集成和可观测性改进的能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-01 |
| 类型 | 基准 |
| 公司参与 | Mercor 与 Cognition 合作 |

## 工作内容

任务由软件工程师设计，要求模型阅读项目、修改实现并验证结果。两个任务组分别覆盖外部服务或组件集成，以及日志、监控等可观测性工作；它们不局限于修复现成的 GitHub issue。

## 数据与使用范围

公开数据包括 100 个集成任务和 100 个可观测性任务，由 50 名开发者参与制作。论文于 2026 年 1 月公开，公司介绍文章发布于 3 月；时间线按论文月份记录。
