# Bespoke Labs

开发合成数据工具、专用模型和企业规模的 RL 环境，参与开放推理数据及 agent 评测。

## 创始人背景

**Mahesh Sathiamoorthy 与 Alex Dimakis** 于 2024 年共同创办 Bespoke Labs。Sathiamoorthy 本科就读 IIT Kharagpur，在 USC 获硕士和博士学位，后在 Google Brain、DeepMind 工作，参与 YouTube 推荐系统、TPU 应用和生成式检索。[创始人主页](https://smahesh.com/)

Dimakis 为机器学习研究者，曾任教于 UT Austin，现公司介绍列其为 UC Berkeley 教授及首席科学家。他的研究涉及生成模型与数据集开发。两人的学术经历早于公司成立，相关早期论文不计入公司发表记录。[公司团队](https://www.bespokelabs.ai/about-us)

## 发展过程

- **2024 年**：围绕数据策展和专用模型创业，公开 Bespoke-MiniCheck 等工作。
- **2025 年**：发布 Curator、Stratos，参与 OpenThoughts、Terminal-Bench 和 GEPA。
- **2026 年**：公司对外业务集中到企业规模 RL 环境及 agent 优化，环境包含代码库、微服务和业务资料。[官网](https://bespokelabs.ai/)

公司不是“暂无论文”的纯服务商。其公开记录包括共同研究、开源工具、数据集和模型，需要逐项辨认。

## 目前的主营业务

面向模型实验室构建长程训练环境，面向企业提供贴近业务系统的评测和优化环境。开源工具包括数据生成管线 Curator；开放研究涵盖推理数据、终端任务和提示优化。

商业环境的完整内容并不全部公开。公开模型卡、代码仓库和论文可以说明方法及实验，不能据此推定客户私有环境的质量或规模。
