# BankerToolBench：投行文件与工具任务

让 agent 在投行工作环境中生成表格、演示文稿和其他交付文件。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-04-13 |
| 类型 | 基准 |
| 公司参与 | Handshake 研究团队参与发布 |

## 工作内容

任务从资深银行从业者的工作要求出发，提供数据室、市场信息及 SEC 资料等工具。agent 需要查找资料、计算、组织分析并产出 Excel、PowerPoint、PDF 或 Word 文件。评分检查文件内容和业务要求，而不只检查聊天回复。

## 数据与使用范围

研究涉及 502 名银行从业者；每项任务包含细粒度评分标准，通常超过 100 项。论文中的结果对应指定环境和模型配置，并不表示模型可以直接承担客户交付。
