# BankerVerifierBench：工作产物验证器评测

用专家标注检查自动评分器是否准确判断投行任务的评分项。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-05-27 |
| 类型 | 基准 |
| 公司参与 | Handshake 发布 |

## 工作内容

数据来自 21 项 BankerToolBench 任务，包含 3,204 条专家判断。评测对象是自动验证器：它需要判断 agent 的文件或操作是否满足某条标准，再与专家标注比较。

## 数据与使用范围

它评测的是评分器，不是直接对投行 agent 排名。发布文章将数据集开放列为后续计划；不能将文章发布等同于数据已全部开放。
