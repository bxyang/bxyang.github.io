# CAREBench：面向儿童使用场景的安全评测

评估模型在儿童相关对话中处理风险和提供恰当回应的能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-06-29 |
| 类型 | 基准 |
| 公司参与 | Handshake 研究团队参与发布 |

## 工作内容

基准由父母和临床专业人员参与标注，覆盖 12 类风险。测试关注模型能否识别语境、避免不恰当内容，并采取符合儿童场景的回应方式。研究使用文字任务，不依赖儿童受虐影像。

## 数据与使用范围

共 500 个提示，论文比较 7 个模型。不同模型的失败率差异较大；数据中的风险覆盖及评分规则限定了结论的适用范围。
