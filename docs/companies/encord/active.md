# Encord Active：训练数据质量分析

分析数据、标签和模型错误，帮助选择下一批需要处理的数据。

## 工作内容

系统计算数据和标注相关指标，将异常样本、重复内容或疑似标签错误组织成可检查的数据子集。开发者可以据此安排审核或补充标注，再比较模型变化。
