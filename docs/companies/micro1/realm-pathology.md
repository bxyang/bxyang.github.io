# Realm Pathology：病理报告任务

评测模型对真实去标识病理报告的整理与解释。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-06-22 |
| 类型 | 基准 |
| 公司参与 | micro1 发布 |

## 工作内容

模型需要保留报告中的事实、诊断边界和不确定性，不能增加原文没有支持的诊断。评分采用逐项权重，检查重要信息是否遗漏，以及改写是否改变含义。

## 数据与使用范围

公开说明涉及 50 个任务，其中 41 个单轮、9 个多轮，每个任务执行三次。任务是报告处理评测，不能据此推断模型具备独立诊断能力。
