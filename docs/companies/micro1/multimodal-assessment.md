# 多模态候选人评估：分数与后续就业的关系

一份简历与一次包含面试、现场题目和角色评价的评估，提供的信息不同。micro1 的这项研究为 800 名候选人同时计算两种分数，再比较它们与后续就业记录的关系。综合评估的 AUC 为 0.742，简历评分为 0.641。这个结果描述分数对就业标签的区分能力；它没有直接测量入职后的绩效，也没有通过随机实验测量使用评估系统是否提高了招聘质量。

## 同一批候选人的两种评分

作为说明示例，同一名候选人可能拥有与岗位匹配的项目经历，但在现场题目中表现不同；也可能简历表达简短，却在结构化问答中展示更多经验。研究比较的是两套信息来源不同的评分，而不是只替换一个模型、保持所有输入一致的实验。

### 简历基线

外部简历评分使用开源 Resume-Matcher。论文将其描述为结合岗位关键词、文本相似性、格式兼容性、技能匹配和经历相关性的 0—100 分系统。它是一个具体的软件基线，不能代表所有人工招聘者、所有简历评分模型或所有申请人管理系统。

论文没有给出该基线的 commit、实际语言模型、嵌入模型、提示与权重配置。因此，虽然项目本身公开，研究中生成 800 个分数的确切实现仍不能由一个仓库链接完整确定。[原文 §3.1](https://www.researchgate.net/publication/395809850_Uncovering_Candidate_Potential_with_Multi-Modal_AI_Assessments)

### AI Match Score

综合评分也在 0—100 范围内，使用结构化面试中的技能判断、现场题目、沟通与协作评价、岗位定制练习，以及简历中的经历信息。评分标准可以配置，或采用强调技术能力与岗位匹配的默认规则。

原文的 multi-modal 在方法描述中体现为多种评估材料。它没有给出可复现的音频、视频、图像编码器，或跨模态融合网络，因此不能根据标题补写一套视觉语音模型架构。现场面试的存在也不等于研究公开验证了面部表情或声学特征的增益。

综合分数怎样合成，各部分是否由同一模型评分，具体模型版本、调用温度、量表一致性和各岗位权重如何设置，论文均未充分披露。也没有移除某一种材料的消融，所以不能将总分差异归因于面试、现场题目或软技能中的某一个组成部分。

## 就业标签来自职业资料，而非岗位绩效

论文的 Hired 标签来自候选人的公开职业资料。研究先从简历解析 LinkedIn 地址，由招聘人员检查分析期间是否出现与所评角色相关的新职位；不明确的案例交由第二位人员复核并协商，缺少足够公开信息的资料在预处理阶段排除。[原文 §3.2、附录 B](https://www.researchgate.net/publication/395809850_Uncovering_Candidate_Potential_with_Multi-Modal_AI_Assessments)

这里有三项区别影响解释：

- 标签表示在观察期间进入相关职位，不一定是最初参与评估的那家企业录用了此人。
- 未观察到新职位不能自动等同于能力不足，候选人可能没有求职、没有接受机会，或没有及时更新资料。
- 获得工作与入职后的绩效、留任和协作表现是不同结果；本文没有后续绩效数据。

论文称标签经过核验，但没有给出具体观察起止日期、从评估到结果的间隔分布、标注者一致率，或相对于候选人自报和雇主记录的准确率。评分是否曾被相关招聘决策者看到也未明确说明。因此，不能排除分数与录用流程相互影响，更不能把关联解释为一种评分方式造成就业增加。

## 800 人的数据构成与筛选边界

| 分组 | 人数 | 占比 |
| --- | ---: | ---: |
| 技术岗位 | 730 | 91.2% |
| 非技术岗位 | 70 | 8.8% |
| 有相关新就业记录 | 507 | 63.4% |
| 未被标为 Hired | 293 | 36.6% |

每名候选人都有两种分数，形成配对比较。技术岗位占绝大多数，非技术岗位只有 70 人；汇总结果不能代替各行业、经验层级和地区的单独验证。[原文表 1](https://www.researchgate.net/publication/395809850_Uncovering_Candidate_Potential_with_Multi-Modal_AI_Assessments)

附录 B 报告缺失数据为 1.2%、没有重复记录，异常值被保留；正文又将最终数据称为完整观测。原文没有说明 1.2% 对应筛选前的人数、记录还是字段，也未交代填补规则和排除总数。不能从这个百分比反推原始招募人数。

排除没有足够公开就业信息的人，有助于明确标签，但也限制了样本覆盖。这批人都完成两种评估并具有可核查职业资料，结果不一定适用于没有完成面试或公开资料较少的候选人。论文没有提供从最初候选池到最终 800 人的完整流转表。

## AUC 与 AP 分别衡量什么

令 $s_i$ 为候选人分数，$y_i\in\{0,1\}$ 为就业标签。ROC 曲线通过改变分数阈值，比较正类被识别的比例与负类被误报的比例。AUC 可以用正负样本之间的排序解释：

$$
\widehat{\mathrm{AUC}}=
\frac{1}{n_+n_-}\sum_{i:y_i=1}\sum_{j:y_j=0}
\left(\mathbf 1[s_i>s_j]+\frac12\mathbf 1[s_i=s_j]\right).
$$

$n_+$ 与 $n_-$ 分别为两类人数，平分通常按半次正确排序处理。AUC 为 0.742 可以理解为随机抽取一名正类与一名负类时，分数较好地区分二者的排序统计量；它不是 74.2% 的候选人被分类正确，也不是分数为 74.2 的人有 74.2% 录用概率。上式用于解释标准指标，论文没有发表新的损失函数。

AP 是平均精确率，沿排序中的召回率增量加权精确率。常见写法为：

$$
\mathrm{AP}=\sum_k (R_k-R_{k-1})P_k,
$$

其中 $P_k$ 和 $R_k$ 是各运行点的精确率与召回率。原文没有公开计算脚本，因此无法核对它是否恰好采用这一实现，还是使用其他 PR 汇总方式。

AP 对正类占比敏感。这份样本的正类比例为 $507/800=63.375\%$，本身已经较高；不能把这里的 AP 直接外推到录用比例很低的筛选池。

### 主要数值

| 指标 | AI Match Score | 简历评分 |
| --- | ---: | ---: |
| AUC | 0.742 | 0.641 |
| AP | 0.841 | 0.735 |

来源为原文 §4.1—§4.2、附录表 5。两个分数在同一批人上比较，综合评分的点估计更高。但两者输入材料和评估成本不同，不能将其解释为等信息、等成本条件下只改变评分算法的增益。

公司所说的“提高 16%”，可以由展示值计算得到：

$$
\frac{0.742-0.641}{0.641}\approx15.8\%.
$$

这是 AUC 相对增幅的近似说法，不是分类正确率增加 16 个百分点。展示值相减为 0.101，原文表 3、表 5 则列出 0.102；两者可能涉及未展示的小数，但没有原始数值可确认。AP 差为 0.106，与表内报告一致。[公司结果说明](https://www.micro1.ai/research/uncovering-candidate-potential-with-multi-modal-ai-assessments)

## 分数平均更高，与更准确是两件事

原文表 2 给出两种分数的整体分布：

| 统计量 | AI Match Score | 简历评分 |
| --- | ---: | ---: |
| 平均值 | 66.88 | 59.74 |
| 标准差 | 17.68 | 26.01 |
| 中位数 | 68.00 | 61.64 |
| 第 25 百分位 | 54.00 | 41.36 |
| 第 75 百分位 | 82.00 | 80.72 |

综合评分的分布更集中。论文对同一候选人的两分之差做配对 t 检验，报告平均差 7.13、$t=7.07$、$p<10^{-11}$。这个检验回答两种分数是否存在平均偏移，**没有直接检验 AUC 差异是否显著**。

说明示例：如果给每个人的简历分数统一加 7 分，只要不发生截断，平均数就增加 7，而候选人排序及 AUC 完全不变。这个例子说明分数标尺的偏移不能替代预测能力检验。

### 配对检验可以用汇总量近似核查

设差值 $d_i=a_i-b_i$，差值标准差为 $s_d$，则：

$$
t=\frac{\bar d}{s_d/\sqrt n},\qquad
s_d^2=s_a^2+s_b^2-2r s_a s_b.
$$

将表中的两种标准差、Pearson 相关系数 $r=0.190$ 和 $n=800$ 代入，得到 $s_d\approx28.54$，再以平均差 7.13 计算，得到 $t\approx7.067$，与报告值接近。这是汇总数算术核查，不是重新读取 800 人数据的统计复现。

原文还给出 Cohen’s $d=0.321$。用两组边际标准差的合并尺度计算，$7.13/\sqrt{(17.68^2+26.01^2)/2}\approx0.321$；若使用配对差值的标准差，则 $d_z\approx0.250$。二者标准化分母不同，不能都笼统称为同一种配对效应量。

表中均值相减为 7.14，正文为 7.13。和 AUC 的差值一样，这里保留展示精度的差别，不用取整表反造原始逐人记录。

## 弱相关不等于已证明信息互补

原文报告两分之间 Pearson $r=0.190$、Spearman $\rho=0.171$。前者衡量线性关联，后者比较排序关联。两个数较低，说明这套评分不会总是把相同候选人排在相近位置。

但低相关本身不足以证明新增信息有效。一个随机分数也可能与简历分数相关很低；真正的信息增量需要进一步看加入它后，对就业标签的预测是否在保留数据上改善。更直接的检验可以比较只用简历、只用综合分，以及两者联合时的交叉验证表现。论文没有提供这种完整的联合模型增量分析。

同理，$r^2=0.0361$ 不能解释为“简历只包含候选人能力的 3.61%”。它仅涉及两个观测分数之间的线性关系，能力本身并没有一个在这里被直接测得的完整标尺。

### 分数差异的分组

原文用每名候选人的绝对分差划分一致性：

| 绝对分差区间 | 人数 | 比例 |
| --- | ---: | ---: |
| 不超过 5 分 | 100 | 12.5% |
| 表中标为 6—10 分 | 101 | 12.6% |
| 表中标为 11—20 分 | 212 | 26.5% |
| 超过 20 分 | 387 | 48.4% |

四组人数合计 800。但其中一种分数有小数，表内“6—10”“11—20”的简写没有明确 5 与 6 之间等边界如何归类；没有代码时不宜自行补充取整规则。[原文表 4](https://www.researchgate.net/publication/395809850_Uncovering_Candidate_Potential_with_Multi-Modal_AI_Assessments)

这张表测量的是分数标尺差异，不是招聘决定的一致率。两套分数的均值与方差本来就不同，即使排序比较接近，绝对分差也可能很大。把分差超过 20 分直接称为一方“判错”，还需要就业标签和明确决策阈值。

## “被简历遗漏的人”需要明确判定条件

论文和公司文章讨论简历分低、综合分高的一组候选人，并使用“接近两倍”的概括。正文将其解释为简历筛选可能遗漏的人员，另有综合分较低的一组。

在可读取的正文和表格中，没有找到足以独立重建这个倍率的完整人数、统一筛选阈值和逐组就业列联表。图 5 的内嵌数字未能在网页全文中读取，因此这里不把“接近两倍”转化为一个已复算的业务收益。

即使按照分差划组，组名也不构成独立的能力真值。综合分较高不能单独证明候选人具备更强能力；要判断某个筛选规则遗漏多少最终就业者，应明确规则、阈值、分母，并计算实际标签下的漏报。本文没有对这些规则开展随机上线对照。

## 统计流程披露到什么程度

方法部分列出交叉验证 AUC/AP、校准曲线、bootstrap 与非参数检查。表 4 报告两种分数的 Shapiro–Wilk 正态性检验均拒绝正态假设，但正文和附录未给出以下完整信息：

| 环节 | 未充分披露的内容 |
| --- | --- |
| 交叉验证 | 折数、拆分单位、岗位或候选人的分组、重复次数、调参位置 |
| AUC 差异 | 成对区间、检验方法、折内汇总和原始排序 |
| bootstrap | 重采样次数、单位、区间端点及是否保持候选人配对 |
| 校准 | 从 0—100 分转换为概率的过程、分箱与具体误差值 |
| 标签验证 | 双人一致率、复核数量、随访窗口与排除流转 |
| 泛化 | 新企业、新地区、新时期以及非技术岗位的独立测试 |

因此，不能依据一个配对 t 检验的很小 p 值，就为 AUC 差、潜在人才数量和招聘收益同时赋予显著性。原文附录 A 对统计效力有概括描述，但没有给出可重算的功效分析或关键性能区间。
