# LongExtractionBench：长文档结构化抽取

在相同的长篇密集文档上比较七种生产级抽取系统。

| 项目 | 信息 |
| --- | --- |
| 时间 | 首发日期未确认 |
| 类型 | 合作基准 |
| 公司参与 | Reducto 委托；micro1 选取文档、人工核实并发布结果 |

## 工作内容

225 份文档平均约 358 页，包含重复表格和大量字段。参考标签由模型直接阅读原文生成，人工处理分歧并抽查一致项；确定性评分器分别计算精度、召回与字段准确性。

## 数据与使用范围

报告分别展示完成文档上的准确度、运行失败、不支持的输入和延迟。Reducto 设计初始参考标签及运行评分方法，micro1 进行方法核查；本页明确委托关系，避免误称完全独立发起。
