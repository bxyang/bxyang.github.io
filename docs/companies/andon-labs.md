# Andon Labs

通过模拟基准和现实部署，研究 agent 的长期任务执行、空间理解与自主经营。

## 创始人背景

**Axel Backlund 与 Lukas Petersson** 共同创办 Andon Labs。两人来自瑞典，是高中同学，后来分别就读大学并继续合作技术项目。Petersson 曾在 ETH Zürich 学习 AI，并有 Google 和 Disney Research 经历；Backlund 的经历侧重工程和 AI 评测。[创始人采访](https://observer.com/2026/05/andon-labs-ai-agent-managing-brick-and-mortar/)

Y Combinator 将公司成立时间列为 **2023 年**、加速器批次列为 **Winter 2024**。两项日期分别对应公司创办和参加加速器。[YC 公司资料](https://www.ycombinator.com/companies/andon-labs)

## 发展过程

- **2023—2024 年**：成立公司，参加 Y Combinator W24，开展 AI 控制与 agent 评测。
- **2025 年 2 月**：发布 Vending-Bench；6 月与 Anthropic 公开真实售货机实验 Project Vend。
- **2025 年下半年**：发布 Blueprint-Bench、Butter-Bench 和 Vending-Bench 2 / Arena。
- **2026 年**：公开商店、咖啡馆、电台及 Drone-Bench 等实验。[官方时间线](https://andonlabs.com/)

## 目前的主营业务

公司为模型开发者研究和测试 agent，也运营小规模现实实验来记录系统行为。模拟评测强调可重复比较；现实部署观察供应、顾客、员工和工具限制带来的实际问题。

其商店、电台和咖啡馆属于研究部署，不是可以直接下载的标准化 benchmark。两类工作在时间线中分开标注。
