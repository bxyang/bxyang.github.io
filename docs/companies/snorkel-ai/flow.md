# Snorkel Flow：程序化数据开发

将标注、数据分析和模型迭代组织在同一平台中。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2020 |
| 类型 | 产品 |
| 公司参与 | Snorkel AI 开发 |

## 工作内容

用户定义数据任务，编写或管理标注规则，检查模型和标签的错误，再根据结果改进数据。平台也提供人工标注工作批次、提示开发及评测入口，连接领域专家和模型开发者。 [资料](https://docs.snorkel.ai/docs/25.4/user-guide/intro/welcome-to-snorkel-flow)

## 数据与使用范围

2020 年推出商业平台，后续版本持续扩展。当前功能以对应版本的官方文档为准；商业平台与学术弱监督算法不能等同。 [资料](https://docs.snorkel.ai/docs/25.4/user-guide/intro/welcome-to-snorkel-flow)
