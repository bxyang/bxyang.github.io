# RIFT：诊断评分标准本身的八类问题

原论文：[RIFT: A RubrIc Failure Mode Taxonomy and Automated Diagnostics](https://arxiv.org/abs/2604.01375v2)。本文依据 2026 年 4 月 20 日的 v2。

## 1. 摘要翻译

以下为 Qi 等人 v2 摘要的中文译文，原文采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，改动为翻译。[原文与许可](https://arxiv.org/abs/2604.01375v2)

基于评分标准的评估广泛用于语言模型基准和训练流程，尤其适合开放式、较难直接验证的任务。尽管已有研究利用强化学习结果等下游信号展示了评分标准的有效性，但仅凭这些汇总信号或下游信号，仍缺少一种有原则的方法来诊断评分标准本身如何失效。

为弥补这一缺口，我们提出 RIFT，即 RubrIc Failure mode Taxonomy，用于系统描述评分标准在构成和设计方面的失效模式。RIFT 包含八种失效模式，归入三个大类：可靠性失效、内容效度失效和后果效度失效。

RIFT 采用扎根理论构建：对来自五种不同数据来源的评分标准反复标注，这些来源覆盖通用指令遵循、代码生成、创意写作和专家级深度研究，直到不再发现新的失效模式。我们通过测量独立人工标注者之间的一致性来评估分类的一致性，观察到总体上尚可的一致程度：两两一致率为 87%，平均 Cohen’s kappa 为 0.64。最后，为支持规模化诊断，我们提出自动化评分标准质量指标，并表明它们与人工失效模式标注相吻合，最高 F1 达到 0.925。

## 2. 研究背景与相关研究

开放式回答往往没有唯一正确答案。评分标准因此把目标拆成一组可以检查的要求，再由人或模型裁判逐项判断。不过，得分是否可靠同时取决于标准、裁判和任务本身。训练效果变好，或模型裁判与人更一致，并不能单独说明评分标准设计正确。

Related Work 回顾了任务专用 rubric、自动生成评分标准、基准可靠性与失效分类研究。已有工作更多关注如何生成或使用评分标准，以及最终评估结果是否可靠。RIFT 则借用测量理论区分三个问题：标准能否得到一致解释，是否覆盖真正要测的内容，以及使用之后是否产生有意义的区分和激励。[第 1—2 节](https://arxiv.org/pdf/2604.01375v2#page=1)

## 3. 核心贡献

**核心问题。** 在不把问题都归因于模型裁判的前提下，具体识别评分标准的设计缺陷，使修改标准有明确依据。

**核心方案。** 三名专家在四轮迭代中分析 85 组评分标准，边标注边修订类别，形成八种失效模式。可靠性问题包括措辞主观、多个要求捆绑而难以分别评分，以及缺少核验依据；内容效度问题包括评价目标偏离或限制过死、遗漏必要要求；后果效度问题包括可被钻空子、无法区分质量，以及重复评价同一要求。例如，把“清晰、全面、有创意”合成一项，既可能解释不一致，也难以判断部分满足时应得多少分。[第 3 节、表 1](https://arxiv.org/pdf/2604.01375v2#page=3)

作者还测试自动诊断：直接让模型按分类体系判断、汇总多次判断，以及利用裁判一致性、与参考裁判的一致程度和分数变化等信号寻找问题。这些信号与专家标注进行比较，用于判断哪些缺陷更容易自动发现。

**结论。** 分类体系具有一定人工一致性，但不同类别的分歧仍然存在。自动方法对主观措辞等问题较有效，最高 F1 0.925 对应其中一种类别和设置，不是全部八类问题的总体检测水平；“可钻空子”等问题仍较难识别。部分连续指标的最佳阈值是在测试集上选择，因此这些分数更适合展示信号潜力，不能视为新数据上的已验证部署效果。论文支持将自动诊断与有针对性的专家复核结合，逐步修订评分标准。[第 4—5 节](https://arxiv.org/pdf/2604.01375v2#page=5)
