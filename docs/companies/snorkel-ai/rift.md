# RIFT：评分标准的失败分类

检查 rubric 本身是否可靠、覆盖正确内容并产生合适的评价。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-04-01 |

| 公司参与 | Snorkel 研究团队发布 |

## 工作内容

研究通过反复标注来自五类数据来源的 rubric，整理八种失败模式，分为可靠性、内容效度和后果效度三组。再设计自动诊断指标，比较其判断与人工标注的一致性。 [资料](https://arxiv.org/abs/2604.01375)

## 数据与使用范围

样本覆盖指令遵循、代码、创作及专家研究。诊断对象是评分标准，而不是直接对被评分模型排名；文中的最高 F1 对应特定失败类别与实验。 [资料](https://arxiv.org/abs/2604.01375)
