# Learning from Less：少数据 RLVR

研究训练样本数量、多样性和难度如何影响小模型的强化学习。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-04-20 |
| 类型 | 论文 |
| 公司参与 | Snorkel 研究团队发布 |

## 工作内容

使用可程序生成的计数、图推理和空间推理任务，分别控制数据量、难度和多样性。实验比较只用简单任务与混合难度训练，检查模型能否迁移到更复杂任务。 [资料](https://arxiv.org/abs/2604.18381)

## 数据与使用范围

混合难度数据在部分低数据设置下达到更高样本效率。研究给出的是这些可验证任务上的经验结果，不把“最多五倍”当成所有领域的固定收益。 [资料](https://arxiv.org/abs/2604.18381)
