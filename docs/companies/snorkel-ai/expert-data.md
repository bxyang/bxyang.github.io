# Snorkel Expert Data-as-a-Service

组织外部专家为模型开发者制作专业训练与评测数据。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-05-29 |
| 类型 | 产品与服务 |
| 公司参与 | Snorkel AI 运营 |

## 工作内容

服务把专业人员的知识转成任务、回答和评分标准，再通过程序化检查与人工复核管理数据质量。它与客户自行使用 Flow 或 Evaluate 的模式不同，交付内容包含按项目制作的数据。 [资料](https://snorkel.ai/blog/building-the-ai-data-development-platform-for-specialized-ai/)

## 数据与使用范围

发布公告覆盖 STEM、职业领域和消费场景。专业覆盖与单项数据交付规模并不相同；具体任务、数据许可及验证流程由项目确定。 [资料](https://snorkel.ai/blog/building-the-ai-data-development-platform-for-specialized-ai/)
