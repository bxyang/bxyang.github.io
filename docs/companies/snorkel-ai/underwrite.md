# UNDERWRITE：保险核保环境

结合内部业务知识、工具与用户沟通评测保险核保 agent。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-01-31 |
| 类型 | 基准 |
| 公司参与 | Snorkel 研究团队与领域专家设计 |

## 工作内容

任务要求检索专有规则、使用可能含噪声的工具，并向并不总能完整回答问题的模拟用户收集信息。环境将核保流程组织为多轮操作，评价答案、效率和重复运行的可靠性。 [资料](https://arxiv.org/abs/2602.00456)

## 数据与使用范围

论文比较 13 个模型，发现高准确率与高效率并不总是同时出现。专有业务知识和交互细节属于任务的一部分，不能用普通保险知识问答成绩替代。 [资料](https://arxiv.org/abs/2602.00456)
