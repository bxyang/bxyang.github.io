# Liger：结合基础模型表示与弱监督

利用基础模型的嵌入，提高弱标签来源的质量估计和覆盖率。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2022-03-24 |

| 公司参与 | Ré、Sala 等共同研究；收录于 Snorkel 官方研究目录 |

## 工作内容

Liger 将嵌入空间分区，分别估计弱监督来源在不同区域的准确率，再沿相近的嵌入扩展标注来源的覆盖范围。方法结合基础模型表达的信息与规则、已有模型或人工提供的弱标签。 [资料](https://arxiv.org/abs/2203.13270)

## 数据与评测

研究在六个自然语言与视频任务上比较普通弱监督、弱监督近邻方法及适配器。理论分析说明改进与嵌入空间中标签分布的平滑程度有关。 [资料](https://arxiv.org/abs/2203.13270)

## 结果与公开范围

论文报告相对普通弱监督平均提升 14.1 个点，发表于 UAI 2022。公司目录将其列为专家知识扩展方向的研究；本文保留其学术合作属性。 [资料](https://arxiv.org/abs/2203.13270)
