# 弱到强泛化的数据选择

研究什么样的数据能够让弱模型的标签帮助更强模型学习。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-12-05 |
| 类型 | 合作论文 |
| 公司参与 | Snorkel 研究目录收录，Frederic Sala 等署名 |

## 工作内容

论文提出重叠密度：同一样本同时具有弱模型容易学会的模式和更强模型才能学习的模式。研究设计检测算法寻找这类样本，再在多个数据来源中选择更有助于泛化的数据。 [资料](https://arxiv.org/abs/2412.03881)

## 数据与使用范围

工作包含理论界限和实验检验，后发表于 ICLR 2025。它研究数据选择机制，不是现成商业数据集；公司关联以官方目录和作者身份为依据。 [资料](https://arxiv.org/abs/2412.03881)
