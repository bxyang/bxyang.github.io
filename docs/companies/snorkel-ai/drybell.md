# Snorkel DryBell：企业知识的弱监督转换

把企业已有规则、资源和模型转成弱监督训练信号。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2018-12-02 |
| 类型 | 创办前合作论文与系统 |
| 公司参与 | Stanford 与 Google 合作；Ratner、Hancock、Ré 共同参与 |

## 工作内容

DryBell 在 Snorkel 框架上增加模板式知识接入、跨特征服务和无需采样的执行方式。部分企业资源只能在训练阶段使用，系统将它们提供的监督转化为上线模型能够使用的预测能力。 [资料](https://arxiv.org/abs/1812.00417)

## 数据与评测

研究在 Google 的三个分类任务上验证，处理百万级数据点的运行时间为数十分钟。对照包含使用数万个人工标签训练的分类器。 [资料](https://arxiv.org/abs/1812.00417)

## 结果与公开范围

论文报告弱监督模型达到与这些人工标注模型相近的质量。该工作是公司成立前的工业合作研究，并非 Snorkel AI 当时已出售的产品。 [资料](https://arxiv.org/abs/1812.00417)
