# Data Programming：把标注规则变成概率训练标签

一组规则可以很快标出大量数据，但规则会漏标、相互冲突，也可能重复表达同一条知识。Data Programming 用概率模型描述这些标注来源，估计它们的质量和依赖关系，再把不确定的标签交给下游分类器训练。

这篇论文提出的是一种训练数据制作方法。领域专家编写可以重复执行的标注函数，系统负责合并它们提供的信号。论文同时给出了参数恢复的理论条件，以及新闻、基因组学和药物基因组学中的关系抽取实验。

## 规则怎样变成标注函数

论文考虑二分类，真实标签为 $Y\in\{-1,+1\}$。每个标注函数可以投正票、投负票，或者弃权：

$$
\lambda_i:\mathcal X\rightarrow\{-1,0,+1\}.
$$

这里的 0 表示没有给出标签，不表示负类。对 $n$ 个候选样本运行 $m$ 个函数，得到一个 $n\times m$ 的标签矩阵 $L$，其中 $L_{ji}=\lambda_i(x_j)$。

例如，判断一句话是否明确表达两个实体之间的关系，可以使用三类信号：知识库中是否已有这个实体对、句子是否出现支持关系的表达、句子是否出现否定表达。每种信号都只覆盖部分情况，知识库中存在关系也不保证当前句子正在表达它。

以下是用于说明接口的简化代码，不是论文实验中的完整规则：

```python
ABSTAIN, NEGATIVE, POSITIVE = 0, -1, 1

def known_pair(x):
    return POSITIVE if x.entity_pair in known_relations else ABSTAIN

def explicit_negation(x):
    return NEGATIVE if "does not cause" in x.text else ABSTAIN
```

这两个函数可能在同一个样本上冲突。传统的 `if-then-return` 做法按固定顺序执行规则，采用第一个非空标签；顺序变动可能改变训练数据。论文将这一方法记为 ITR，并在实验中保留相同规则集合，改变规则输出的合并方式。[第 3 节与第 5 节](https://arxiv.org/pdf/1605.07723v3#page=3)。

## 条件独立模型怎样估计标签质量

先考虑一个简化模型：给定真实类别后，各标注函数独立。每个函数有两个参数：

- $\beta_i$：覆盖率，即给出非零标签的概率。
- $\alpha_i$：给出标签时，判断正确的概率。

模型还假设两个类别的先验概率各为 $1/2$。单个函数的条件分布为：

$$
P(\Lambda_i=\ell\mid Y=y)=
\begin{cases}
\beta_i\alpha_i,&\ell=y,\\
\beta_i(1-\alpha_i),&\ell=-y,\\
1-\beta_i,&\ell=0.
\end{cases}
$$

因此，所有函数输出与真实类别的联合概率可以写成：

$$
\mu_{\alpha,\beta}(\Lambda,Y)
=\frac12\prod_{i=1}^{m}P(\Lambda_i\mid Y).
$$

真实类别没有观测到，但标签矩阵已经可见。学习时对两个可能类别求和，最大化观测到这些函数输出的概率：

$$
(\hat\alpha,\hat\beta)
=\arg\max_{\alpha,\beta}
\sum_{x\in S}\log\sum_{y\in\{-1,+1\}}
\mu_{\alpha,\beta}(\lambda(x),y).
$$

这就是论文式（1）和式（2）的作用：从规则输出的一致、冲突与覆盖模式中估计参数。它并不是先获得每条规则的人工测量准确率，再做加权投票。参数能否从这些观测中恢复，取决于后面介绍的模型假设。[第 3 节，式（1）—（2）](https://arxiv.org/pdf/1605.07723v3#page=4)。

### 概率标签的一个计算例子

在上述对称、条件独立模型中，后验的对数几率可以由联合分布直接推得：

$$
\log\frac{P(Y=+1\mid\Lambda)}{P(Y=-1\mid\Lambda)}
=\sum_{i:\Lambda_i\ne0}\Lambda_i\log\frac{\alpha_i}{1-\alpha_i}.
$$

这是本文对论文式（1）的展开。覆盖率因子在这一次后验比较中抵消，弃权函数不贡献方向性票数；这并不表示覆盖率对参数学习或数据质量没有影响。

假设三个相互独立的函数准确率分别为 0.9、0.7、0.7，当前投票为 $+1,-1,-1$。则后验正类几率为：

$$
\frac{0.9}{0.1}\left(\frac{0.3}{0.7}\right)^2
=\frac{81}{49},\qquad
P(Y=+1\mid\Lambda)=\frac{81}{130}\approx0.623.
$$

简单多数票会选择负类，概率模型在这些假定参数下偏向正类，但只给出约 62.3% 的概率。这个数字是教学示例，不是论文数据上的结果，也不用于满足后文定理中的特定参数区间。

## 概率标签怎样训练分类器

生成模型给样本 $x$ 一个概率 $q_x=P(Y=+1\mid\lambda(x))$。下游分类器使用样本特征 $f(x)$，得到分数 $s_x=w^Tf(x)$。论文将普通逻辑损失改为对标签后验求期望：

$$
\mathcal L(w)=\frac1{|S|}\sum_{x\in S}
\left[q_x\log(1+e^{-s_x})+(1-q_x)\log(1+e^{s_x})\right]
+\rho\|w\|_2^2.
$$

其中 $\rho$ 是正则化系数。标签概率接近 1 时，样本主要按正类训练；接近 0 时主要按负类训练；接近 0.5 时，训练目标保留较大的不确定性。把所有概率直接截成硬标签，会改变这个目标。

两个模型承担的任务也不同：生成模型学习标注来源的统计性质，下游判别模型学习文本特征与类别的关系。论文分别采用人工特征和 LSTM 学到的特征。这里的“生成模型”是对标签与规则输出联合分布的建模，不是生成文本的大语言模型。[第 3 节，式（3）](https://arxiv.org/pdf/1605.07723v3#page=4)。

## 规则存在依赖时的处理

如果两条规则来自几乎相同的词典，或者一条规则专门修正另一条规则，它们的票数就不应被视为独立证据。论文允许开发者提供依赖图，并为四类关系设置因子：

| 依赖类型 | 表达的关系 |
| --- | --- |
| Similar | 两个函数倾向于给出相同输出 |
| Fixing | 后一个函数主要在前一个函数触发时工作，并修正其错误 |
| Reinforcing | 后一个函数在前一个函数覆盖的部分样本上进一步支持正确判断 |
| Exclusive | 两个函数倾向于不同时给出非零标签 |

依赖关系的结构由用户指定，系统学习对应的强度。不能把这一版本的方法写成能够自动发现任意依赖图。

加入依赖后，联合分布写成因子图形式：

$$
\mu_\theta(\Lambda,Y)
=\frac{\exp(\theta^Th(\Lambda,Y))}{Z_\theta}.
$$

$h$ 是因子组成的向量，$\theta$ 是待学习的权重，$Z_\theta$ 负责归一化。例如，相似性因子可以是 $\mathbf1\{\Lambda_i=\Lambda_j\}$；修正关系包含 $\mathbf1\{\Lambda_i=-Y,\Lambda_j=Y\}$，还包含约束后一个函数覆盖范围的因子。

模型仍然通过边缘似然学习，再输出概率标签。论文描述的优化使用随机梯度，并借助 Gibbs 采样估计期望。依赖建模增加了计算工作，不意味着任意复杂的依赖都已经得到高效学习的保证。[第 4 节](https://arxiv.org/pdf/1605.07723v3#page=6)。

## 理论保证的范围

论文证明，在一组明确条件下，增加未标注数据可以同时降低参数估计误差与下游期望损失。它没有证明任意几条规则都能恢复真值。

独立模型的简化定理使用了较强的设置：规则准确率在 $[0.8,0.9]$，覆盖率在 $[0.3,0.5]$，并给出 $m\ge2000$ 的充分条件。这不是实际使用必须编写 2,000 条规则的要求；实验中的规则数远小于它。附录 B 给出了随参数变化的更完整充分条件。[定理 1 与附录 B](https://arxiv.org/pdf/1605.07723v3#page=5)。

理论还要求真实标签生成过程属于所设模型族，并包含下列条件独立假设：

$$
Y\perp f(X)\mid\lambda(X).
$$

它表示：给定所有标注函数输出后，特征不再提供额外的类别信息。这是连接概率标签训练损失与真实风险的重要条件。实际文本任务是否满足这一假设，不能仅凭训练程序能够运行来判断。

带依赖的理论还要求可行参数集合具备可估计性，并对给定规则输出后的类别不确定性设上界。在这些条件及下游优化误差上界 $\chi$ 下，论文给出：

$$
\mathbb E\|\hat\theta-\theta^*\|^2\le M\epsilon^2,
\qquad
\mathbb E[\ell(\hat w)-\min_w\ell(w)]
\le\chi+\frac{c\epsilon}{2\rho}.
$$

这里 $M$ 是参数维数，$c$ 来自理论条件。达到相应误差所需的未标注样本量按 $\widetilde O(\epsilon^{-2})$ 增长，波浪号省略对数项。“与监督学习相同的渐近量级”比较的是这种增长关系，不代表有限样本下准确率相同，也不代表规则编写没有成本。[定理 2、附录 A—F](https://arxiv.org/pdf/1605.07723v3#page=7)。

### 证明怎样连接两个阶段

附录先对边缘对数似然求导，把梯度写成两个期望之差；再用条件方差与 Fisher 信息的约束建立目标函数的强凹性。这样可以控制随机梯度优化后的参数误差。

随后，证明比较使用估计标签分布和真实标签分布得到的逻辑损失，利用特征有界、条件独立和正则化条件，把参数误差转换为下游风险误差。因此，参数估计与分类效果之间的联系来自这些条件共同成立，并非“去噪”这个名称本身。[附录 C—D](https://arxiv.org/pdf/1605.07723v3#page=13)。

## 三组关系抽取实验

实验先从文本中抽出实体及候选实体对，再判断当前文本是否真正表达目标关系。新闻任务使用 TAC-KBP 2014；另两组任务分别涉及基因突变与表型的关系，以及基因之间的相互作用。

正文表 1 使用同一组标注函数，比较 ITR 与 Data Programming。以下列出原表 F1，分数按 0 至 100 表示，差值是 F1 点数：

| 特征 | 任务 | ITR | Data Programming | 差值 |
| --- | --- | ---: | ---: | ---: |
| 人工特征 | 新闻 | 35.10 | 37.02 | +1.92 |
| 人工特征 | 基因组学 | 55.65 | 57.24 | +1.59 |
| 人工特征 | 药物基因组学 | 57.23 | 60.83 | +3.60 |
| LSTM | 新闻 | 32.66 | 35.78 | +3.12 |
| LSTM | 基因组学 | 58.52 | 58.99 | +0.47 |
| LSTM | 药物基因组学 | 37.23 | 42.17 | +4.94 |

这些结果说明，在所测任务和规则集合下，改变标签合并方式改善了下游 F1。它不表示每个指标都同时提高。例如，新闻 LSTM 的精确率从 37.68 升到 47.47，召回率却从 28.81 降到 27.88；总体 F1 仍然提高。[表 1](https://arxiv.org/pdf/1605.07723v3#page=7)。

论文另报相对一项既有 LSTM 方法提高 5.98 F1 点，这个对照不是表中的 ITR LSTM，不能把 5.98 和表内的 3.12 混用。关于 TAC-KBP 名次，作者是在既有挑战赛结果上作回顾性比较，不是报告本研究当年实际参赛获奖。附录还说明，论文新闻模型没有包含原 2014 参赛系统的联合因子。[第 5 节与附录 G.1](https://arxiv.org/pdf/1605.07723v3#page=8)。

### 规则覆盖了多少数据

| 任务 | 函数数 | 覆盖率 | 至少获得一个标签的候选数 | 重叠率 | 冲突率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 新闻 | 40 | 29.39% | 约 203 万 | 1.38% | 0.15% |
| 基因组学 | 146 | 53.61% | 约 25.6 万 | 26.71% | 2.05% |
| 药物基因组学 | 7 | 7.70% | 约 12.9 万 | 0.35% | 0.32% |
| 疾病提及识别 | 12 | 53.32% | 约 41.8 万 | 31.81% | 0.98% |

覆盖率表示至少有一个函数投票的对象比例，重叠率表示有多个函数投票的比例，冲突率表示存在相反投票的比例。表中的候选数不是手工标注的测试集大小，也不是原始文档数。重叠为模型提供了比较不同来源的机会，但过多的重复来源也可能形成依赖。[表 2](https://arxiv.org/pdf/1605.07723v3#page=8)。

## 依赖实验与用户研究

合成数据实验使用固定覆盖率 0.1，规则准确率从均值为 0.75、范围为 $[0.5,1.0]$ 的均匀分布抽取。图 3a、3b 分别使用 20 和 100 个函数，比较 Data Programming、最优排序的 ITR 和简单多数票。这里的“最优排序”是一种有额外信息的对照条件，不是普通用户可以直接获得的规则排序。

图 3c 从 50 个独立函数出发，逐步添加修正或强化类型的依赖函数。提供依赖结构的模型比仍按独立性处理的模型取得更高 F1。正文还报告，疾病提及识别任务加入依赖信息提高了 2.3 F1 点。这些实验支持在所测依赖类型中使用依赖信息，并未检验全部可能的图结构。[附录 G.2 与图 3](https://arxiv.org/pdf/1605.07723v3#page=27)。

用户研究让几位生物信息学研究人员用不到八小时构建疾病识别训练数据。他们迭代标注函数和候选抽取过程，没有手工标注训练集或做特征工程；最终模型与监督基线的差距在 10 F1 点以内，作者将主要差距归于候选抽取的召回问题。

这是初步的黑客松观察，不是大样本、随机分组的生产率实验。正文没有给出足以估计普遍时间节省比例的对照设计，也没有为主结果表报告重复运行方差。[第 5 节用户研究](https://arxiv.org/pdf/1605.07723v3#page=8)。

## 代码与复现细节

本文检查了与论文 v3 时间接近的 Snorkel 提交 `f98686610b0b13f81ea52969416f269447fd57dc`。这是一份历史代码快照，不能据此认定它就是作者生成所有论文表格的确切提交。

该版本 README 标记为 v0.4.0，使用 Python 2.7；生成模型依赖 NumbSkull，论文附录描述的 LSTM 使用 Theano。它与后续版本的接口及依赖不同，直接安装现在的 Snorkel 不等于复现 2016 年实现。[历史 README](https://github.com/snorkel-team/snorkel/blob/f98686610b0b13f81ea52969416f269447fd57dc/README.md)。

`GenerativeModel.train` 接收标签矩阵与依赖关系，编译因子图并交给 NumbSkull 学习；`marginals` 根据学到的参数返回每个样本属于正类的概率。代码默认值包括 100 个 epoch、步长 0.001、衰减 0.99 和 burn-in 50。这些是所读提交的函数默认值，论文没有确认所有实验都使用这些默认值。[生成模型实现](https://github.com/snorkel-team/snorkel/blob/f98686610b0b13f81ea52969416f269447fd57dc/snorkel/learning/gen_learning.py)。

复现主表还需要固定候选生成、CoreNLP 预处理、知识库快照、规则集合与顺序、依赖图、人工评估集和下游模型设置。附录指出，基因组学合作项目有部分材料未公开，因此不能仅凭 Snorkel 仓库完整重跑所有应用实验。[附录 G.1](https://arxiv.org/pdf/1605.07723v3#page=26)。

### 附录伪代码的梯度方向需要核对

根据附录 Lemma D.1，若 $J(\theta)$ 是观测标签的对数似然，则：

$$
\nabla J(\theta)
=\mathbb E_\theta[h\mid\Lambda=\lambda(x)]
-\mathbb E_\theta[h].
$$

最大化它应沿这个方向更新，或者对负对数似然执行梯度下降。但 v3 第 12 页 Algorithm 1 将无条件样本写在前、条件样本写在后，并对它们的差使用加号，与后面的梯度公式方向相反。

这是本文核对伪代码和推导发现的不一致。本文另外用一个可精确枚举的小型指数族模型做了有限差分检查，确认梯度为“条件期望减无条件期望”；并未据此判断原实验训练实现也有相同问题。自行实现时应从所优化的目标核对符号，而非机械复制该行伪代码。[Algorithm 1](https://arxiv.org/pdf/1605.07723v3#page=12)，[Lemma D.1 及推导](https://arxiv.org/pdf/1605.07723v3#page=15)。
