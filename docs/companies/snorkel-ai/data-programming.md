# Data Programming：把标注规则变成概率训练标签

原论文：[Data Programming: Creating Large Training Sets, Quickly](https://arxiv.org/abs/1605.07723v3)。本文依据 arXiv v3（2017 年 1 月 8 日）；论文发表于 NIPS 2016。

## 0. 作者与机构背景

第一作者 **Alexander Ratner** 当时在斯坦福大学攻读博士，研究如何用领域规则等不完全准确的监督信息减少人工标注。他在博士阶段发展了 Data Programming 和后续的 Snorkel 系统。这也是他后来联合创办 Snorkel AI 的研究基础。[斯坦福 Bio-X 介绍](https://biox.stanford.edu/people/alexander-ratner)

第二作者 **Christopher De Sa** 当时也在斯坦福大学，2017 年获得电气工程博士学位，导师为 Kunle Olukotun 和 Christopher Ré。他的研究侧重机器学习中的随机算法及其高效、并行实现。[个人主页](https://www.cs.cornell.edu/~cdesa/)与[履历](https://www.cs.cornell.edu/~cdesa/papers/cdesa-cv.pdf)

五位作者均署名斯坦福大学，合作领域涵盖机器学习、数据管理和领域信息抽取。Snorkel AI 于 2019 年成立，因此这篇论文属于公司创办前的学术研究；收录在公司研究中，是因为它构成了 Snorkel 方法的早期基础，不能据此写成公司在 2016 年发布的成果。[公司历史](https://snorkel.ai/company/)

## 1. 摘要概述

原文 arXiv 版本采用[非独占分发许可](https://arxiv.org/licenses/nonexclusive-distrib/1.0/)，未确认完整译文的再发布授权，以下为概述。

论文提出用程序生成训练标签：用户把弱监督策略或领域知识写成标注函数，系统通过生成模型处理函数产生的噪声与冲突，再训练能够考虑标签不确定性的分类器。作者在若干条件下证明了模型参数可以恢复，并在关系抽取任务中验证方法。TAC-KBP 实验及初步用户研究表明，这种方式有潜力减少制作训练数据的负担。[原摘要](https://arxiv.org/abs/1605.07723v3)

## 2. 研究背景与相关研究

深度学习能减少手工设计特征的工作，却仍需要大量带标签的数据。在生物医学等任务中，标注者必须具备专业知识；任务定义一旦改变，训练数据还可能需要重新制作。论文希望让专家直接表达可重复使用的判断规则，而不必逐条标注所有样本。

Introduction 和 Related Work 将已有方法分为几条路线。**远程监督**用知识库中的已有关系给文本打标签，但知识库里存在某个关系，并不代表每一句提到相关实体的文本都表达这个关系。已有规则方法也会产生类似噪声，且往往缺少统一处理规则冲突的方式。**众包标签模型**研究如何在没有真实答案时估计标注者的准确率，为本文提供了重要基础；这里的监督来源则可以是程序、词典和知识库，且少量程序能够覆盖大量数据。

论文还讨论了协同训练、Boosting 和带噪标签学习。本文的重点是把多个可能重叠、冲突和相关的监督来源放进同一个框架，并将它们的输出转化为可供不同分类模型使用的训练数据。[第 1—2 节](https://arxiv.org/pdf/1605.07723v3#page=1)

## 3. 核心贡献

**核心问题。** 多条规则的覆盖范围和准确率不同，还可能重复表达同一条知识。简单投票或按固定顺序采用第一条规则，都难以稳定地合并这些信息。作者要解决的是：在没有逐条人工标注训练集的情况下，如何利用规则间的一致与冲突来估计监督信号的质量。

**核心方案。** 用户编写“标注函数”：每个函数对一条数据给出类别，或在没有把握时弃权。例如，知识库可以提示某个基因与疾病有关，句中的否定表达则可以给出反向信号。系统先把所有函数运行在未标注数据上，再用生成模型估计它们的准确率及用户指定的依赖关系，得到每条样本属于不同类别的概率。下游分类器根据这些概率训练，而不是把每个自动标签当成完全正确的答案。论文既分析了条件独立的情形，也扩展到规则互相修正、强化等依赖关系。[第 3—4 节](https://arxiv.org/pdf/1605.07723v3#page=3)

**结论。** 在新闻、基因组学和药物基因组学的关系抽取实验中，方法相对远程监督基线平均提高 2.34 个 F1 点；结合 LSTM 的 TAC-KBP 实验相对对应 LSTM 基线提高 5.98 个 F1 点。这里的比赛名次是使用历史任务结果作比较，并非重新参加当年的比赛。理论分析表明，在标注函数质量、模型可识别性等条件成立时，可以随未标注数据增加获得与监督学习相近的渐近学习速率。结论支持的是在这些条件下利用规则扩展训练数据，不是任意规则都能自动变成准确标签。[第 3—5 节](https://arxiv.org/pdf/1605.07723v3#page=4)
