# FlyingSquid：快速估计弱标签质量

用闭式估计替代反复迭代，提高弱监督标签模型的训练速度。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2020-02-27 |
| 类型 | 学术关联论文与开源框架 |
| 公司参与 | Ré、Sala 等学术团队研究；延续 Snorkel 弱监督方法 |

## 工作内容

方法利用三元组关系估计一类潜变量模型的参数，由此推算不同噪声标注来源的准确率，再生成概率标签。与依赖随机梯度下降的做法相比，它减少了反复优化和调参的过程。 [资料](https://arxiv.org/abs/2002.11955)

## 数据与评测

研究在弱监督基准上比较模型质量与估计时间，并在不要求潜变量模型完全符合真实分布的条件下分析泛化误差。应用实验还涉及视频分析和在线学习。 [资料](https://arxiv.org/abs/2002.11955)

## 结果与公开范围

论文报告平均参数估计速度提高约 170 倍，同时维持相近或更好的预测质量。该工作由学术团队发表，本页按技术关联收录。 [资料](https://arxiv.org/abs/2002.11955)
