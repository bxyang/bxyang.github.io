# Agents’ Last Exam：跨行业长期工作任务

在多个专业领域评测 agent 完成可验证工作流程的能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-06-03 |
| 类型 | 合作基准 |
| 公司参与 | UC Berkeley RDI 等合作；Snorkel 参与研究并通过基准资助计划支持 |

## 工作内容

任务依据美国职业分类组织，覆盖 55 个细分领域和 13 个行业组，要求完成长流程工作并提交可检查的结果。项目按难度及运行条件区分不同任务子集。 [资料](https://arxiv.org/abs/2606.05405)

## 数据与评测

论文初版描述千余项任务；后续项目页记录超过 1,500 项任务，其中 ALE-V1 公开 147 个参考任务。部分资料或软件具有访问限制，相应任务保留在非公开池中。 [资料](https://arxiv.org/abs/2606.05405)

## 结果与公开范围

项目公开参考任务、代码和运行结果，并采用滚动更新方式增加新任务及轮换公开子集。页面中的完整任务池数量与公开任务数对应不同范围。 [资料](https://arxiv.org/abs/2606.05405)
