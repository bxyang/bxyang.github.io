# Snorkel：把弱监督做成可迭代的训练数据系统

原论文：[Snorkel: Rapid Training Data Creation with Weak Supervision](https://arxiv.org/abs/1711.10160v1)，首次公开于 2017 年。本文阅读原版，并参考 [2019 年在线发表的期刊扩展版](https://link.springer.com/article/10.1007/s00778-019-00552-1)；摘要译自采用开放许可的期刊版。

## 0. 作者与机构背景

第一作者 **Alexander Ratner** 当时在斯坦福大学攻读博士，研究如何用领域规则等弱监督信息生成训练数据。他先参与提出 Data Programming，随后带领 Snorkel 开源项目，将这一方法做成可供用户操作的系统。[斯坦福介绍](https://biox.stanford.edu/people/alexander-ratner)

第二作者 **Stephen H. Bach** 在原版发表时是斯坦福大学博士后，研究规则、概率模型与弱监督；他于 2015 年取得马里兰大学计算机科学博士学位，2018 年加入布朗大学。期刊扩展版同时列出了他的斯坦福和布朗大学署名。[个人履历](https://cs.brown.edu/people/sbach/cv.pdf)

原版六位作者均署名斯坦福大学，系统的应用研究还涉及美国退伍军人事务部、美国食品药品监督管理局等合作方。Snorkel AI 于 2019 年从斯坦福的研究项目中创办，因此 2017 年的论文是公司的学术源头，而不是当时已存在的公司发布的产品。Ratner 后来成为公司联合创始人，Bach 后来也参与公司研究。[公司历史](https://snorkel.ai/company/)

## 1. 摘要翻译

以下为 Ratner 等人的期刊版摘要中文译文；原文采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，此处的改动为翻译。[原摘要与许可](https://link.springer.com/article/10.1007/s00778-019-00552-1)

为训练数据添加标签，正日益成为部署机器学习系统的最大瓶颈。我们提出 Snorkel，这是一种首创的系统，使用户无需手工标注任何训练数据，就能训练当时先进水平的模型。用户转而编写标注函数，表达各种启发式规则；这些函数的准确率和相互关联可能都是未知的。

Snorkel 将我们近期提出的机器学习范式 Data Programming 首次实现为端到端流程，从而在无法获得真实标签的情况下对这些函数的输出进行去噪。根据过去一年与公司、政府机构和研究实验室合作的经验，我们提供了灵活的接口层，供用户编写标注函数。

在一项用户研究中，与花费七小时手工标注相比，领域专家构建模型的速度达到 2.8 倍，预测表现平均提高 45.5%。我们研究了这一新场景中的建模权衡，并提出一个优化器来自动作出权衡决策，使每次流程执行最多加速至 1.8 倍。

在与美国退伍军人事务部和美国食品药品监督管理局开展的两项合作中，以及代表其他部署场景的四个开源文本和图像数据集上，Snorkel 的预测表现比此前的启发式方法平均提高 132%；相较使用大型人工整理训练集的方法，预测表现的平均差距为 3.60%。

## 2. 研究背景与相关研究

专家可以写出规则，却很难手工标注足够多的医学图像、科研文献或业务记录。规则通常只在部分数据上可靠：一条规则覆盖少但很准确，另一条覆盖广却经常出错；直接混合它们，会丢失每个标签的质量信息。用户还需要在任务定义变化时快速修改这些规则并重新生成数据。

论文将远程监督、众包和领域启发式规则视为不同的弱监督来源。众包研究已经提出估计标注者准确率的概率模型，Data Programming 进一步将类似思想推广到程序化来源。但这还没有解决实际使用中的完整流程：怎样让用户接入不同数据结构，怎样选择需要建模的规则依赖，以及怎样把生成的标签交给不同的模型。

Related Work 同时区分了主动学习、半监督学习、迁移学习和数据融合。前几类方法分别通过选择待标注样本、利用未标注数据结构或复用已有模型减少标注需求；Snorkel 关注的则是管理专家提供的高层监督信息。它与数据融合都需要处理来源可靠性，但这里合并的是对样本的类别判断，来源还可以弃权。[原版第 1、5 节](https://arxiv.org/pdf/1711.10160v1#page=1)

## 3. 核心贡献

**核心问题。** 把弱监督从一种数学方法变成可以反复使用的训练数据开发流程：让用户表达领域知识，处理来源的冲突和相关性，并将标签的不确定性传递给最终模型。

**核心方案。** Snorkel 用标注函数统一接入规则、知识库和弱分类器；函数可以给出类别，也可以弃权。系统在未标注数据上运行这些函数，学习生成模型，合并为概率标签，再用这些标签训练下游分类器。最终分类器可以学习规则之外的特征，因此不必在预测时重复执行所有规则。

系统还设计了建模策略优化器。当简单多数投票已经足够时，可以跳过较昂贵的参数学习；需要处理规则依赖时，则选择对结果更有帮助的关联。这样，用户修改规则后可以更快获得反馈，而不必每次都执行同样复杂的流程。[原版第 2—3 节](https://arxiv.org/pdf/1711.10160v1#page=3)

**结论。** 多个文本和图像任务以及用户研究支持了这种开发方式：专家能够更快构建模型，预测表现通常优于直接使用启发式标签，并接近人工训练集的结果。摘要中的 132% 是相对启发式基线的平均提升，不是准确率增加 132 个百分点。论文所说的“不手工标注训练数据”也有明确范围：开发和独立测试仍使用小规模人工标注集，以便修改规则和衡量模型表现。[原版第 2、4 节](https://arxiv.org/pdf/1711.10160v1#page=3)
