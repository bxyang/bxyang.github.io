# Snorkel：弱监督训练数据生成

将专家编写的标注规则组合成训练标签。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2017-11-28 |
| 类型 | 创办前论文与开源项目 |
| 公司参与 | 创始团队在 Stanford 的前期研究；早于公司成立 |

## 工作内容

专家把启发式规则、知识库和其他弱信号写成标注函数。系统估计不同信号的质量及冲突，为未标注数据生成概率标签，再用这些标签训练判别模型。 [资料](https://arxiv.org/abs/1711.10160)

## 数据与使用范围

论文发布在 2019 年公司成立前，因此归入技术起源。开源 Snorkel 与后来的商业 Snorkel Flow 有不同的软件与服务范围。 [资料](https://arxiv.org/abs/1711.10160)
