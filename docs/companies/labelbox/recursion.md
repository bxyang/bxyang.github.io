## 工作内容

平台接入企业 API、数据库及内部工具，用 WorldSim 将业务规则和操作流程转成训练环境。用户定义任务与评分标准，生成包含边界情况的场景，对 agent 的最终结果和中间决策分别评分。

## 数据与使用范围

评分后的执行轨迹用于微调或强化学习，训练后的模型通过托管 agent 执行长时间和异步任务。实际运行中新出现的情况进入下一轮数据与评测流程。官网列出客服与财务分析示例，产品首发日期未确认。
