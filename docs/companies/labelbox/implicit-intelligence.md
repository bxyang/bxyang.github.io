# Implicit Intelligence 与 Agent-as-a-World

测试 agent 能否处理用户没有直接说出的要求和环境约束。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-11-21 |
| 类型 | 研究与环境 |
| 公司参与 | Labelbox 发布 |

## 工作内容

研究用可配置的世界描述组织实体、动作和状态，再通过模拟环境让 agent 执行任务。评价不只看显式指令，还检查 agent 是否发现相关限制，处理工作中的隐含条件。

## 数据与使用范围

Agent-as-a-World 用于表达和运行环境，Implicit Intelligence 关注评测目标，两者在同一研究中介绍。环境定义和模拟器行为会影响任务难度。
