# Terra：机器人训练数据

采集视频、操作轨迹和多模态标注，支持机器人模型训练与评测。

## 工作内容

数据覆盖第一人称、俯视和头部与手腕联合视角，也包括专家远程操作示范。预训练资料侧重环境、物体与任务的多样性；后训练资料提供带动作标签的示范；评测围绕操作和导航任务展开。

## 数据与使用范围

采集流程先归类场景、物体、任务和操作者风格，再结合自动检查与人工复核发现缺口，调整后续采集。官网展示洗碗、整理食品、叠衣和双臂操作等样例。数据通过商业项目提供，具体交付范围按采集配置确定。
