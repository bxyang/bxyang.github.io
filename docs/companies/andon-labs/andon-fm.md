# Andon FM：AI 电台经营实验

让四个 AI 模型分别运营电台，观察内容和商业行为的长期变化。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-05-13 |
| 类型 | 实地实验 |
| 公司参与 | Andon Labs 组织 |

## 工作内容

四个模型从相同的初始要求出发，建立节目风格并尝试盈利。研究跟踪它们在约五个月中的不同决策，以观察持续目标、内容安排与经营策略如何演化。

## 数据与使用范围

报告属于长期观察案例。模型、电台受众和具体运行条件共同影响结果，不能仅根据某个电台的经营情况判断模型通用能力。
