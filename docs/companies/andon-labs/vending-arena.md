# Vending-Bench Arena：多 agent 经营竞争

让多个 agent 在同一地点经营各自的自动售货机。

| --- | --- |

## 工作内容

Arena 在第二版环境中加入竞争。不同经营者可以调整价格，也可以选择协作或交易，每个 agent 仍按自身经营结果评分。其他模型的行为因此成为环境变化的一部分。

## 数据与使用范围

与单独经营模式同日介绍。对手组合会影响结果，Arena 的余额不应与单 agent 版本直接混合排名。
