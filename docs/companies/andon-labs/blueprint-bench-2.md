# Blueprint-Bench 2：带持续笔记的空间任务

让 agent 连续重建公寓布局，并在任务之间保留策略笔记。

## 工作内容

每个 agent 顺序处理 50 套公寓，每套约 20 张室内照片。模型输出房间、门和连接关系，并可在持续笔记中记录之前任务的经验。

## 数据与使用范围

评分比较连接图，综合邻接关系、房间数、门数和方向等指标，并消除旋转、镜像差异。人类基线仅覆盖 12 套公寓；官网未标明可靠首发日期。
