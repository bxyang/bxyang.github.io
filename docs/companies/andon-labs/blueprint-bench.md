# Blueprint-Bench：照片到平面图

根据室内照片重建房间布局和连接关系。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-10-01 |
| 类型 | 基准 |
| 公司参与 | Andon Labs 发布 |

## 工作内容

模型需要识别照片中的房间、推断相邻关系，并输出二维布局。任务考查从多个视角恢复空间结构的能力，而不是对单张图片做物体识别。

## 数据与使用范围

评分将生成的布局与参考结构比较，并设置人类和随机基线。新版 Blueprint-Bench 2 增加跨公寓笔记机制，在独立页面介绍。
