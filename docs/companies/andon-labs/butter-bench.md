# Butter-Bench：机器人日常递送

评测语言模型作为机器人上层控制器执行日常递送的能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-10-28 |
| 类型 | 基准与机器人实验 |
| 公司参与 | Andon Labs 发布 |

## 工作内容

任务分为寻找包裹、识别冷藏标记、发现用户位置变化、确认取件、多步导航及完整递送六部分。模型需结合视觉、通信和移动工具，在状态发生变化时调整计划。

## 数据与使用范围

发布实验中，最佳模型完成率约 40%，人类约 95%。成绩衡量特定机器人与场地中的上层协调能力，不单独评价底层运动控制。
