# Mona：斯德哥尔摩咖啡馆实验

将实体咖啡馆的启动和经营任务交给 AI Mona。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-05-04 |
| 类型 | 实地实验 |
| 公司参与 | Andon Labs 组织 |

## 工作内容

继旧金山商店后，团队在斯德哥尔摩租下场地，将经营计划、沟通和当地流程交给 AI 处理。项目增加了不同地区的行政与经营条件，用于观察持续工作中的行为。

## 数据与使用范围

首次报告介绍启动及前两周情况。这是小规模实地实验，公开材料尚不构成多地区、长期利润表现的统计研究。
