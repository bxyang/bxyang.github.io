# Vending-Bench：长期经营模拟

让 agent 在模拟世界中长期管理自动售货机业务。

## 工作内容

agent 需要订货、管理库存、调整价格并保持账目与计划连贯。模拟时间向前推进，早先的选择会影响之后的资金和库存，因此任务要求保存状态并反复执行经营决策。

## 数据与使用范围

通过经营结果和执行行为分析长期一致性。首次发布于 2025 年 2 月；它与真实办公室售货机实验 Project Vend 是两个项目。
