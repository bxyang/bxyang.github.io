# Surge AI

> 110 人、从不融资，靠质量溢价做到十亿美元级营收，是 Meta 交易后前沿实验室的最大受益者。

## 基本盘

| | |
|---|---|
| **成立** | 2020，创始人 Edwin Chen |
| **融资** | 完全自举，从未接受外部融资（2025 年曾传 $25B+ 轮次，未确认关闭） |
| **规模** | 约 110 名员工，无销售团队；众包劳动力通过子公司 Data Annotation（约 100 万合同工） |
| **营收信号** | 2024 年约 $1.2B（媒体报道，公司从不披露）；2025 年底 run-rate 约 $1.4B |
| **大客户** | Meta 2024 年在 Surge 上花费约 $150M；Google 合同从一通两小时电话长到 >$100M/年 |
| **定价** | 比竞品贵 50% 到 10 倍，直接对接客户方的数据科学家而非采购 |
| **官网** | <https://surgehq.ai> |
