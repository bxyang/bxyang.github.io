# FinanceBench：财务文件问答

以公开财务报告为依据，评测模型检索证据和回答财务问题的能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2023-11 |
| 类型 | 基准 |
| 公司参与 | Patronus 与合作方共同发布 |

## 工作内容

问题配有答案和支持证据，模型需要在企业报告中找到信息，进行必要计算并作答。研究比较不同检索和上下文配置，区分没有找到证据、理解错误及拒绝回答等情况。

## 数据与使用范围

完整集合包含 10,231 个问题，公开样本为 150 个。论文的 2,400 次回答实验来自多个模型和配置；某一配置的错误比例不代表整个数据集或所有后续模型。
