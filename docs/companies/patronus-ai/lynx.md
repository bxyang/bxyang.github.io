# Lynx：检索增强回答的幻觉检测器

判断模型回答是否受到给定参考文档支持。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-07-11 |
| 类型 | 论文与模型 |
| 公司参与 | Patronus 发布 |

## 工作内容

Lynx 将问题、参考材料和生成回答一起作为输入，检查回答中的陈述是否与证据一致。训练数据包含经过构造和筛选的不受支持回答，以学习区分真实依据与表面流畅的内容。

## 数据与使用范围

研究同时发布 HaluBench，包含约 15,000 个跨领域样本，并开放模型、数据及代码。检测结论以给定证据为范围，不等同于对外部世界事实的全面核实。
