# Lynx：判断回答是否受到参考材料支持

原文：*Lynx: An Open Source Hallucination Evaluation Model*（[论文](https://arxiv.org/abs/2407.08488v2)）。

## 1. 摘要翻译

以下译自所列版本摘要；原文采用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 许可，本节译文沿用该许可。

检索增强生成（RAG）技术旨在减轻大语言模型（LLM）的幻觉。然而，大语言模型仍可能生成检索到的上下文无法支持或与其矛盾的信息。我们提出 LYNX，一种达到当前先进水平的幻觉检测大语言模型，能够针对具有挑战性的现实幻觉场景进行较复杂的推理。为了评估 LYNX，我们提出 HaluBench：一个综合性的幻觉评测基准，包含来自多个现实领域的 1.5 万个样本。实验结果表明，在 HaluBench 上，LYNX 的表现超过 GPT-4o、Claude-3-Sonnet，以及其他闭源和开源的“以大语言模型为裁判”的模型。我们公开发布 LYNX、HaluBench 和评测代码，供公众使用。

## 2. 研究背景与相关研究

检索增强生成会先找到与问题相关的材料，再让模型根据材料回答。它可以补充模型没有学到的新知识，却不能保证回答忠实于检索内容：模型可能误读条件、混淆对象，或者加入材料没有支持的解释。Lynx 研究的是生成之后如何自动检查这种问题。（论文 §1）

本文讨论的已有路线包括 RAGAS、ARES 和通用大模型裁判。RAGAS 通过提示模型分解和核查陈述来计算忠实性等指标；ARES 使用合成数据训练评测模型。通用大模型则可以直接读取问题、材料与答案作判断，但在专业领域和细微语义差别上仍会出错。（论文 §1—§2）

这与自然语言推断有关：检测器需要识别一句话是否由另一段文字蕴含、是否与之矛盾。不过，Lynx 要结合用户问题理解回答，而不仅是匹配两段文本。已有 HaluEval、RAGTruth 为幻觉研究提供了样本；作者希望进一步纳入金融和医学等领域，让评测覆盖更多需要专业材料推理的情况。（论文 §2）

与外部事实核查相比，本文更关注**回答相对于给定材料的忠实性**。材料本身是否符合现实、检索器是否找到了最相关文档，都不属于其完整评估范围。这也是文中“无需参考答案”的含义：检测时不需要人工写好的标准答案，但仍然需要参考材料。（论文 §3.1、§6）

## 3. 核心贡献

**核心要解决的问题。** 训练一个可公开使用的检测模型，识别那些表面合理、实际不受材料支持的回答，并给出判断理由；同时建立跨领域的统一测试集。

**核心方案。** 作者先从已有问答任务构造“问题—材料—回答—标签”样本。对原本正确的回答，使用 GPT-4o 做语义扰动：尽量保留原来的措辞与合理外观，只改变会使答案不再忠实于材料的关键含义。这样可以得到比简单替换词语更需要理解材料的错误样本。HaluBench 汇集这些数据及既有幻觉数据，来源包括 FinanceBench、DROP、COVID-QA、PubMedQA、HaluEval 和 RAGTruth。（论文 §3.2）

模型训练使用独立构造的 2,400 个训练样本，涵盖其中四类来源，并让 GPT-4o 为标签生成解释。作者微调 Llama 3 的 8B 和 70B 指令模型，使 Lynx 同时输出理由与 PASS/FAIL 判定。它因此是一种专门训练的评测模型，而不只是为通用模型写一段检测提示。（论文 §3.3）

**结论。** 主结果表中，Lynx 70B 的总体准确率为 87.4%，高于该表 GPT-4o 的 86.5%，也高于未经此项微调的 Llama 3 70B。优势并非每个领域都成立：例如 FinanceBench 和 RAGTruth 子集，GPT-4o 的准确率更高。论文支持的是这套评测下的总体改善，不是所有场景均优于通用模型。（论文 §4、表 3）

Lynx 检查的仍然是材料支持性。如果回答与不相关的材料一致，按照本文定义仍可能判为忠实；它也无法保证材料本身真实。论文主要评测英文问答，没有完成多语言、摘要或整个检索流程的全面验证。（论文 §3.1、§6）
