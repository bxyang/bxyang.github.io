# Generative Simulators：生成式训练环境

根据任务难度共同生成场景、工具配置和奖励。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-12-17 |
| 类型 | 研究与产品 |
| 公司参与 | Patronus 开发 |

## 工作内容

系统先按配置生成任务和时间线，再选择匹配复杂度的工具。任务通过课程式筛选后交给 agent 执行，轨迹由奖励函数评分；任务、工具和奖励可以分别调整。

## 数据与使用范围

公开文章描述架构和应用方向，并提供技术报告入口。它是自适应环境生成系统，不是某个固定题数的 benchmark；实际商业环境与公开报告的范围分别以交付说明为准。
