# GLIDER：小型通用语言模型评审器

使用约 30 亿参数的模型执行细粒度评测，并生成解释和文本定位。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-12-18 |
| 类型 | 论文与模型 |
| 公司参与 | Patronus 发布 |

## 工作内容

GLIDER 接收待评估内容与评价条件，输出判断及解释，还能定位与结论有关的文字。训练和测试覆盖多语言及多类评价要求，目标是用较小模型完成原本常交给大模型的评审任务。

## 数据与使用范围

论文涉及 685 个领域、183 类评价条件。其人类一致性结果对应文中测试集，不能外推为任意自定义标准的准确率；使用者仍需校准具体任务。
