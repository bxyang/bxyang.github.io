# 扩散语言模型的提示填充训练

研究扩散语言模型在训练中填充提示部分的作用。

## 工作内容

论文比较只训练回答位置与对完整序列进行掩码训练的方式，并研究提示自填充。核心实验关注训练目标如何影响模型学习，而不是提供一种新的专家标注服务。

## 数据与使用范围

属于模型训练方法研究。结论受扩散模型架构、掩码方式和所用任务限制，不能直接套用到所有自回归语言模型。
