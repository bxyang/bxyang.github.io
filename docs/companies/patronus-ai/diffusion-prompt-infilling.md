# 提示填充：让扩散语言模型学习修改提示词

原文：*Unlocking Prompt Infilling Capability for Diffusion Language Models*（[论文](https://arxiv.org/abs/2604.03677v1)）。

## 1. 摘要翻译

以下译自所列版本摘要，原文采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可。

掩码扩散语言模型（dLM）通过双向去噪生成文本，但这种能力在填充提示词时仍未得到释放。这一限制源于当前监督微调（SFT）中只对回答部分施加掩码的惯例。为了释放这一能力，我们在监督微调中扩展采用全序列掩码，同时对提示词和回答施加掩码。能力得到释放后，模型可以以少量示例为条件，填充提示模板中被遮蔽的部分。我们表明，这种由模型填充的提示词能够达到或超过人工设计模板的表现，可以有效迁移到其他模型，并且能够与已有提示优化方法互补。我们的结果表明，训练实践而非架构限制，是阻碍掩码扩散语言模型填充有效提示词的主要瓶颈。

## 2. 研究背景与相关研究

通常的自回归语言模型从左向右生成文本。掩码扩散模型则反复填补被遮蔽的位置，可以同时利用前后文，因此原则上既能补全答案，也能反过来依据示例答案补全提示词。但 LLaDA、Dream 等模型在指令微调阶段通常只遮蔽回答，始终让提示词保持完整；模型没有在这个阶段充分练习修复提示词。（论文 §1—§2）

本文将这一问题与文本填充、自动提示优化联系起来。BERT、T5 等模型已经使用过遮蔽和重建文本的训练；DDOT 研究扩散模型的文本填充机制。APE、OPRO 和 DSPy 中的优化方法则尝试生成、评估和改进提示词。本文的区别在于修改扩散模型的微调方式，使它能利用双向信息直接填充提示中的指定区域。（论文 §2.3）

这不是让模型凭空猜出一份万能提示。填充时会提供少量有标注的任务示例，再检验候选提示是否能帮助模型完成这些示例。作者希望将示例中的任务要求提炼进一段可重复使用的提示词。（论文 §3）

## 3. 核心贡献

**核心要解决的问题。** 让本来具备双向去噪结构的模型学会填充提示部分，并验证这种能力能否产生实际可用的任务提示。

**核心方案。** 在监督微调时，作者把随机掩码扩展到提示与回答的整个序列，而不是只要求模型重建回答。模型因此有机会学习在不同上下文条件下恢复提示中的内容。训练还可以增加一个只遮蔽回答的后续阶段，以改善正常回答任务；这个阶段是可选的。（论文 §3.1）

使用时，先在模板中选定要改写的位置，让模型结合少量示例及其参考回答填入文本。多个候选提示在示例上验证后，选出一个固定下来，再用于测试问题。参考回答用于提示生成与选择，不是在最终测试时把答案交给模型。生成的提示还可以交给另一个模型使用，或在 COPRO、GEPA 已经优化过的提示上继续做局部修改。（论文 §3.2、§5）

**结论。** 在 LLaDA 和 Dream 的实验中，训练方式、模板和任务都会影响填充效果。全序列训练在一些模型裁判任务中带来更有效的提示；例如 LLaDA 经过全序列训练再做回答侧微调后，填充 Judge 模板在 SummEval 上的斯皮尔曼相关系数为 0.535，高于同一模型直接使用该模板的 0.507。（论文 §4、表 2）

作者还展示了提示迁移与提示优化组合的改善，但不是所有模型或模板都受益，额外的回答侧微调也并非总是更好。本文的主要发现是：提示填充的可用性能够通过改变训练信号得到改善，不能仅根据公开指令模型填充失败，就判断扩散架构不适合这项工作。（论文 §4—§6）
