# MEMTRACK：跨时间工作记忆

衡量 agent 在持续变化的工作记录中保存、选择和更新信息的能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-10-01 |
| 类型 | 基准 |
| 公司参与 | Patronus 发布 |

## 工作内容

环境使用 Slack、Linear 和 Git 风格的工作材料，信息随时间出现并可能相互冲突。agent 需要记住相关事实、选择当前有效的信息，再回答后续问题，评测同时关注正确性、效率与冗余。

## 数据与使用范围

这不是一次把全部材料放入上下文的长文问答。记忆获取方式、更新策略和检索配置均属于评测条件，复现实验时需一并保留。
