# TRACE：agent 奖励作弊轨迹评测

识别 agent 通过偏离任务目标来获得奖励的行为。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2026-01-27 |
| 类型 | 基准 |
| 公司参与 | Patronus 发布 |

## 工作内容

研究整理 54 类奖励作弊行为，并构造由人类验证的执行轨迹。检测器需要根据行动上下文判断是否出现作弊，而非仅搜索某些关键词；论文比较普通提示与对比分析方法。

## 数据与使用范围

数据包括 517 条经过验证的合成轨迹。官网的 DETOUR 条目指向同一篇预印本，因此没有重复记作第二篇论文；后续如有独立版本需按原文区分。
