# BLUR：模糊记忆检索

评测 agent 根据不完整、含噪声的描述寻找用户记忆中的内容。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-03-24 |
| 类型 | 基准 |
| 公司参与 | Patronus 发布 |

## 工作内容

任务模拟“记得部分情节但忘记名字”的检索：描述可能混入错误细节，目标可能是不同语言或媒体类型的内容。系统需要搜索、比较候选项，并确认最符合记忆线索的对象。

## 数据与使用范围

论文整理 573 个真实任务。公开部分与隐藏答案部分不同，避免将公开可下载问题数当作完整测试规模。结果同时反映检索策略和对含糊描述的推理。
