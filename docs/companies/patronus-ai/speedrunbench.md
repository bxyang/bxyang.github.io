# SpeedrunBench：游戏轨迹优化

在完成游戏目标之后，进一步评测 agent 缩短完成帧数的能力。

| 项目 | 信息 |
| --- | --- |
| 时间 | 首发日期未确认 |
| 类型 | 基准 |
| 公司参与 | Patronus 与 University of Washington 合作 |

## 工作内容

研究包含十款游戏和三种设置：边观察边操作、从零构建整条轨迹，以及优化给定轨迹。离线设置允许反复修改、回放和比较帧数，分开考查视觉反应、路线发现与已有方案的改进。

## 数据与使用范围

论文比较十余个模型，同时使用商业游戏和较少出现在训练材料中的开源游戏。PDF 未标明可靠首发日期，因此按日期待确认收录；主要指标是达到目标所用游戏帧数。
