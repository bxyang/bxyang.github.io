# TRAIL：agent 轨迹错误分析

检查模型能否从执行记录中定位 agent 的失败原因。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-05-13 |
| 类型 | 基准 |
| 公司参与 | Patronus 发布 |

## 工作内容

研究为软件工程和搜索任务整理人工标注的执行轨迹，记录错误类型及所在位置。被测分析器需要阅读多步工具调用，判断故障发生在哪里、属于哪类错误，而不仅是判断最终任务是否成功。

## 数据与使用范围

包含 148 条人工标注轨迹，并提供错误分类与数据、代码入口。论文中的低成功率对应完整定位和分类要求，与宽松的整体成败判断不可混用。
