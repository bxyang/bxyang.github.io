# HaluBench：参考文档支持性评测

衡量幻觉检测器能否识别检索增强回答中不受证据支持的内容。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2024-07-11 |
| 类型 | 基准 |
| 公司参与 | Patronus 随 Lynx 发布 |

## 工作内容

样本将问题、上下文、回答和支持性标签配套组织，覆盖多个领域。评测时，检测器需要判断回答是否忠实于上下文；它与直接评估答案写作质量的偏好基准不同。

## 数据与使用范围

约 15,000 个样本，与 Lynx 模型在同一论文中公开。数据构造方式及领域分布会影响检测器分数；本页与 Lynx 页分别介绍数据和模型。
