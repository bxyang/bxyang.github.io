# 统一幻觉定义与 HalluWorld

## 工作内容

工作尝试把多种“幻觉”放到一致的定义中，区分内容与外部依据不符、模型认知与陈述不符等情形。这样的形式化定义用于明确检测对象，并指导评测，而不是简单把所有错误回答都归为同一种问题。
