# 统一幻觉定义精读：明确参考世界、可见信息与冲突规则

同一句回答，在不同任务中可能得到不同的幻觉标签。摘要任务要求忠实于给定文档，开放问答通常依据现实世界记录，浏览器 agent 则需要正确理解眼前的页面。本文提出把这些判断共同依赖的条件写清楚：什么是参考世界，模型能看到其中哪些信息，来源冲突时采用哪条规则。随后，以回答中是否包含相对该参考世界为假的可观察陈述，定义幻觉。

这是一篇**观点与形式化定义论文**。它提出评测组织方式、分析不同错误边界，并用国际象棋说明如何程序化生成测试；没有报告新的模型训练、性能主表或消融实验。HalluWorld 是其关联的另一篇 benchmark 论文，不能把后者的实验直接归为这篇定义论文的结果。[原文摘要、§3–5](https://arxiv.org/pdf/2512.21577v3)

## 从文档忠实性到环境状态一致性

论文以福尔摩斯的例子开头：输入材料写明他居住在伦敦贝克街 221B，模型却回答“他是虚构人物，没有现实地址”。若任务是根据故事材料回答住址，这个回答没有遵循给定的故事世界；若问题要求核实现实中是否有这个人，它又可能与任务的现实参照相符。

例子的作用是说明参照不同会改变判断，而不是用一句话决定所有虚构作品问题的统一标签。评测必须先说明接受故事内事实，还是核实现实人物记录。[原文 §1](https://arxiv.org/pdf/2512.21577v3#page=1)

论文 §2 按研究场景整理定义的发展：

| 场景 | 通常检查的关系 | 需要明确的参照 |
| --- | --- | --- |
| 机器翻译、表格转文本 | 输出是否仍对应输入内容 | 原始文本或结构化数据 |
| 摘要 | 回答中的陈述是否得到文档支持、是否与文档冲突 | 给定文档及其允许推断范围 |
| 开放问答 | 陈述是否符合外部事实 | 官方记录、知识库或指定资料快照 |
| RAG | 回答是否符合检索到的资料 | 检索语料、可见片段及来源优先级 |
| Agent | 对状态、历史和可执行动作的描述是否正确 | 环境状态与执行记录 |
| 多模态 | 语言描述是否符合图像、音频或动态场景 | 感知输入及其他先验信息之间的关系 |

作者还区分摘要研究中的两种用法：与来源直接矛盾的 intrinsic hallucination，以及来源无法核实、但未必现实错误的 extrinsic hallucination。这个区别在后面的三值定义中很重要：**无法支持不自动等于已证伪**。[原文 §2.1–2.5](https://arxiv.org/pdf/2512.21577v3#page=2)

## 定义中的四个组成部分

### 参考世界 W：判断依据

定义 1 写为：

$$
W=(\mathcal S,\mathcal H,\mathcal R).
$$

$\mathcal S$ 是可能的世界状态，$\mathcal H$ 是可能的交互历史，$\mathcal R$ 是约束状态与历史组合是否有效的规则。

这里的“世界模型”不是要求训练一个新的神经网络。它可以是数据库、源文档、DOM、状态机、程序或游戏模拟器。**参考世界**是评测采用的标准；模型内部形成的环境表示则可能不完整或错误，两者不能混为一谈。[原文定义 1、§3](https://arxiv.org/pdf/2512.21577v3#page=3)

在象棋里，状态包括棋子位置和行棋方，历史是此前着法，规则限制合法走法。在网页任务里，状态包括当前元素，历史包括已点击和页面更新，规则规定哪些元素存在、哪些动作可执行。需要保留历史，是因为相同表面输入可能对应不同的有效状态，例如动作是否已经完成、门是否已经打开。

### 视图 V：本次输入让模型看到什么

论文将视图写为：

$$
V(W,x)\subseteq\mathcal S\times\mathcal H.
$$

$x$ 是本次输入，$V$ 指定与它相关且向模型开放的部分信息。完整文档、检索出的部分段落、当前 DOM、棋盘加完整棋谱，都可以是不同视图。改变视图可以改变可获得证据，而不必改变底层世界本身。[原文 §3、§5.1](https://arxiv.org/pdf/2512.21577v3#page=3)

开放问答示例中，模型没有显式收到参考世界资料，论文称其视图为空，回答依赖参数记忆；这不意味着不存在可供评测者核对的现实记录。模型能否获得信息，与参考事实是否存在，是两个不同条件。

### 冲突规则 P：不同来源互相矛盾时采用哪一个

$P$ 定义来源冲突的处理方式。例如，摘要任务可以规定源文档优先；RAG 可以规定检索文档优于参数记忆和问题里的前提；网页任务可以规定真实 DOM 优于用户对按钮名称的描述。

这不是框架自动发现的普遍优先级。论文明确承认来源优先规则可能有主观性，也不保证每个任务都有唯一规则。评测者需要把采用的规则公开，必要时向被测模型说明，才能解释标签。[原文 §3、§7、§9](https://arxiv.org/pdf/2512.21577v3#page=10)

### 真值函数 T：真、假与未知

给定世界、输入和冲突规则，真值函数为：

$$
T_{W,P}(x,c)\in\{\mathrm{true},\mathrm{false},\mathrm{unknown}\}.
$$

$c$ 是待判断的原子陈述。`true` 表示它在当前参照下成立；`false` 表示它在该参照与规则下为假；`unknown` 表示现有定义和材料不能确定。

参考文档没有写一个事实，并不必然使它为假。若评测希望“所有未被材料支持的断言都算违规”，就需要另外定义封闭世界规则或支持性指标，不能默默把 `unknown` 映射为 `false`，然后仍声称使用同一判定标准。

这一点与 [MiniCheck](/companies/bespoke-labs/minicheck) 的任务不同：MiniCheck 二分类的“不支持”同时包含矛盾和证据不足，而本文定义 2 只以 `false` 触发幻觉。两者可以在同一评测框架中描述，但分数不能不经标签映射就相互替换。

## 幻觉标签来自可观察陈述

让模型对输入 $x$ 产生输出 $y$，再用 $C(y)$ 表示输出中可观察、可评价的原子陈述集合。定义 2 为：

$$
H(y;W,P,x)=\mathbf 1\left[
\exists c\in C(y):T_{W,P}(x,c)=\mathrm{false}
\right].
$$

只要包含至少一个假陈述，整个输出就得到幻觉标签。公式既可以用于文字中的明确断言，也可以用于动作所蕴含的环境断言，例如点击一个特定 ID 的按钮通常假定该元素存在。[原文定义 2](https://arxiv.org/pdf/2512.21577v3#page=4)

这是**输出级存在性判定**，不是逐事实正确率。下面是依据该公式编写的说明例子，不是论文实验：

| 输出包含的陈述真值 | 输出是否触发幻觉 |
| --- | --- |
| true、true | 否 |
| true、unknown | 否，但仍含无法核实内容 |
| true、false | 是 |
| false、unknown | 是 |

一个回答含一条错误与含十条错误，在这个二元定义下都记为 1。若要衡量严重程度、错误比例或回答覆盖率，需要追加指标，定义本身没有指定唯一汇总方案。

同样，完全拒答或没有可评价陈述时，存在量词不会找到假陈述。这不意味着任务完成得好。论文因此主张分别记录陈述一致性、动作有效性和任务成功，避免用“没有幻觉”代替“有用且正确地完成工作”。[原文 §5.2、§6、§9](https://arxiv.org/pdf/2512.21577v3#page=8)

### 陈述抽取需要保留语气和不确定性

$C(y)$ 是评测设计的一部分，不是论文已经给出并验证准确率的通用抽取器。若把“可能存在某个对象”直接改成“存在某个对象”，就改变了模型原本表达的确定程度。

论文要求保留这种认识状态差异。对“有 70% 概率成立”这类陈述，还需要定义可检验的概率参照；只出现数字并不会自动产生合适的真值函数。不能明确评价的陈述，应保留未知或歧义状态。原文也没有提供处理所有模糊措辞、讽刺和省略表达的完整规则。[原文 §3 的 Claim Extraction、§7](https://arxiv.org/pdf/2512.21577v3#page=4)

### 可观察错误与内部成因分开

论文使用“内部世界建模不准确”解释幻觉，但其实际判据比较的是输出与参考世界。§5.2 还明确说明：潜在表示较好的模型仍可能在部分信息下作出错误断言，内部表示不完整的模型也可能通过拒答避免幻觉。

因此，这个公式不是神经网络内部状态探针。仅从一个错误断言，不能据此确认错误到底来自记忆、感知、推理、奖励偏好还是输出阶段。本文对世界模型的讨论以作者的功能性定义为准，不把标签当成已经完成的机制定位。[原文 §4、§5.2](https://arxiv.org/pdf/2512.21577v3#page=7)

## 四类任务如何代入定义

### 摘要：文档决定当前任务中的事实

论文的公司财报示例中，文档说季度收入 21 亿美元，低于分析师预期的 23 亿；模型却写“超过预期”。收入数字本身可以正确，但与预期的关系错误，因此整段输出触发幻觉。这里采用源文档为权威的规则，无需先查询其他新闻。[原文 §3.1.1](https://arxiv.org/pdf/2512.21577v3#page=4)

示例说明原子陈述拆分的必要性：对整段做粗略主题匹配，可能因公司、季度和数字都相同而漏掉比较关系。

### 开放问答：没有提供材料也可以核对外部记录

原文以诺贝尔文学奖年份问题说明：模型即使没有收到奖项记录，输出的获奖者仍可由指定的权威记录判定。参考世界不等于模型眼前的上下文，也不等于模型自己记住的内容。[原文 §3.1.2](https://arxiv.org/pdf/2512.21577v3#page=5)

实际开放领域通常没有一份完整且永不变化的事实表。论文限制章节建议把参考世界限定为具体任务范围与版本，例如某个知识库快照，而不是声称系统具有对所有现实事实的最终裁定能力。

### RAG：错误前提不应自动覆盖检索证据

虚构国家示例中，问题给出一个地理前提，检索资料却指出对象是电影中的虚构国家。作者规定检索资料优先，模型仍编出首都，就与该规则下的参照冲突；另一个人口数值若缺乏可以核实的资料，则标为 `unknown`。[原文 §3.1.3](https://arxiv.org/pdf/2512.21577v3#page=5)

这个例子展示的是作者为该任务设置的世界与政策。它不意味着所有虚构世界都不允许有首都或人口，也不意味着检索结果在任何场景都高于用户给定的故事设定。改变参照或任务要求，必须相应改变政策和标签。

### 网页 agent：不存在的按钮与选错按钮不同

示例 DOM 只有 `confirm-btn` 和 `cancel-btn`，agent 却生成 `click(button#submit-btn)`，并声称这个按钮可用。真实元素集合不包含该 ID，因此“存在该按钮”的断言为假。用户要求点击 Submit 并不能使不存在的 DOM 元素变成真实对象。[原文 §3.1.4](https://arxiv.org/pdf/2512.21577v3#page=5)

论文区分三种错误：

- 对环境状态的描述错误，例如断言不存在的按钮存在，属于这里的幻觉。
- 正确理解按钮与状态，但选择了不能达成目标的动作，属于规划或控制错误。
- 正确理解状态和目标，却没有遵循目标，属于指令遵循问题。

这是一套概念区分，尚未由本文提供的自动分类器在真实轨迹中全面验证。一次动作失败也不充分证明其必然带有错误的环境信念；还需要明确动作对应的陈述以及当前状态记录。

## 用已知世界生成测试：象棋示例

论文 §5 的重点是提供生成流程。先取得有效状态与历史 $(s,h)$，再生成给模型阅读的文档：

$$
D=\Gamma_{\mathrm{docs}}(s,h),\qquad
x\sim\Gamma_{\mathrm{query}}(s,h,D).
$$

$\Gamma_{\mathrm{docs}}$ 可以生成棋子位置说明或棋谱；$\Gamma_{\mathrm{query}}$ 根据同一状态生成问题，覆盖对象位置、合法走法、一步将死等不同能力。随后由视图函数选择可见信息，模型回答，再抽取陈述并由规则检查。[原文 §5.1、图 2](https://arxiv.org/pdf/2512.21577v3#page=8)

图 3 展示模型认为白方可以一步吃到黑后，但实际棋盘上的兵挡住线路。只按棋子起点和终点判断会漏掉阻挡，完整状态与规则则能检查这一陈述。

同一个棋盘可配不同视图：完整棋盘、棋盘加历史，或只给文字评论。这样可以控制模型获得多少信息，同时保持底层状态不变。论文还提出变化棋局复杂度、历史长度和问题形式，以区分直接观察与状态推断的难点。

这段设计没有报告某个模型的棋局正确率，也没有提供样本量、采样分布、置信区间或基线消融。“可以按规则自动得到标签”依赖具体实现条件：题目能被形式化、参考状态正确、陈述抽取保真、真值检查器覆盖了相应命题。自由回答的所有细节不会仅因底层是棋盘就自动可判定。

### 与棋力和内部表示探测的区别

一个模型可能选择合法但很弱的棋步；只要它对棋盘和走法的事实陈述正确，就不一定触发这篇论文的幻觉定义。相反，一个棋力很强的模型也可能在解释中声称不存在的攻击路线。

所以 Elo、胜率、合法动作率、隐藏状态中能否解码棋盘，与这里的“可观察陈述是否为假”是不同测量。论文提出用环境作为可计算参照，而不是直接把游戏得分改名为幻觉率。[原文 §5.2](https://arxiv.org/pdf/2512.21577v3#page=8)

## 统一框架如何组织缓解方法

论文讨论了三组已有观点，但没有通过受控实验给出哪一种方案总体最好的结论。

| 干预 | 作者在框架中的解释 | 保留的限制 |
| --- | --- | --- |
| 更好的检索、工具或多模态输入 | 改变视图 $V$，增加可观察信息 | 信息已经提供后，仍可能被误解或发生来源冲突 |
| 校准、拒答训练 | 改变不确定情况下的表达与决策 | 可以减少错误断言，但未必补上缺失知识或完成任务 |
| 表示和训练方法改进 | 改善内部对参考世界的近似 | 本文没有提出并验证一种具体网络或训练目标 |
| 外部验证与明确冲突规则 | 改变判断过程或来源采用方式 | 仍依赖验证器覆盖范围和规则是否适合任务 |

这些关系来自 §4、§6 和 §8 的论证。论文关于“检索在哪些场景更有效”的讨论属于机制解释与研究主张，不是本文新完成的跨领域随机对照。不能据此写成检索对所有代码或 agent 任务均无帮助。

作者进一步提出改变来源优先级、测试随时间更新的世界、增加更长历史和部分可观察环境。具体而言，后续评测可以同时记录状态陈述一致性、动作有效性和任务成功，以免一个指标掩盖另外两个环节。[原文 §9](https://arxiv.org/pdf/2512.21577v3#page=10)
