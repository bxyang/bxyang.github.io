# Percival Chat：对话式执行轨迹分析

通过对话检查 agent 的调用链、错误和跨会话上下文。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-09-25 |
| 类型 | 产品 |
| 公司参与 | Patronus 开发 |

## 工作内容

用户可以按项目和轨迹定位问题，查看调用依赖、工具和 API 使用，比较耗时并检查具体日志字段。系统也帮助归纳跨多条轨迹重复出现的问题。

## 数据与使用范围

Memory Files 保存日志结构、重要字段及分析背景，后续会话可以继续使用。产品提供协作分享，是商业评测工作台的一部分；与公开 TRAIL 基准分别记录。
