# Fleet AI

构建模拟工作场景，为 agent 提供软件操作练习、人工监督和评测环境。

## 创始人背景

官方将 **Nicolai（Nic）Ouporov** 列为创始人和 CEO。他曾在 Columbia University 学习计算机科学，参与创业与技术项目；更多教育及研究履历未在公司介绍中完整披露。[本人履历](https://www.linkedin.com/in/nicolas-ouporov) · [公司介绍](https://www.fleetai.com/about)

**Fred Havemeyer** 在公司文章中被称为 founding member of technical staff，即早期技术成员。该头衔不等于联合创始人，本站不据第三方汇总页将其写成联合创始人。[团队文章目录](https://www.fleetai.com/notes)

## 发展过程

- **2024 年起**：围绕 agent 训练环境开展业务，早期网站以 fleet.so 为入口。
- **2025—2026 年**：公开介绍持续聚焦高保真软件环境及人类监督；目前域名已转到 fleetai.com。
- **2026 年 2 月**：发表早期技术成员的工作经历文章，说明环境开发团队的构成。[官方文章](https://www.fleetai.com/notes)

公司未公开详细的逐年产品发布记录。这里不以融资报道的推测补齐不存在的产品日期。

## 目前的主营业务

Fleet 为 agent 构建可反复执行任务的模拟环境，让系统练习软件、工具和团队工作方式。人工可提供过程监督；环境中的任务与反馈可用于训练和评估。[官方业务说明](https://www.fleetai.com/about)

截至本次核对，官方入口未提供可确认的自有公开 benchmark 论文清单。工作页介绍其环境产品及已披露的设计范围，不虚构具体客户、测试集规模或模型成绩。
