# UI-Vision：桌面界面感知与交互

通过人类桌面操作示范评测界面元素定位、布局理解和动作预测。

| 项目 | 信息 |
| --- | --- |
| 时间 | 2025-03-19 |
| 类型 | 合作基准 |
| 公司参与 | Turing 研究目录收录的合作项目 |

## 工作内容

数据覆盖 83 个桌面应用，包含界面框、元素标签和点击、拖动、键盘输入轨迹。三组任务从局部元素定位扩展到布局理解，再到预测下一步动作。

## 数据与使用范围

这是离线评测，使用带标注示范，而不是让 agent 在实时桌面中完整执行工作。论文提供开放数据资源；合作项目不能笼统写成 Turing 独立提出。
