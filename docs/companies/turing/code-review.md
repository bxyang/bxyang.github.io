# Code Review Benchmark：代码审查

评测模型能否在代码变更中发现和说明问题。

| 项目 | 信息 |
| --- | --- |

## 工作内容

评测对象是代码审查反馈：模型需要理解变更及其上下文，指出有依据的问题。任务与直接生成补丁不同，关注发现问题、解释问题与避免无效反馈。

## 数据与使用范围

官方榜单介绍约 1,200 个任务。不同模型必须使用相同审查输入和评分设置才能比较；公开榜单不自动意味着完整任务集开放下载。
