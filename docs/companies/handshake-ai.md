# Handshake AI

依托招聘网络组织专业人才，提供模型训练数据、行业任务基准和验证工具。

## 创始人背景

Handshake 的三位创始人为 **Garrett Lord、Ben Christensen、Scott Ringwelski**，相识于 Michigan Technological University。Lord 曾在 Palantir 实习；Christensen 与 Ringwelski 参与学校的技术项目，Ringwelski 负责早期软件架构。三人共同建立连接学生、高校和雇主的平台。[母校对创始过程的采访](https://www.mtu.edu/magazine/2026/stories/handshake-origins/)

Handshake AI 是这家公司后来开设的业务，不是一家在 2014 年就开始制作大模型数据的独立企业。当前公司仍将三人列为联合创始人。[官方介绍](https://joinhandshake.com/about/)

## 发展过程

- **2014 年**：校园招聘平台推出，以高校职业中心为合作入口。
- **2019—2024 年**：招聘网络扩大，覆盖更多学生、校友和雇主。
- **2025 年**：推出 Handshake AI，招募专家和通才参与模型训练与评测。
- **2026 年**：公开研究包括 BankerToolBench、Gandalf、CAREBench 和 VIALS，涵盖投行工作、验证器、儿童安全和生命科学图像。[研究目录](https://joinhandshake.com/research/benchmarks/)

## 目前的主营业务

招聘平台继续运营；Handshake AI 则通过 Fellowship 和专业岗位招募参与者，组织数据生产与模型评测。任务领域包含软件、金融、科学和其他职业技能。[AI 项目介绍](https://joinhandshake.com/ai/)

其 ATLAS 研究系列按职业和任务划分基准，Gandalf 则用于检查 agent 生成的文件和环境状态。经济研究报告与模型能力基准是两类成果，本时间线主要收录后者。
